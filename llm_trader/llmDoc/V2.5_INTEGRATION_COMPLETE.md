#### D. run_trading_cycle() 方法增强 (lines 344-533)

**周期开始时**:
1. 定期刷新 1h/1d 背景数据 (每 300 秒)
2. 构建时间上下文 (交易时段、清仓触发)
3. 执行 EOD 清仓 (如果触发)

**每个 symbol 处理**:
1. 从 Redis 获取最新 1s bars
2. 更新聚合器 (`aggregator.update_from_1s()`)
3. 获取多周期快照 (`aggregator.get_snapshot()`)
4. 使用 UniversalPromptBuilder 构建 prompt
5. 调用 LLM 获取决策
6. 应用硬规则 Gates:
   - EOD 清仓 → 强制 SELL
   - 禁止开新仓 → BUY 转为 HOLD

```
┌─────────────────────────────────────────┐
│  Kafka Ticks → SFS-1s → Redis (sfs:1s)  │
└──────────────────┬──────────────────────┘
                   ↓
       ┌───────────────────────────┐
       │  LLM Trader Bot (V2.5)    │
       │                           │
       │  ┌─────────────────────┐  │
       │  │ RealtimeAggregator  │◄─┼── Redis 1s bars
       │  │ (1s~1h in memory)   │  │
       │  └─────────┬───────────┘  │
       │            ↓               │
       │  ┌─────────────────────┐  │
       │  │ HigherTFContextLoader│◄─┼── ClickHouse 1h/1d
       │  └─────────┬───────────┘  │
       │            ↓               │
       │  ┌─────────────────────┐  │
       │  │UniversalPromptBuilder│  │
       │  └─────────┬───────────┘  │
       │            ↓               │
       │  ┌─────────────────────┐  │
       │  │   LLM Provider      │  │
       │  │ (OpenAI/Gemini/etc) │  │
       │  └─────────┬───────────┘  │
       │            ↓               │
       │  ┌─────────────────────┐  │
       │  │  TimeManager Gates  │  │
       │  │  (EOD flatten)      │  │
       │  └─────────┬───────────┘  │
       │            ↓               │
       │  ┌─────────────────────┐  │
       │  │  Trade Execution    │  │
       │  └─────────────────────┘  │
       └───────────────────────────┘
```

## 🔧 关键特性

### 1. 实时多周期聚合
- **完全内存运算**: 不依赖 ClickHouse features 表
- **增量更新**: 每个 1s bar 触发级联聚合
- **内存占用**: ~500KB/symbol (10 symbols = 5MB)

### 2. 硬规则 Gates
```python
if time_ctx['should_flatten'] and position_size > 0:
    action = "SELL"  # 强制清仓
    shares = position_size

if not time_ctx['allow_new_position'] and action == "BUY":
    action = "HOLD"  # 禁止开仓
```

### 3. 跨模型兼容
- **OpenAI/DeepSeek-NIM**: `json_schema` mode
- **Gemini**: `response_mime_type: application/json`
- **Claude**: Prompt 严格约束

### 4. 冷启动优化
- 启动时从 ClickHouse 获取 20 分钟 5s bars
- 合成为 1s bars 预填充聚合器
- 避免启动后 15 分钟盲区

## ⚠️ 依赖要求

### Redis 数据
需要 SFS-1s Service 运行并写入 Redis:
```bash
# 检查 Redis 数据
redis-cli LINDEX "sfs:1s:AAPL" 0
```

### ClickHouse 数据
需要 `sfs.sfs_5s` 表有历史数据:
```sql
-- 检查 5s bars
SELECT count() FROM sfs.sfs_5s
WHERE symbol='AAPL' AND ts > now() - INTERVAL 1 HOUR;
```

### VIX 数据 (可选)
需要 `trading.refs_vix_ticks` 表:
```sql
-- 检查 VIX
SELECT * FROM trading.refs_vix_ticks
ORDER BY ts DESC LIMIT 1;
```
