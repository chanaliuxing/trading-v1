* 给 1 分钟周期建立 **IBKR直写表** 和 **聚合别名**；
* 提供一个 **统一口径视图**（优先 IBKR、缺失回退聚合）；
* 保持现网一切不变，**先影子运行**，随时可回滚。

# 1) SQL 补丁（追加到 `ch_init.sql` 或直接执行）

> 目标：
>
> * 不破坏现有 `trading.bars_1m`（聚合产物/历史表）。
> * 新增 `trading.bars_1m_ibkr`（供 1m IBKR writer 写入）。
> * 用 **别名视图** `trading.bars_1m_agg` 指向老表。
> * 用 **统一视图** `trading.bars_1m_current` 选优（IBKR 优先，聚合兜底）。

> 说明：
>
> * 第一步我用“**克隆结构**”的方式创建 `bars_1m_ibkr`，降低手工 DDL 不一致的风险。
> * 如你的 CH 版本不支持 `AS trading.bars_1m` 克隆引擎，备选方案见下方「若克隆不支持」。

```sql
-- 1) 如果存在老表 trading.bars_1m，则创建一个“IBKR直写表”与其结构保持一致
--    方式A（推荐）：克隆结构（引擎/索引完全一致）
CREATE TABLE IF NOT EXISTS trading.bars_1m_ibkr AS trading.bars_1m;

-- 2) 建一个“聚合别名视图”指向老表（保持现网聚合产出不变）
CREATE OR REPLACE VIEW trading.bars_1m_agg AS
SELECT *
FROM trading.bars_1m;

-- 3) 统一口径视图：优先 IBKR，其次聚合；同键去重（按 src_priority、ver 选优）
CREATE OR REPLACE VIEW trading.bars_1m_current AS
SELECT *
FROM
(
    SELECT *, 2 AS src_priority FROM trading.bars_1m_ibkr
    UNION ALL
    SELECT *, 1 AS src_priority FROM trading.bars_1m_agg
)
ORDER BY (symbol, ts_start, src_priority DESC, ver DESC)
LIMIT 1 BY symbol, ts_start;
```

### 若克隆不支持（备选 DDL）

> 如果你所在的 ClickHouse 版本/配置不支持 `AS trading.bars_1m` 克隆引擎，请用下面“显式 DDL”建表（字段与现有 bars_* 保持一致，`ReplacingMergeTree(ver)`）：

```sql
-- 显式 DDL（精简版），如需完全一致可用 SHOW CREATE 复制 existing DDL 后仅改表名
CREATE TABLE IF NOT EXISTS trading.bars_1m_ibkr
(
    `symbol` String,
    `bar_sec` UInt16 DEFAULT 60,
    `ts_start` DateTime,
    `ts_end` DateTime,
    `open` Float64,
    `high` Float64,
    `low` Float64,
    `close` Float64,
    `vwap` Nullable(Float64),
    `volume` Float64,
    `trades` UInt64,
    `bid_last` Nullable(Float64),
    `ask_last` Nullable(Float64),
    `mid_last` Nullable(Float64),
    `what_to_show` LowCardinality(String) DEFAULT 'TRADES',
    `is_rth` UInt8 DEFAULT 1,
    `source` LowCardinality(String) DEFAULT 'IBKR',
    `exchange` LowCardinality(String) DEFAULT 'SMART',
    `currency` LowCardinality(String) DEFAULT 'USD',
    `tz` LowCardinality(String) DEFAULT 'America/New_York',
    `d` Date DEFAULT toDate(ts_start),
    `minute_of_day` UInt16 DEFAULT (toHour(ts_start) * 60) + toMinute(ts_start),
    `ver` UInt64,
    `is_backfill` UInt8 DEFAULT 0,

    -- 常见别名列（按你现有 DDL 可扩充，如 ohlc4/hlc3/range/body/notional）
    `ohlc4` Float64 ALIAS (open + high + low + close) / 4,
    `hlc3`  Float64 ALIAS (high + low + close) / 3,
    `range` Float64 ALIAS high - low,
    `body`  Float64 ALIAS close - open,
    `notional` Float64 ALIAS volume * close
)
ENGINE = ReplacingMergeTree(ver)
PARTITION BY toYYYYMMDD(ts_start)
ORDER BY (symbol, ts_start)
TTL ts_start + toIntervalDay(180)
SETTINGS index_granularity = 8192;

CREATE OR REPLACE VIEW trading.bars_1m_agg AS
SELECT * FROM trading.bars_1m;

CREATE OR REPLACE VIEW trading.bars_1m_current AS
SELECT *
FROM
(
    SELECT *, 2 AS src_priority FROM trading.bars_1m_ibkr
    UNION ALL
    SELECT *, 1 AS src_priority FROM trading.bars_1m_agg
)
ORDER BY (symbol, ts_start, src_priority DESC, ver DESC)
LIMIT 1 BY symbol, ts_start;
```

> 以后要扩展 5m/15m/30m/1h/4h/1d，只需把上面的 1m 替换为对应分辨率，`bar_sec` 改为对应秒数即可。我们会在 P6 再统一切换读口径。

# 2) 配置灰度（`config.yml`）

> P1 我们已经加过 `writers:` 段。现在仅需在**不影响现网**的情况下，准备好 1m IBKR 写入的开关（依旧默认关闭，建表后可影子打开）：

```yaml
writers:
  - name: bars_5s_writer
    enabled: true
    topic: md.bar.5s.v2
    table: bars_5s
    group_id: ch_writer_bars_5s
    batch_size: 200
    batch_timeout_sec: 2.0

  - name: bars_1m_ibkr_writer
    enabled: false                # 先保持 false；完成 DDL 与验证后再打到 true 影子跑
    topic: md.bar.1m.ibkr
    table: bars_1m_ibkr
    group_id: ch_writer_bars_1m_ibkr
    batch_size: 200
    batch_timeout_sec: 2.0
```

> **启用影子写**时，只改 `enabled: true` 并重启服务即可。读侧仍然用老表或后续统一视图，不影响策略。

# 3) 验收与观测（不动读侧）

1. **建表/视图完成性**

```sql
SHOW TABLES FROM trading LIKE 'bars_1m%';

DESCRIBE TABLE trading.bars_1m;
DESCRIBE TABLE trading.bars_1m_ibkr;
SELECT count() FROM trading.bars_1m_agg;        -- 应等于 trading.bars_1m
SELECT count() FROM trading.bars_1m_current;    -- 在 IBKR 未写入时，应等于 bars_1m
```

2. **选优逻辑（影子写开启后验证）**
   打开 `bars_1m_ibkr_writer` 的 enabled，观察写入：

```sql
-- 抽样看“同一窗口只保留一行（优先 IBKR，ver 更大优先）”
SELECT symbol, ts_start, anyHeavy(source) AS picked_source, anyHeavy(ver) AS picked_ver
FROM trading.bars_1m_current
WHERE symbol IN ('AAPL','MSFT') AND d = today()
GROUP BY symbol, ts_start
ORDER BY ts_start DESC
LIMIT 50;

-- IBKR 表与 current 的对齐率
SELECT count() AS ibkr_rows,
       (SELECT count() FROM trading.bars_1m_current WHERE d=today()) AS cur_rows
FROM trading.bars_1m_ibkr WHERE d=today();
```

3. **新鲜度与稳定性**

```sql
-- 近10个 symbol 最新 1m 的 ts_end（应与老表保持相同/更优）
SELECT symbol, max(ts_end) AS last_ts
FROM trading.bars_1m_current
WHERE d = today()
GROUP BY symbol
ORDER BY last_ts DESC
LIMIT 10;
```

# 4) 回退（1 分钟内）

* 将上游读口径（如果已切）改回 `trading.bars_1m`（或把 `bars_1m_current` 暂时改为 `SELECT * FROM trading.bars_1m`）；
