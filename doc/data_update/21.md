## 面板一览（可直接跑）

* Simulated Block Rate（按时间序列）：用 `${spread_max}` / `${imb_max}` 动态模拟熔断覆盖率
* Symbol Block Rates（表）：各标的在所选时间窗的拦截率
* Dynamic Threshold Pass Rate（时间序列）：`base_thr + alpha * p95_30s` 的放行率
* Alpha Grid（表）：多组 `alpha` 网格下，各标的放行率
* Suggested Thresholds（表）：基于 `p95_of_p95` 与 `imb95` 的参考值
* Next-Minute Return — Blocked vs Allowed（表）：被拦分钟与放行分钟的下一分钟回报对比
* Open/Close Share of Signals（表）：开/收盘 5 分钟的信号占比

---

## 使用方法

1. Grafana → Dashboards → **Import** → 上传 JSON → 选择你的 ClickHouse 数据源。
2. 顶栏变量：

   * `symbol`：默认 All（正则匹配）
   * `base_thr`：动态阈值的基础值（默认 `0.55`）
   * `alpha`：每 bps 抬升的斜率（默认 `0.008`）
   * `spread_max` / `imb_max`：模拟熔断阈值（默认 `8` / `0.60`）

> 所有查询基于你已落地的表：`lake.bbo_1s_features`, `lake.quotes_l1`, `trading.signals_1m`, `trading.bars_1m_current`。
