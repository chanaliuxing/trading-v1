那我来拍板：把“**参数热更新**”做成**事件驱动**，每个进程在本地监听 `config.symbol_risk_params.v1`，一收到某只票的参数就**立刻失效缓存**，实盘 1 分钟内生效改成**秒级生效**。都是“加法”，不破坏你现有逻辑。

---

# 做什么（最小改动）

1. 新增 `libs/param_watch.py`：一个轻量 Kafka 订阅器（`aiokafka`），收到消息就调用回调 `invalidate(symbol)`。
2. 在 `SignalExecutor` 与 `IBKRBroker` 里**可选开启**监听；默认 60s TTL 还在，**监听到就即时刷新**。
3. `config.yml` 加个开关与 group_id 后缀，避免和 writer / 其它消费者冲突。

## 1) 新文件：`libs/param_watch.py`

```python
# libs/param_watch.py
from __future__ import annotations
import asyncio, json, signal
from typing import Callable, Optional
from aiokafka import AIOKafkaConsumer
from libs.config import config
from libs.logger import get_logger

log = get_logger(__name__)

class ParamWatch:
    """
    订阅 config.symbol_risk_params.v1，收到一条就调用 cb(symbol) 失效缓存。
    - 幂等：同一 symbol 多次收到也没副作用
    - 解耦：只负责触发，不落库
    """
    def __init__(self,
                 topic: str = "config.symbol_risk_params.v1",
                 group_id_suffix: str = ".hot",
                 invalidate_cb: Optional[Callable[[str], None]] = None):
        self.topic = topic
        base_gid = f"{topic}{group_id_suffix}"
        self.group_id = config.kafka_config.get("group_id_prefix", "svc") + "." + base_gid
        self.bootstrap = config.kafka_config["bootstrap_servers"]
        self.invalidate_cb = invalidate_cb or (lambda s: None)
        self._task: Optional[asyncio.Task] = None
        self._consumer: Optional[AIOKafkaConsumer] = None
        self._stopping = asyncio.Event()

    async def start(self):
        if self._consumer: return
        self._consumer = AIOKafkaConsumer(
            self.topic,
            bootstrap_servers=self.bootstrap,
            group_id=self.group_id,
            enable_auto_commit=True,
            auto_offset_reset="latest",
            value_deserializer=lambda b: json.loads(b.decode("utf-8")),
            key_deserializer=lambda b: b.decode("utf-8") if b else None,
            max_poll_records=50
        )
        await self._consumer.start()
        self._task = asyncio.create_task(self._run(), name="param_watch_run")
        log.info("ParamWatch started", topic=self.topic, group_id=self.group_id)

    async def stop(self):
        self._stopping.set()
        try:
            if self._task: await asyncio.wait_for(self._task, timeout=5)
        except Exception:
            pass
        try:
            if self._consumer: await self._consumer.stop()
        except Exception:
            pass
        self._consumer = None
        self._task = None
        self._stopping.clear()
        log.info("ParamWatch stopped")

    async def _run(self):
        assert self._consumer is not None
        while not self._stopping.is_set():
            try:
                msg = await self._consumer.getone()
            except Exception as e:
                log.warning("ParamWatch poll error, retrying", err=str(e))
                await asyncio.sleep(1.0)
                continue
            try:
                key = msg.key or ""
                payload = msg.value or {}
                data = payload.get("data", {})
                sym = (data.get("symbol") or key or "*").upper()
                self.invalidate_cb(sym)
                log.info("param.invalidate", symbol=sym)
            except Exception as e:
                log.warning("ParamWatch handle error", err=str(e))
```

## 3) 在执行器里启用（增量补丁）

**`services/trading/signal_executor.py`** —— 在 `__init__` 添加：

```python
from libs.param_watch import ParamWatch  # NEW

class SignalExecutor:
    def __init__(self, ...):
        ...
        self.param_watch = None
        pw_cfg = getattr(config, "param_watch", {}) or {}
        if pw_cfg.get("enabled", True):
            # 监听到就清理这只票的缓存；下一次取阈值/风控即刷新
            self.param_watch = ParamWatch(
                topic=pw_cfg.get("topic", "config.symbol_risk_params.v1"),
                group_id_suffix=pw_cfg.get("group_id_suffix", ".hot"),
                invalidate_cb=self.param_store.invalidate
            )
            asyncio.create_task(self.param_watch.start())
```

**在优雅停机处**（如果有 `stop()`/`close()`）：

```python
if self.param_watch:
    await self.param_watch.stop()
```

> 其它逻辑不用变：我们之前的 `_dynamic_threshold()`、`_micro_check()` 已经改成从 `param_store` 取值；这里只是把“60s 轮询”升级为“事件驱动秒级”。

## 5) 快速验收

1. **推一条参数到 Kafka（dry-run 先看）**

```bash
python -m tools.push_symbol_params --yaml params.yml --dry-run
python -m tools.push_symbol_params --yaml params.yml
```

2. **观察日志**（executor / broker 任一处）
   出现 `param.invalidate symbol=TSLA` 即表示已接收并刷新。

3. **信号阈值变化**

```sql
SELECT ts, symbol, prob, threshold
FROM trading.signals_1m
WHERE d=today() AND symbol='TSLA'
ORDER BY ts DESC LIMIT 30;
```

推高 `TSLA.alpha_per_bps` 后，新的 `threshold` 会**在下一条信号时间**反映出来（无需重启）。

## 6) 灰度与回退

* 灰度：先只对 1–2 只票生效（`params.yml` 只包含这些 symbol），稳定后再全量。
* 回退：`config.yml` 把 `param_watch.enabled=false` 即回归 60s TTL；或直接停掉该消费者进程。
