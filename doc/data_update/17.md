# B) 动态阈值（spread 愈大，阈值愈高），可开关

## 1) 配置开关（`config.yml`）

```yaml
execution:
  dynamic_threshold:
    enabled: true
    base: 0.55            # 基础阈值
    alpha_per_bps: 0.008  # 每 1 bps 增加 0.008 的概率阈值（例：P95=5bps → +0.04）
    lookback_min: 20      # 回看 20 分钟的一秒级 BBO 特征
    min: 0.52
    max: 0.80
    source_table: "lake.bbo_1s_features"  # 已在 P5 建好
```

> 经验起点：`alpha_per_bps ∈ [0.006, 0.010]`；开盘时 spread 常更高，阈值会被抬升，能有效抑制噪声成交。

## 2) `SignalExecutor` 中按 P95 spread 动态计算阈值

`services/trading/signal_executor.py` 里新增一个查询方法 + 使用处替换：

```python
# 顶部新增
from libs.db.clickhouse import ClickHouseDB
from datetime import timedelta, timezone, datetime

# ExecCfg 里不用加字段，直接读 config.execution.dynamic_threshold
class SignalExecutor:
    def __init__(...):
        ...
        self.db = ClickHouseDB()
        self.dyn = (getattr(config, "execution", {}).get("dynamic_threshold", {}) or {})
        self.dyn_enabled = bool(self.dyn.get("enabled", False))
        self._thr_cache: dict[tuple[str, datetime], float] = {}  # (sym, minute_ts) -> thr

    def _minute_floor(self, t: datetime) -> datetime:
        return t.replace(second=0, microsecond=0, tzinfo=timezone.utc)

    def _dynamic_threshold(self, sym: str, tgt: datetime) -> float:
        if not self.dyn_enabled: 
            return float(self.cfg.threshold)
        key = (sym, tgt)
        if key in self._thr_cache:
            return self._thr_cache[key]
        base = float(self.dyn.get("base", 0.55))
        alpha = float(self.dyn.get("alpha_per_bps", 0.008))
        lookback = int(self.dyn.get("lookback_min", 20))
        tbl = str(self.dyn.get("source_table","lake.bbo_1s_features"))

        start = tgt - timedelta(minutes=lookback)
        rows = self.db.query(f"""
            SELECT toFloat64(quantileExact(0.95)(spread_bps)) AS p95
            FROM {tbl}
            WHERE symbol=%(s)s AND ts >= %(st)s AND ts < %(ed)s
        """, {"s": sym, "st": start, "ed": tgt}) or [{"p95": None}]
        p95 = rows[0]["p95"] or 0.0
        thr = base + alpha * float(p95)     # 线性抬升
        thr = max(float(self.dyn.get("min", 0.52)), min(thr, float(self.dyn.get("max", 0.80))))
        self._thr_cache[key] = thr
        return thr
```

在 `_loop()` 里拿到 `tgt` 和 `symbols` 后、推理输出前，把**每个 symbol 的阈值**算出来并套用：

```python
if work:
    X = df.loc[work, self.features].fillna(method="ffill").fillna(method="bfill")
    proba = self.model.predict_proba(X.values)[:,1]
```
