## 看板包含什么

* 概览

  * Signals & Pass Rate（时间序列）
  * Cumulative PnL（分钟累计）
* 风控

  * Risk Guard Events by Reason（按原因分面）
  * Block Rate by Symbol（表格）
  * Spread P95（按 $__interval 聚合）
  * Crossed/Locked Rate（ask<bid）
* 交易

  * Orders by Status（时间序列）
  * Fills Notional（买/卖）
  * Top Symbols by PnL（表格）
  * Threshold vs Prob（均值/放行率）

> 所有查询都用你前面落地的表：`trading.signals_1m`, `monitor.risk_guard_events`, `lake.bbo_1s_features`, `lake.quotes_l1`, `trading.pnl_minute`, `trading.orders`, `trading.fills`。

---

## 导入与使用

1. Grafana → Dashboards → **Import** → 上传上面的 JSON。
2. 在顶部变量栏选择：

   * **ClickHouse DS**：选你的 ClickHouse 数据源
   * **Symbols**：可多选，默认 “All”
   * **Account**：默认 “All”
3. 右上角选择时间范围（默认 7d），刷新频率 30s。

> 变量用的是 `match(symbol, ${symbol:regex}) / match(account, ${account:regex})`，All=`.*`，无需改 SQL。

## 小改建议（可选）

* 如果你的环境没有 `trading.bars_5s`，把“Symbols”变量查询改为：

  ```
  SELECT DISTINCT symbol FROM trading.signals_1m ORDER BY symbol
  ```
* 如果 `pnl_minute` 还没上线，把相关面板先隐藏或用 `pnl_daily` 替代：

  ```
  SELECT d_local AS t, sum(realized + unrealized_eod) AS pnl
  FROM trading.pnl_daily
  WHERE $__timeFilter(t) AND match(account, ${account:regex})
  GROUP BY t ORDER BY t
  ```
* 想要“每分钟拦截率”面板，可以把这条加成一个 timeseries：

  ```
  SELECT
    toStartOfInterval(ts, INTERVAL $__interval SECOND) AS t,
    avg(action='BLOCK') AS block_rate
  FROM monitor.risk_guard_events
  WHERE $__timeFilter(ts) AND match(symbol, ${symbol:regex})
  GROUP BY t ORDER BY t
  ```
