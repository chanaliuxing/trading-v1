# 1) ClickHouse 扩展：5m / 15m 分表 + 统一视图（只做加法）

> 与 1m 的做法完全一致：**不动老表**（聚合产物），新增 IBKR 直写表与 `current` 统一口径视图；老聚合表通过 `*_agg` 视图接入 fallback。

### 1.1 5 分钟

```sql
-- 5m：IBKR直写表（优先使用“克隆结构”以保证字段/引擎一致）
CREATE TABLE IF NOT EXISTS trading.bars_5m_ibkr AS trading.bars_5m;

-- 5m：聚合别名视图（指向现有聚合表）
CREATE OR REPLACE VIEW trading.bars_5m_agg AS
SELECT * FROM trading.bars_5m;

-- 5m：统一口径（IBKR优先，聚合兜底；同键只取一行）
CREATE OR REPLACE VIEW trading.bars_5m_current AS
SELECT *
FROM (
  SELECT *, 2 AS src_priority FROM trading.bars_5m_ibkr
  UNION ALL
  SELECT *, 1 AS src_priority FROM trading.bars_5m_agg
)
ORDER BY (symbol, ts_start, src_priority DESC, ver DESC)
LIMIT 1 BY symbol, ts_start;
```

### 1.2 15 分钟

```sql
-- 15m：IBKR直写表
CREATE TABLE IF NOT EXISTS trading.bars_15m_ibkr AS trading.bars_15m;

-- 15m：聚合别名视图（指向现有聚合表/物化视图产物）
CREATE OR REPLACE VIEW trading.bars_15m_agg AS
SELECT * FROM trading.bars_15m;

-- 15m：统一口径视图
CREATE OR REPLACE VIEW trading.bars_15m_current AS
SELECT *
FROM (
  SELECT *, 2 AS src_priority FROM trading.bars_15m_ibkr
  UNION ALL
  SELECT *, 1 AS src_priority FROM trading.bars_15m_agg
)
ORDER BY (symbol, ts_start, src_priority DESC, ver DESC)
LIMIT 1 BY symbol, ts_start;
```

> 说明：如果你所在 CH 版本不支持 “AS trading.bars_X” 克隆表，请用之前 1m 的“显式 DDL”版建表（把表名/默认 `bar_sec` 改成 300/900 秒即可）。

# 5) 验收（重点是“current”一口径是否被补全）

**A. 近三日缺口统计（1m/5m/15m 通用）**

```sql
WITH '1m' AS res
SELECT
  d,
  count() AS windows,
  countIf(src='IBKR') AS ibkr_rows,
  countIf(src='AGG')  AS agg_rows
FROM
(
  SELECT d, symbol, ts_start,
         multiIf(_table='bars_1m_ibkr','IBKR','AGG') AS src
  FROM (
    SELECT *, _table FROM trading.bars_1m_current
  )
  WHERE d >= today()-2
)
GROUP BY d
ORDER BY d DESC;
```

**B. current 选优正确（IBKR 优先 + ver 更大优先）**

```sql
SELECT symbol, ts_start,
       anyHeavy(source) AS picked_source,
       sum(1) AS dup_cnt
FROM trading.bars_1m_current
WHERE d = today()-1
GROUP BY symbol, ts_start
HAVING dup_cnt = 1
ORDER BY ts_start DESC
LIMIT 50;
```

**C. 回补充足性（对账后应覆盖到 RTH 完整时间轴）**

```sql
-- 任意日任意标的的“理论窗口-实际窗口”
WITH toDate('2025-09-05') AS day
SELECT count() AS missing_cnt
FROM
(
  SELECT t AS ts_start
  FROM generateSeries(toDateTime(concat(toString(day),' 13:30:00')),
                      toDateTime(concat(toString(day),' 20:59:59')),
                      INTERVAL 60 SECOND)
) g
LEFT JOIN
(
  SELECT ts_start FROM trading.bars_1m_current
  WHERE symbol='TSLA' AND d=day
) h USING ts_start
WHERE h.ts_start IS NULL;
```

# 6) 回退策略（仍然 1 分钟内）

* 若 5m/15m 影子写引入异常：把相应 `writers.*_ibkr_writer.enabled: false`，和 `backfill.instances.*_enabled: false` 即可；
* `bars_{res}_current` 如已对上游开放，想暂停 fallback：临时把 `current` 视图改成只读 `*_agg`；
* 离线脚本停掉 cron 即可；**数据已写入的部分不会污染**（`ReplacingMergeTree(ver)` 兜底），你只需要调整视图优先级即可。

* 1m/5m/15m 都具备 **IBKR 直写 + 聚合兜底 + 统一视图**；
* Catchup（盘中）+ Reconciler（盘后）双保险；
* 一键命令 + 定时任务 + 验收 SQL 全齐活。
