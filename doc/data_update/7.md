好，直接把 **spread / imbalance** 做成 `lake.bbo_1s_features`，同时给你**两种形态**：

* **物化视图（MV）→入库落表**：适合大量回测、方便下游直接 `SELECT`。
* **普通视图（View）→即席计算**：零存储、即时衍生，适合轻负载或先灰度。

下面给你**可直接执行**的 ClickHouse DDL 补丁（只做加法，不影响现网）。
建议追加到 `ch_init.sql`，或直接在 CH 客户端执行。

## 1) 特征落表（推荐：物化视图 + 明细表）

```sql
-- 先确保库存在（如果你已在 P5 创建过 lake，就会跳过）
CREATE DATABASE IF NOT EXISTS lake;

-- 明细表：bbo_1s_features（按秒的盘口特征）
CREATE TABLE IF NOT EXISTS lake.bbo_1s_features
(
  symbol       String,
  ts           DateTime,               -- 秒对齐（来自 bbo_1s）
  mid          Nullable(Float64),      -- (bid+ask)/2
  spread       Nullable(Float64),      -- ask-bid（若 crossed/locked → NULL）
  spread_bps   Nullable(Float64),      -- (ask-bid)/mid * 1e4
  imbalance    Nullable(Float64),      -- (bid_size-ask_size)/(bid_size+ask_size)
  microprice   Nullable(Float64),      -- (bid*ask_size + ask*bid_size)/(bid_size+ask_size)
  is_valid     UInt8,                  -- 1=正常BBO（ask>=bid且>0），否则0
  ver          UInt64,                 -- 版本（沿用 bbo_1s.ver）
  d            Date DEFAULT toDate(ts)
)
ENGINE = ReplacingMergeTree(ver)
PARTITION BY d
ORDER BY (symbol, ts)
TTL d + INTERVAL 180 DAY;

-- 物化视图：从 bbo_1s 同步生成特征
CREATE MATERIALIZED VIEW IF NOT EXISTS lake.mv_bbo_1s_to_features
TO lake.bbo_1s_features
AS
SELECT
  symbol,
  ts,
  -- 保护：避免非法/异常价导致除零或负 spread
  if(ask>0 AND bid>0, (bid+ask)/2, NULL)                                                AS mid,
  if(ask>=bid AND ask>0 AND bid>0, ask - bid, NULL)                                     AS spread,
  if(ask>=bid AND ask>0 AND bid>0 AND ( (bid+ask)/2 )>0,
     (ask - bid) / ((bid+ask)/2) * 1e4, NULL)                                           AS spread_bps,
  if((bid_size + ask_size) > 0,
     (bid_size - ask_size) / (bid_size + ask_size), NULL)                                AS imbalance,
  if((bid_size + ask_size) > 0,
     (bid*ask_size + ask*bid_size) / (bid_size + ask_size), NULL)                        AS microprice,
  toUInt8(ask>=bid AND ask>0 AND bid>0)                                                  AS is_valid,
  ver,
  toDate(ts)                                                                             AS d
FROM lake.bbo_1s;
```

**说明与取舍**

* 只要 `lake.bbo_1s`（P5 已建）在写，特征表就会**自动跟进**。
* 对**异常报价**（crossed/locked、或≤0）：不丢弃行，但所有依赖值置为 `NULL`，并标 `is_valid=0`。
* 仍用 `ReplacingMergeTree(ver)`，迟到/回补会被新 `ver` 自动覆盖。
* 保留期示例 180 天，可按需要调整。

## 2) 零存储形态（普通视图，按需即席计算）

如果你想先灰度，不落表，只“看一眼”即席结果，可以建**普通视图**：

```sql
CREATE OR REPLACE VIEW lake.bbo_1s_features_vw AS
SELECT
  symbol,
  ts,
  if(ask>0 AND bid>0, (bid+ask)/2, NULL)                                                AS mid,
  if(ask>=bid AND ask>0 AND bid>0, ask - bid, NULL)                                     AS spread,
  if(ask>=bid AND ask>0 AND bid>0 AND ( (bid+ask)/2 )>0,
     (ask - bid) / ((bid+ask)/2) * 1e4, NULL)                                           AS spread_bps,
  if((bid_size + ask_size) > 0,
     (bid_size - ask_size) / (bid_size + ask_size), NULL)                                AS imbalance,
  if((bid_size + ask_size) > 0,
     (bid*ask_size + ask*bid_size) / (bid_size + ask_size), NULL)                        AS microprice,
  toUInt8(ask>=bid AND ask>0 AND bid>0)                                                  AS is_valid,
  ver,
  toDate(ts)                                                                             AS d
FROM lake.bbo_1s;
```

> 两者可**并存**：`bbo_1s_features`（存盘）用于回测/重算密集场景；`bbo_1s_features_vw`（即席）用于线上轻读或对照验证。

## 3) 快速验收（复制即用）

```sql
-- 是否有新表/视图
SHOW TABLES FROM lake LIKE 'bbo_1s%';

-- 有数据后：抽样检查
SELECT *
FROM lake.bbo_1s_features
WHERE d = today()
ORDER BY ts DESC
LIMIT 10;

-- 异常价占比（越低越好）
SELECT
  countIf(is_valid=0) AS bad,
  count() AS total,
  round(bad/total*100, 3) AS bad_pct
FROM lake.bbo_1s_features
WHERE d = today();

-- 分钟级聚合（给成本/滑点模型做参考）
SELECT
  symbol,
  toStartOfMinute(ts) AS minute,
  quantileExact(0.95)(spread_bps) AS p95_spread_bps,
  avgIf(spread_bps, is_valid=1)   AS avg_spread_bps,
  avgIf(imbalance, is_valid=1)    AS avg_imbalance
FROM lake.bbo_1s_features
WHERE d = today()
GROUP BY symbol, minute
ORDER BY minute DESC
LIMIT 20;
```

## 4) 回退 & 调优

* **回退**：`DETACH TABLE lake.mv_bbo_1s_to_features` 可立即停止落表；读取 `bbo_1s_features_vw` 仍可即席获得同样字段。
* **调优路径**：

  * 想要**平滑指标**（如 30s/5min 移动均值）：不建议在 MV 里做；用**派生视图**或**查询时窗口函数**更灵活。
  * 想要**日级/分钟级成本轮廓表**（P95 spread 等）：单独建 `market_cost_profile` 聚合表与日更任务（我可以下一步给）。
  * 如需**过滤异常报价**：把 MV 的 `SELECT` 增加 `WHERE ask>=bid AND ask>0 AND bid>0`；当前默认是**不丢弃**、只置 `NULL`，更利于质量统计与审计。

## 5) 给策略/特征的落地建议

* 策略侧如需**更稳健的滑点门槛**：用上面的分钟聚合 SQL 直接生成 `minute_of_day × P95(spread_bps)` 的表（或物化视图）作为成本曲线。
