好，**第 2 步：把“执行错误码矩阵（Error Matrix）”接入 place/modify/cancel**。
目标：**不再因为可修复错误引发“改单风暴/下单雪崩”**，并把**不可修复错误**快速、可审计地拒绝。

我按“配置 → 规则引擎 → 价格修复 → 重试控制 → 三个包装器(place/modify/cancel) → 指标与自测”给你**可直接粘贴**的实现骨架（不生成文件）。

## A) 配置（`config.yml` 增量）

```yaml
exec:
  error_matrix:
    enabled: true
    # 指数退避：基础/上限/抖动
    backoff:
      base_ms: 150
      max_ms: 2000
      jitter_ms: 120
      max_attempts: 6           # 单次动作最大尝试次数

    # 速率限制（防 pacing）
    pacing:
      per_symbol_qps: 2.0       # 每symbol下单+改单+撤单合计QPS
      per_account_qps: 8.0

    # 可修复类：如何处理
    fixups:
      tick_size: "round"        # 按tick四舍五入
      price_collar_pct: 3.0     # 超围栏→夹紧
      luld_clamp: true          # 有LULD→夹紧到带内
      ssr_bump_ticks: 1         # SSR卖空→高于bid n tick
      rth_only_autoswitch: true # 非RTH被拒→若策略允许盘前盘后则切开关重试

    # 永久拒绝类（示例关键词/码；真实IB码因地区不同会有差异，因此采用 message 关键字+可选code）
    permanent_rules:
      - { code: 201,   contains: "Contract description" }     # 无效合约/权限
      - { code: 101,   contains: "Max rate of messages" }     # 被风控限流（账户级）
      - { code: 135,   contains: "rejected by system" }       # 券商系统拒绝
      - { contains: "insufficient" }                          # 保证金/资金不足
    retryable_rules:
      - { contains: "pacing violation" }                      # 节流
      - { contains: "price out of range" }                    # 价格越界
      - { contains: "outside regular trading hours" }         # 非RTH
      - { contains: "cancel pending" }                        # 与撤单并发
      - { contains: "duplicate" }                             # 幂等冲突→换ref重试
```

> 说明：我们**不强依赖具体 IB 错误码**，而是以 `message contains` 为主、`code` 为辅，避免地区/版本差异导致误判。

## B) 错误分类与决策（Error Matrix）

```python
# -*- coding: utf-8 -*-
from dataclasses import dataclass
from typing import Optional, Dict

@dataclass
class BrokerError:
    code: Optional[int]
    message: str
    context: Dict  # {action:'place/modify/cancel', order_ref:..., symbol:..., side:..., limit_px:..., ...}

@dataclass
class MatrixDecision:
    kind: str     # 'retry', 'fix_and_retry', 'rate_limit_sleep', 'permanent_fail'
    reason: str
    fix: Optional[Dict] = None  # e.g. {'limit_px': 123.45, 'allow_prepost': True}
    delay_ms: int = 0

class ErrorMatrix:
    def __init__(self, cfg, market_state_provider, logger, metrics):
        self.cfg = cfg
        self.ms = market_state_provider
        self.log = logger
        self.m = metrics

    def classify(self, err: BrokerError) -> str:
        msg = (err.message or "").lower()
        code = err.code
        # 永久拒绝
        for rule in self.cfg["exec"]["error_matrix"]["permanent_rules"]:
            cnd = rule.get("contains","").lower()
            if (not cnd or cnd in msg) and (("code" not in rule) or rule["code"] == code):
                return "permanent"
        # 可重试
        for rule in self.cfg["exec"]["error_matrix"]["retryable_rules"]:
            cnd = rule.get("contains","").lower()
            if (not cnd or cnd in msg) and (("code" not in rule) or rule["code"] == code):
                return "retryable"
        # 可修复（基于语义）
        if "min tick" in msg or "price increment" in msg or "invalid price" in msg:
            return "fix_tick"
        if "price out of range" in msg or "outside price" in msg:
            return "fix_range"
        if "short sale" in msg and "uptick" in msg:
            return "fix_ssr"
        if "outside regular trading hours" in msg:
            return "fix_rth"
        if "pacing" in msg or "rate of messages" in msg:
            return "pacing"
        # 默认：可重试一次看看
        return "retryable"

    async def decide(self, err: BrokerError) -> MatrixDecision:
        klass = self.classify(err)
        cfix = self.cfg["exec"]["error_matrix"]["fixups"]
        # 速率限制
        if klass == "pacing":
            return MatrixDecision("rate_limit_sleep", "pacing_violation", delay_ms=self.cfg["exec"]["error_matrix"]["backoff"]["max_ms"])
        if klass == "permanent":
            return MatrixDecision("permanent_fail", "permanent_rule_matched")

        # 可修复：构造修复建议
        fix = {}
        ctx = err.context
        symbol = ctx.get("symbol")
        m = await self.ms.get(symbol) if symbol else None

        if klass == "fix_tick":
            if cfix.get("tick_size","round") == "round" and m:
                t = m.tick_size or 0.01
                for k in ("limit_px","stop_px"):
                    if ctx.get(k) is not None:
                        px = ctx[k]
                        adj = round(round(px / t) * t, 10)
                        fix[k] = adj
            return MatrixDecision("fix_and_retry", "tick_size_fix", fix=fix)

        if klass == "fix_range":
            # 夹紧到价格围栏
            collar = float(cfix.get("price_collar_pct", 3.0))
            ref = (m.mid_px or m.last_px) if m else ctx.get("ref_px")
            if ref and ctx.get("limit_px") is not None:
                lim = ctx["limit_px"]
                dev = abs(lim - ref) / ref * 100.0
                if dev > collar:
                    lim = ref*(1+collar/100) if lim>ref else ref*(1-collar/100)
                fix["limit_px"] = lim
            # LULD 夹紧
            if cfix.get("luld_clamp", True) and m and m.luld_low and m.luld_high:
                for k in ("limit_px","stop_px"):
                    if k in fix:
                        v = fix[k]
                        v = min(max(v, m.luld_low), m.luld_high)
                        fix[k] = v
            return MatrixDecision("fix_and_retry", "price_range_fix", fix=fix)

        if klass == "fix_ssr":
            # 卖空：价格≥bid+tick
            if m and m.bid_px:
                bump = (cfix.get("ssr_bump_ticks",1) or 1) * (m.tick_size or 0.01)
                if ctx.get("limit_px") is not None:
                    need = m.bid_px + bump
                    if ctx["limit_px"] < need:
                        fix["limit_px"] = need
                else:
                    # 市价/无价：转限价（更安全）
                    fix["order_type"] = "LMT"
                    fix["limit_px"] = m.bid_px + bump
            return MatrixDecision("fix_and_retry", "ssr_fix", fix=fix)

        if klass == "fix_rth":
            # 允许切换 RTH 标志（如果策略允许）
            if cfix.get("rth_only_autoswitch", True):
                fix["allow_prepost"] = True
                return MatrixDecision("fix_and_retry", "prepost_enable", fix=fix)

        # 其它可重试
        return MatrixDecision("retry", "transient_retry")
```

## C) 价格修复与上下界（与 Reg-Lite 对齐）

> 这段在**发送前**最后再跑一次，确保修复后的价格仍满足 **tick/围栏/LULD/SSR**。

```python
class PriceFixer:
    def __init__(self, cfg, market_state_provider):
        self.cfg = cfg
        self.ms = market_state_provider

    async def sanitize(self, symbol, side, order):
        """
        order: {'order_type','limit_px','stop_px','tif','allow_prepost',...}
        返回修正后的 order
        """
        m = await self.ms.get(symbol)
        t = m.tick_size or 0.01
        collar = float(self.cfg["exec"]["error_matrix"]["fixups"]["price_collar_pct"])
        ref = m.mid_px or m.last_px

        # tick 对齐
        def rt(px): return None if px is None else round(round(px/t)*t, 10)
        if order.get("limit_px") is not None:
            order["limit_px"] = rt(order["limit_px"])
        if order.get("stop_px") is not None:
            order["stop_px"] = rt(order["stop_px"])

        # 围栏
        if ref and order.get("limit_px") is not None:
            lim = order["limit_px"]; dev = abs(lim-ref)/ref*100.0
            if dev > collar:
                order["limit_px"] = ref*(1+collar/100) if lim>ref else ref*(1-collar/100)

        # LULD
        if m.luld_low and m.luld_high:
            for k in ("limit_px","stop_px"):
                if order.get(k) is not None:
                    order[k] = min(max(order[k], m.luld_low), m.luld_high)

        # SSR
        if side in ("SELL_SHORT",) and getattr(m, "ssr_active", False) and m.bid_px:
            need = m.bid_px + t
            if order.get("order_type") == "MKT":
                order["order_type"] = "LMT"
                order["limit_px"] = max(order.get("limit_px") or need, need)
            elif order.get("limit_px") is not None:
                order["limit_px"] = max(order["limit_px"], need)

        return order
```

## D) 重试控制（指数退避 + 节流器）

```python
import time, random, asyncio
from collections import defaultdict, deque

class RetryBudget:
    def __init__(self, cfg):
        b = cfg["exec"]["error_matrix"]["backoff"]
        self.base = int(b["base_ms"]); self.max = int(b["max_ms"])
        self.jit  = int(b["jitter_ms"]); self.max_attempts=int(b["max_attempts"])
        self.attempts = defaultdict(int)

    def next_delay(self, key:str) -> int:
        n = self.attempts[key] = self.attempts[key] + 1
        ms = min(self.max, int(self.base * (2 ** (n-1))) + random.randint(0,self.jit))
        return ms

    def too_many(self, key:str) -> bool:
        return self.attempts[key] >= self.max_attempts

    def reset(self, key:str):
        self.attempts.pop(key, None)

class TokenBucket:
    """ 简易节流：symbol/account 两级 """
    def __init__(self, rate_per_sec: float, capacity: int = 4):
        self.rate = rate_per_sec; self.capacity = capacity
        self.tokens = capacity; self.ts = time.time()

    def allow(self) -> bool:
        now = time.time()
        self.tokens = min(self.capacity, self.tokens + (now - self.ts) * self.rate)
        self.ts = now
        if self.tokens >= 1.0:
            self.tokens -= 1.0
            return True
        return False

class PaceGate:
    def __init__(self, cfg):
        pc = cfg["exec"]["error_matrix"]["pacing"]
        self.sym = defaultdict(lambda: TokenBucket(pc["per_symbol_qps"]))
        self.acct = TokenBucket(pc["per_account_qps"])

    async def wait(self, symbol:str):
        while not (self.acct.allow() and self.sym[symbol].allow()):
            await asyncio.sleep(0.05)
```

## E) 包装器：place / modify / cancel

> 把你现有的 `ib_connector.place_order(...)`、`modify_order(...)`、`cancel_order(...)` 外面包一层。**统一幂等键**与**错误决策**。

```python
class ExecWrapper:
    def __init__(self, cfg, connector, market_state_provider, logger, metrics):
        self.cfg = cfg; self.conn = connector; self.ms = market_state_provider
        self.log = logger; self.m = metrics
        self.matrix = ErrorMatrix(cfg, market_state_provider, logger, metrics)
        self.fixer  = PriceFixer(cfg, market_state_provider)
        self.retry  = RetryBudget(cfg)
        self.pace   = PaceGate(cfg)

    async def _send(self, action:str, symbol:str, payload:Dict) -> Dict:
        """调用真实券商接口，返回 {'ok':True,'data':...} 或抛出异常/返回 {'ok':False,'error':...}"""
        # 这里用你已有的 ib_client/connector 封装
        if action == "place":
            return await self.conn.place_order(**payload)
        if action == "modify":
            return await self.conn.modify_order(**payload)
        if action == "cancel":
            return await self.conn.cancel_order(**payload)
        raise RuntimeError("unknown action")

    async def _attempt(self, action:str, symbol:str, ctx_key:str, payload:Dict):
        await self.pace.wait(symbol)
        try:
            res = await self._send(action, symbol, payload)
            if isinstance(res, dict) and res.get("ok", True):
                self.retry.reset(ctx_key)
                return res
            # 标准化错误
            be = BrokerError(code=res.get("code"), message=res.get("message",""), context={**payload, "action":action, "symbol":symbol})
        except Exception as e:
            be = BrokerError(code=getattr(e, "code", None), message=str(e), context={**payload, "action":action, "symbol":symbol})

        # 交给矩阵
        decision = await self.matrix.decide(be)
        self.log.warning(f"[ExecMatrix] action={action} key={ctx_key} klass={decision.kind} reason={decision.reason} fix={decision.fix} err={be.code}:{be.message}")

        if decision.kind == "permanent_fail":
            self.m.exec_perm_fail.labels(action=action, reason=decision.reason).inc()
            raise RuntimeError(f"permanent_fail:{decision.reason}")

        if decision.kind == "rate_limit_sleep":
            await asyncio.sleep(decision.delay_ms/1000.0)
            return await self._attempt(action, symbol, ctx_key, payload)

        if decision.kind in ("retry","fix_and_retry"):
            if self.retry.too_many(ctx_key):
                self.m.exec_retry_exhausted.labels(action=action).inc()
                raise RuntimeError("retry_exhausted")
            if decision.fix:
                payload = {**payload, **decision.fix}
                # 再做一次 sanitize，确保tick/围栏/LULD/SSR一致
                if action in ("place","modify"):
                    payload = await self._sanitize_payload(symbol, payload)
            delay = self.retry.next_delay(ctx_key)
            await asyncio.sleep(delay/1000.0)
            return await self._attempt(action, symbol, ctx_key, payload)

        # 兜底：视为失败
        raise RuntimeError("unhandled_error_matrix_path")

    async def _sanitize_payload(self, symbol:str, payload:Dict) -> Dict:
        if "order_type" in payload:
            side = payload.get("side","BUY")
            fixed = await self.fixer.sanitize(symbol, side, {
                "order_type": payload.get("order_type"),
                "limit_px": payload.get("limit_px"),
                "stop_px": payload.get("stop_px"),
                "tif": payload.get("tif"),
                "allow_prepost": payload.get("allow_prepost", False),
            })
            payload.update(fixed)
        return payload

    # ---- 对外三个方法 ----
    async def place(self, symbol:str, payload:Dict):
        payload = await self._sanitize_payload(symbol, payload)
        key = f"place:{symbol}:{payload.get('order_ref')}"
        return await self._attempt("place", symbol, key, payload)

    async def modify(self, symbol:str, payload:Dict):
        payload = await self._sanitize_payload(symbol, payload)
        key = f"modify:{symbol}:{payload.get('order_ref')}"
        return await self._attempt("modify", symbol, key, payload)

    async def cancel(self, symbol:str, payload:Dict):
        key = f"cancel:{symbol}:{payload.get('order_ref')}"
        return await self._attempt("cancel", symbol, key, payload)
```

> 用法：把你原来 Phase4/执行器里调用 `connector.place_order(...)` 的地方替换为 `exec_wrapper.place(symbol, payload)`。`payload` 就是你现有的下单参数（order_ref/side/order_type/limit_px/stop_px/tif/allow_prepost/qty/...）。

## G) 自测 / 错误注入小剧本（本地 10 分钟）

> 不连 IB。用一个 **FakeConnector** 模拟不同错误，确认分支逻辑。

```python
class FakeConnector:
    def __init__(self, script):
        self.script = script  # dict key→sequence of responses
        self.calls = []

    async def place_order(self, **kw):
        k = f"place:{kw.get('order_ref')}"
        self.calls.append(k)
        seq = self.script.get(k, [])
        if not seq: return {"ok": True, "data": {"order_id":"ok"}}
        resp = seq.pop(0)
        return resp

    async def modify_order(self, **kw):
        k = f"modify:{kw.get('order_ref')}"
        self.calls.append(k)
        seq = self.script.get(k, [])
        if not seq: return {"ok": True}
        return seq.pop(0)

    async def cancel_order(self, **kw):
        k = f"cancel:{kw.get('order_ref')}"
        self.calls.append(k)
        seq = self.script.get(k, [])
        if not seq: return {"ok": True}
        return seq.pop(0)
```

**验收要点**

* 可修复类：**最多 1–3 次**尝试内成功；日志包含 `klass=fix_and_retry reason=...`；
* pacing：有**sleep**再成功；
* 永久失败：**立即终止**，计入 `exec_perm_fail_total{reason=...}`；
* 超过 `max_attempts`：落 `exec_retry_exhausted_total`。

## H) 与 Phase4/OCO 的衔接提醒

* **首次成交即挂 OCO** 时，如 OCO 子单触发**价格越界**，也会走同一矩阵（避免“改单风暴”）。
* **部分成交→按比例同步 OCO** 的“改单”也走矩阵；对 pacing 类错误，**退避**而不是连环改。
* **反手**时，先**强撤**旧保护（cancel→矩阵），等 `CANCELLED` 回执或**超时TTL**后再发新单（避免并发 modify/cancel 交错）。

### 一句话总结

* 这套 Error Matrix **不依赖具体 IB 码**，用“关键词+可选 code”稳健分类；
* 可修复类**自动修复并重试**，其它**指数退避**；
* 永久错误**立刻失败**且有**可观测指标**；
* 接完这一步，你的执行层能在**监管/质量/速率**高压下稳定运行，**没有“改单风暴”**。

如果你准备好了，我们就进入**第 3 步：Reservation 看门狗（TTL 释放 + 冷启动自愈 + 异常强撤）**。你说“继续”，我就把看门狗接线与演练脚本贴出来。
