## 2) 适配层（把老策略 → DSL `signal`）

> 放在旧策略旁边或新 `adapters/legacy_adapter.py`。策略端只需要实现一个 `emit_signal(features)`。

```python
# -*- coding: utf-8 -*-
# LegacyStrategyAdapter：兼容旧策略输出，生成 DSL signal
from dataclasses import dataclass

@dataclass
class LegacySignal:
    side: int           # +1 / -1 / 0
    strength: float     # 0..1
    ref_px: float
    risk_anchor: float  # ATR等
    ts_end: int         # epoch_us

class LegacyStrategyAdapter:
    def __init__(self, strategy_impl, dsl_template_name: str, rule_engine, ctx, logger):
        """
        strategy_impl: 老策略对象（已有 compute() / decide() / etc）
        dsl_template_name: 绑定的模板名，如 'meanrev_v2_tpl'
        rule_engine: 第12步提供的 RuleEngine 实例
        ctx: 引擎上下文（含 Position/Param/SubmtIntent等）
        """
        self.impl = strategy_impl
        self.tpl = dsl_template_name
        self.rules = rule_engine
        self.ctx = ctx
        self.log = logger

    async def on_features(self, symbol: str, f: dict):
        """
        老策略继续按原逻辑产出 side/score/ref，还有你们已有的 alpha 信号。
        """
        # 1) 调用老策略拿到原始决策因素（示例方法名，按实际调整）
        # 例如：side, score = self.impl.compute_direction(f)
        side, score = self.impl.compute_direction(f)  # side∈{-1,0,+1}; score∈[0,1]
        ref_px = f.get("mid_last") or f.get("close")  # 参考价可选
        atr = f.get("atr_14") or f.get("atr1m") or 0.0
        ts_end = int(f["ts_end"])  # microseconds 或 milliseconds 请统一

        signal = {
            "side": int(side),
            "strength": float(max(0.0, min(1.0, score))),
            "ref_px": float(ref_px),
            "risk_anchor": float(atr),
            "ts_end": ts_end
        }

        # 2) 交给 DSL 引擎生成 envelopes（target/protect/reverse）
        envs = await self.rules.evaluate(self.ctx, self.tpl, symbol, f, signal)

        # 3) 逐个提交（后续走 风控→仲裁→预留→执行）
        for env in envs:
            await self.ctx.SubmitIntent(env)
```

> 这样老策略几乎不动：原 `compute_direction(f)` 保留；止损/分批/反手全部落到模板。

### 3.1 均值回归 `meanrev_v2_tpl`

```yaml
name: meanrev_v2_tpl
defaults:
  cadence_s: 5
  ttl_ms: 2000
  min_lot: 10
  lot_round: 10
  base_risk_usd: 2000
  atr_k: 1.6
  time_limit_s: 1200
  trail_atr_mult: 1.4
  reversal_atomic: true
rules:
  - id: gate
    when: { all: [ "f.qscore>=70", "f.gap_ratio<=0.05" ] }
  - id: sizing
    when: "signal.side!=0"
    compute:
      lot_abs: "floor( base_risk_usd / max(0.01, atr_k * f.atr_14), lot_round )"
      layers:
        - { trigger: "abs(f.zscore_20)>=1.0", qty_mult: 1.0 }
        - { trigger: "abs(f.zscore_20)>=1.5", qty_mult: 1.5 }
        - { trigger: "abs(f.zscore_20)>=2.0", qty_mult: 2.0 }
    emit:
      type: target
      mode: net
      qty: "lot_abs * qty_mult * sign(signal.side)"
      style: { kind: LMT, limit_px: "signal.ref_px" }
  - id: protect
    when: "position.qty!=0"
    emit: { type: protect, oco: { trail_atr_mult: "trail_atr_mult", time_stop_s: "time_limit_s" } }
  - id: reverse
    when: { all: [ "position.qty*signal.side<0", "abs(signal.strength)>=0.6" ] }
    emit: { type: reverse, atomic: "reversal_atomic", style: { kind: LMT, limit_px: "signal.ref_px" } }
```

## 4) Phase3 接线片段（把 DSL 引擎插到老流水线）

> 在 `phase3_v2.py` 的策略调用处，用适配器替换直接下单逻辑。

```python
# -*- coding: utf-8 -*-
# 伪代码：Phase3 中每个 symbol 的 5s/10s tick 到来时
from adapters.legacy_adapter import LegacyStrategyAdapter
from rules.engine import RuleEngine       # 第12步给的
from templates import load_templates      # 自己写个加载函数（YAML→dict）

TEMPLATES = load_templates(["meanrev_v2_tpl.yml","breakout_v1_tpl.yml","trend_v1_tpl.yml","orb_retest_tpl.yml"])
RULES = RuleEngine(TEMPLATES, logger, metrics)

# 假设老策略对象已有（从 strategy_loader 加载）
adapters = {}  # key=(strategy_id) -> adapter
def get_adapter(strategy_id, strategy_impl, ctx, tpl_name):
    if strategy_id not in adapters:
        adapters[strategy_id] = LegacyStrategyAdapter(strategy_impl, tpl_name, RULES, ctx, logger)
    return adapters[strategy_id]

async def on_features_event(strategy_id, strategy_impl, tpl_name, symbol, f, ctx):
    # f：本次 5s/10s 的 feature 行（含 ts_end/ref_px/atr 等）
    adapter = get_adapter(strategy_id, strategy_impl, ctx, tpl_name)
    await adapter.on_features(symbol, f)
```

> `strategy_loader.py` 里为每个策略实例加一个模板名 `tpl_name` 的配置即可（不同策略用不同模板）。

## 5) 迁移回归（A/B 对齐）

> 保持“可控差异”：止损/分批逻辑迁到模板后，回测轨迹与旧版**不可能100%一致**，但我们给门槛与定位方法。

### 5.1 影子 vs 纸交（迁移前后 A/B）

* 用我之前提供的**回归脚本**对同一窗口做两组跑：

  * A：老策略（旧 Phase3 路径）
  * B：新策略（Adapter + DSL 模板）
* 对比指标（建议阈值）：

  * `中位滑点差 |Δbps| ≤ 5bps`
  * `fill_dt_p95_s ≤ 3s`
  * `持仓轨迹一致率 ≥ 90%`（止损编舞差异允许一定不一致）
  * `PnL 偏差（绝对） ≤ 10%`
* 定位差异：开启 `audit.rule_trace.v1`，找“同一时刻为何老路径加仓而新路径没加/数量不同”。

### 5.2 单策略自测清单

* `gate` 命中率与预期一致（`qscore/gap` 触发屏蔽时无下单）
* `protect`：首次成交后 OCO 必挂、数量与方向匹配；手动取消一腿 → 5s 内自愈
* `reverse`：命中后**原子反手**，中途失败可自愈或 KillSwitch
* `cadence`：独立 5s/10s 节奏互不影响（不同策略实例可不同）

## 6) 上线步骤（每个策略）

1. **冻结老参数**：导出老策略 runtime 参数与种子（param_hash）
2. **选择模板**：`meanrev / breakout / trend / orb_retest`（或定制）
3. **映射老参数到 DSL**：`min_lot/lot_round/atr_k/time_limit_s` 等
4. **影子对齐**：近 2–3 天影子跑，A/B 对比阈值达标
5. **纸交金丝雀**：3–5 标的小额度，观察 OCO/拒单率/SLO
6. **Prom/Grafana**：`rule_hits_total{rule_id}`、`qty_pruned_by_caps_total`、`reverse_atomic_total`
7. **放量**：接入第 11 步的**动态 cap**；先 10%→25%→100%
8. **回滚**：一键切回老 Phase3 路径（feature 与下游一致，切换仅在 Phase3）

---

## 7) 妥协与风险提示

* **止损/分批转模板**后，跟老代码的**微观时序**不同步，导致少量“不同步成交”；这属于预期差异。
* 若老策略里对“瞬时盘口”的行为很多（如 tick 内微调价），建议：

  * 在模板里保留 `limit_px = ref_px`；
  * 由执行器（Phase4）启用**Reg-Lite 价格修正**与**一次重申价**，而不是在策略层频繁改价。
* DSL 表达式**必须 O(1)**，禁止昂贵计算（EMA/ATR 仍由 features 管道产出）。

## 8) 快速迁移样板（把某个老策略接到模板）

```python
# 示例：把老的 MeanReversionStrategy 接到 meanrev_v2_tpl
from adapters.legacy_adapter import LegacyStrategyAdapter
from rules.engine import RuleEngine
from templates import load_templates

TEMPLATES = load_templates(["meanrev_v2_tpl.yml"])
ENGINE = RuleEngine(TEMPLATES, logger, metrics)

class MeanReversionStrategy:
    # 保留你们已有构造/参数
    def compute_direction(self, f):
        # 旧逻辑：zscore>阈值多/空、强度按|z|线性压缩到[0,1]
        z = float(f.get("zscore_20", 0.0))
        if abs(z) < 1.0: return 0, 0.0
        side = +1 if z < 0 else -1   # 往均值回归方向
        strength = min(1.0, max(0.0, (abs(z)-1.0)/1.5))  # 1.0->2.5 映射到 0..1
        return side, strength

# Phase3 接线
meanrev_impl = MeanReversionStrategy()
adapter = LegacyStrategyAdapter(meanrev_impl, "meanrev_v2_tpl", ENGINE, ctx, logger)

async def on_features(symbol, f):
    await adapter.on_features(symbol, f)
```

### 10) 收尾：如何判定迁移完成？

* 影子/纸交 **A/B 对齐**达到阈值；
* `rule_trace` 审计里**所有命中路径**可解释；
* OCO 不变量**0 违规**，反手编舞演练通过；
* 实盘 canary **2 个交易日**稳定（拒单率 <1%，SLO 达标）；
* 回滚开关可随时切到老 Phase3（未用上则下线老路径）。
