好，**第 4 步：OCO 同步与反手编舞**。
目标：做到**首次成交即挂保护**、**部分成交按比例调整**、**一方触发另一方即刻清理**，以及**信号反转时原子切换头寸**。下面给你**可直接粘贴**的实现骨架（不生成文件），默认你已经接上了前 3 步的 Reg-Lite、Error Matrix、Reservation Watchdog。

## A) 数据模型（轻量，不侵入你现有表结构）

> 放到 `phase4_executor.py` 或一个 `oco_manager.py` 中，供执行器进程引用。

```python
# -*- coding: utf-8 -*-
import asyncio, time
from dataclasses import dataclass, field
from typing import Optional, Dict, Any

def now_us(): return int(time.time()*1e6)

@dataclass
class OCOConfig:
    tp_px: Optional[float] = None              # 固定止盈（可空，走ATR动态）
    sl_px: Optional[float] = None              # 固定灾难止损（入场即设）
    trail_atr_mult: Optional[float] = None     # 跟踪止损 ATR 倍数（执行器内跟踪）
    time_stop_s: Optional[int] = None          # 时间止损（自首次成交起计时）
    tif: str = "DAY"

@dataclass
class PlanCtx:
    plan_id: str
    strategy_id: str
    symbol: str
    side_entry: str                  # 'BUY' or 'SELL' 进场方向（多=BUY，空=SELL）
    pos_qty: float = 0.0             # 实时头寸（正多负空）
    avg_px: Optional[float] = None
    first_fill_us: Optional[int] = None
    oco: Dict[str,str] = field(default_factory=dict)  # {'tp':order_ref,'sl':order_ref}
    last_best_px: Optional[float] = None              # 用于trail
    config: OCOConfig = field(default_factory=OCOConfig)
    lock: asyncio.Lock = field(default_factory=asyncio.Lock)  # 串行化该 plan 的编舞
```

## B) OCO 管理器（首次挂、比例调、触发清理、时间止损）

> 依赖：
>
> * **ExecWrapper**（上一轮的错误矩阵包装器）
> * **MarketStateProvider**（tick/lot/LULD/SSR/ticks rounding）
> * **ReserveLedger**（部分成交/终态释放已经接上）

```python
class OCOManager:
    def __init__(self, execw, ms_provider, ledger, logger, metrics):
        self.exec = execw
        self.ms = ms_provider
        self.ledger = ledger
        self.log = logger
        self.m = metrics

    # ---- 1) 首次成交即刻挂 OCO（按已成交头寸规模） ----
    async def ensure_on_first_fill(self, plan: PlanCtx):
        async with plan.lock:
            if plan.pos_qty == 0:
                return
            # 若已有 OCO 则跳过
            if plan.oco.get('tp') and plan.oco.get('sl'):
                return
            m = await self.ms.get(plan.symbol)
            tick = m.tick_size or 0.01

            side_exit = "SELL" if plan.pos_qty > 0 else "BUY"    # 平多→SELL，平空→BUY
            qty = abs(plan.pos_qty)

            # 计算止盈/止损价（若未显式给，按 ATR/阈值估）
            ref = m.mid_px or m.last_px or plan.avg_px
            tp_px = plan.config.tp_px
            sl_px = plan.config.sl_px
            if ref and not tp_px:
                tp_bp = 40/1e4
                tp_px = ref*(1+tp_bp) if side_exit=="SELL" else ref*(1-tp_bp)
            if ref and not sl_px:
                hard_bp = 80/1e4
                sl_px = ref*(1-hard_bp) if side_exit=="SELL" else ref*(1+hard_bp)

            # 下单（止盈用 LMT，止损用 STP_LMT 更安全）
            tp_ref = f"{plan.plan_id}-TP"
            sl_ref = f"{plan.plan_id}-SL"
            try:
                res_tp = await self.exec.place(plan.symbol, {
                    "order_ref": tp_ref,
                    "side": side_exit,
                    "order_type": "LMT",
                    "limit_px": tp_px,
                    "qty": qty,
                    "tif": plan.config.tif
                })
                plan.oco['tp'] = res_tp['data'].get('order_ref', tp_ref)
                await self.ledger.attach_order_ref(plan.plan_id, "tp", plan.oco['tp'])
                self.m.oco_place_total.labels(kind="tp").inc()
            except Exception as e:
                self.log.error(f"[OCO] place TP fail {plan.plan_id} {e}")

            try:
                res_sl = await self.exec.place(plan.symbol, {
                    "order_ref": sl_ref,
                    "side": side_exit,
                    "order_type": "STP_LMT",
                    "limit_px": sl_px,            # 触发后限价（防止巨大滑点）
                    "stop_px": sl_px,             # 简化：同价；也可 stop<limit（SELL）/stop>limit（BUY）
                    "qty": qty,
                    "tif": plan.config.tif
                })
                plan.oco['sl'] = res_sl['data'].get('order_ref', sl_ref)
                await self.ledger.attach_order_ref(plan.plan_id, "sl", plan.oco['sl'])
                self.m.oco_place_total.labels(kind="sl").inc()
            except Exception as e:
                self.log.error(f"[OCO] place SL fail {plan.plan_id} {e}")

            # 启动时间止损
            if plan.config.time_stop_s and not plan.first_fill_us:
                plan.first_fill_us = now_us()
            if plan.config.time_stop_s:
                asyncio.create_task(self._time_stop(plan))

    # ---- 2) 部分成交后按比例调整 OCO 数量 ----
    async def on_fill_update(self, plan: PlanCtx, new_pos_qty: float, avg_px: Optional[float]):
        async with plan.lock:
            plan.avg_px = avg_px or plan.avg_px
            prev = plan.pos_qty
            plan.pos_qty = new_pos_qty
            # 首次从 0→非0：立即挂 OCO
            if prev == 0 and new_pos_qty != 0:
                await self.ensure_on_first_fill(plan)
                return
            # 回到 0：取消现有 OCO
            if new_pos_qty == 0:
                await self._cancel_oco(plan, reason="flattened")
                return
            # 调整 OCO 数量
            qty = abs(new_pos_qty)
            for kind in ("tp","sl"):
                if plan.oco.get(kind):
                    try:
                        await self.exec.modify(plan.symbol, {
                            "order_ref": plan.oco[kind],
                            "qty": qty
                        })
                        self.m.oco_modify_total.labels(kind=kind, field="qty").inc()
                    except Exception as e:
                        self.log.warning(f"[OCO] modify {kind} qty fail {plan.plan_id}: {e}")

            # 跟踪止损（trail）
            if plan.config.trail_atr_mult and plan.avg_px:
                await self._maybe_trail(plan)

    # ---- 3) 一方触发 → 另一方清理 & 计划闭环 ----
    async def on_child_filled(self, plan: PlanCtx, which: str):
        async with plan.lock:
            # which in {'tp','sl'}
            other = "sl" if which=="tp" else "tp"
            if plan.oco.get(other):
                try:
                    await self.exec.cancel(plan.symbol, {"order_ref": plan.oco[other]})
                    self.m.oco_cancel_total.labels(kind=other, reason=f"oco_{which}_filled").inc()
                except Exception as e:
                    self.log.warning(f"[OCO] cancel other {other} fail {plan.plan_id}: {e}")
            plan.oco.clear()
            # 计划终止：让上层状态机把 plan 置为 COMPLETED / CLEANUP
            # 释放预留由上层在订单终态时完成

    # ---- 4) 时间止损 ----
    async def _time_stop(self, plan: PlanCtx):
        # 独立协程：到时即平仓
        try:
            await asyncio.sleep(plan.config.time_stop_s)
            async with plan.lock:
                if plan.pos_qty == 0: 
                    return
                # 直接平仓（市价或小偏离的 LMT/IOC）
                side_exit = "SELL" if plan.pos_qty > 0 else "BUY"
                qty = abs(plan.pos_qty)
                try:
                    await self.exec.place(plan.symbol, {
                        "order_ref": f"{plan.plan_id}-TIMEFLAT",
                        "side": side_exit,
                        "order_type": "STP_LMT",
                        "stop_px": None,                 # 可省略，使用轻微偏离的 LMT 也可
                        "limit_px": None,
                        "qty": qty,
                        "tif": "IOC"
                    })
                    self.m.oco_time_stop_total.inc()
                except Exception as e:
                    self.log.error(f"[OCO] time stop fail {plan.plan_id}: {e}")
        except asyncio.CancelledError:
            return

    # ---- 5) Trail 逻辑（执行器内定时提升止损价） ----
    async def _maybe_trail(self, plan: PlanCtx):
        m = await self.ms.get(plan.symbol)
        tick = m.tick_size or 0.01
        ref = m.last_px or m.mid_px
        if not ref or not plan.avg_px or not plan.oco.get("sl"):
            return
        go_long = plan.pos_qty > 0
        # 高水位（多→最高价；空→最低价）
        if plan.last_best_px is None:
            plan.last_best_px = ref
        if (go_long and ref > plan.last_best_px) or ((not go_long) and ref < plan.last_best_px):
            plan.last_best_px = ref
        # 以 ATR 作为 trail 距离（示例：从 extras 或外部因子获取）
        atr = getattr(m, "atr_5s", None)  # 若无则略
        if not atr:
            return
        if go_long:
            new_sl = max(plan.config.sl_px or -1e9, plan.last_best_px - plan.config.trail_atr_mult * atr)
        else:
            new_sl = min(plan.config.sl_px or 1e9, plan.last_best_px + plan.config.trail_atr_mult * atr)
        # 仅向有利方向移动
        cur_sl = None  # 需要你在订单缓存里读取当前止损价；这里假设读不到则直接尝试
        try:
            await self.exec.modify(plan.symbol, {
                "order_ref": plan.oco["sl"],
                "stop_px": new_sl,
                "limit_px": new_sl  # 触发后限价同价，避免巨大滑点
            })
            self.m.oco_modify_total.labels(kind="sl", field="trail").inc()
        except Exception as e:
            self.log.debug(f"[OCO] trail modify fail {plan.plan_id}: {e}")

    # ---- 6) 取消当前 OCO（平仓或反手前调用） ----
    async def _cancel_oco(self, plan: PlanCtx, reason: str):
        for kind, ref in list(plan.oco.items()):
            try:
                await self.exec.cancel(plan.symbol, {"order_ref": ref})
                self.m.oco_cancel_total.labels(kind=kind, reason=reason).inc()
            except Exception as e:
                self.log.warning(f"[OCO] cancel {kind} fail {plan.plan_id}: {e}")
        plan.oco.clear()
```

## C) 反手编舞（Atomic Reverse）：先清保护，再原子替换

> 原则：**不同时持有相反方向的敞口**；避免 “旧保护单 + 新进场单” 交错成交导致“裸露或反向裸露”。
> 序列：暂停同符号新意图 → 取消既有 OCO → `flatten` 当前头寸（或用 net 量一次性反手）→ 新进场 → 首次成交即挂新 OCO。

```python
class ReversalOrchestrator:
    def __init__(self, oco: OCOManager, execw, ms_provider, arbiter_gate, logger, metrics):
        self.oco = oco; self.exec = execw; self.ms = ms_provider
        self.gate = arbiter_gate     # 暂停该 symbol 的新意图（防并发）
        self.log = logger; self.m = metrics

    async def reverse(self, plan: PlanCtx, target_qty: float, new_oco_cfg: OCOConfig):
        # target_qty：反手后的目标净仓（正多负空）
        async with plan.lock:
            sym = plan.symbol
            # 1) 暂停新意图
            self.gate.pause(sym, reason="reverse")
            try:
                # 2) 清理旧 OCO
                await self.oco._cancel_oco(plan, reason="reverse")

                # 3) 计算净变动；可选策略：
                # a) 保守：先flatten再新进
                if plan.pos_qty != 0:
                    side_exit = "SELL" if plan.pos_qty > 0 else "BUY"
                    qty = abs(plan.pos_qty)
                    try:
                        await self.exec.place(sym, {
                            "order_ref": f"{plan.plan_id}-FLAT",
                            "side": side_exit,
                            "order_type": "STP_LMT",  # 或 IOC LMT
                            "qty": qty, "tif": "IOC"
                        })
                        self.m.reverse_steps_total.labels(step="flatten").inc()
                    except Exception as e:
                        self.log.error(f"[REV] flatten fail {plan.plan_id}: {e}")
                        return

                # 4) 新进场（至 target_qty）
                side_entry = "BUY" if target_qty > 0 else "SELL"
                qty = abs(target_qty)
                try:
                    res = await self.exec.place(sym, {
                        "order_ref": f"{plan.plan_id}-REV",
                        "side": side_entry,
                        "order_type": "LMT",   # 由 Translator 决定时更合理
                        "qty": qty,
                        "tif": "DAY"
                    })
                    self.m.reverse_steps_total.labels(step="entry").inc()
                    # 5) 更新 plan 基本面并替换 OCO 配置
                    plan.side_entry = side_entry
                    plan.config = new_oco_cfg
                    plan.first_fill_us = None  # 让首次成交回调再挂新 OCO
                except Exception as e:
                    self.log.error(f"[REV] entry fail {plan.plan_id}: {e}")
                    return
            finally:
                # 6) 恢复新意图
                self.gate.resume(sym)
```

> 注：如果你的合规允许**净反手**（一次性下 net 量），可以把步骤 3/4合并为一张净单（更省成本）。但对 SSR/LULD/Halt 状态要格外小心，保守做法更稳。

## D) 与你的执行/事件总线的接线点

1. **FillEvent** → `OCOManager.on_fill_update(plan, new_pos_qty, avg_px)`

   * 如果从 0→非 0，会自动 `ensure_on_first_fill()` 挂 OCO；
   * 如果回到 0，会自动取消 OCO。
2. **ChildOrder Filled**（止盈或止损分支成交） → `OCOManager.on_child_filled(plan, which='tp'|'sl')`
3. **信号反转**（策略目标与现有 `pos_qty` 方向相反） → `ReversalOrchestrator.reverse()`
4. **时间止损**：`ensure_on_first_fill` 启动协程，到时直接触发平仓（IOC/STP_LMT）。

---

## E) 边界与异常处理（已内置/建议）

* **并发安全**：`plan.lock` 串行化同一个 plan 的所有编舞（挂/改/撤）。
* **错误矩阵**：所有 place/modify/cancel 都走 **ExecWrapper**，确保 tick/LULD/SSR/围栏与 pacing 退避一致。
* **预留与对账**：

  * 首次挂 OCO/修改/撤单会更新 `ledger.attach_order_ref()`（我们已在 OCO 首挂时做）；
  * `FILLED/CANCELLED/REJECTED` 回执进入后 → `ledger.release(plan_id, cause=...)`；
  * **部分成交** → `ledger.shrink_by_fill(plan_id, fill_notional)`（你的 fill 回调已有）。
* **冷启动**：若进程重启，Reconciler 会**领养**券商侧 OCO 子单并恢复 `plan.oco` 映射，避免“幽灵”或“孤儿”。

## G) 回放/自测脚本（10 分钟验收）

1. **首次成交即挂**

   * plan.pos_qty: 0→+100（模拟 fill）→ 看到 2 张挂单：TP(LMT)、SL(STP_LMT)，`oco_place_total{tp,sl}`+1。
2. **部分成交比例调**

   * 继续 fill +50 → `modify qty=150`；再减仓 -70 → `modify qty=80`；`oco_modify_total{field=qty}`统计正确。
3. **止盈触发清理**

   * 模拟 TP 子单 `Filled` → 另一侧 SL 被 `cancel()`，`oco_cancel_total{reason=oco_tp_filled}`+1，计划闭环。
4. **时间止损**

   * 配置 `time_stop_s=30`，成交后 30s 自动 `IOC` 平仓，`oco_time_stop_total`+1。
5. **反手编舞**

   * 持有 +100，多头 → 反转到 -200：

     * 暂停新意图 → 取消 OCO → `flatten` +100 → 下新进 -200 → 首次成交挂新的 OCO；
     * `reverse_steps_total{flatten,entry}`统计出现。
6. **异常恢复**

   * 在反手流程中模拟 `cancel` 返回 pacing（错误矩阵退避），不会风暴；最终撤成并继续流程。

## H) 与前 3 步协同（关键一致性）

* **Reg-Lite**：OCO 的 LMT/STP_LMT 价格都先过 Reg-Lite（tick/LULD/SSR/围栏），**不会**挂违规保护。
* **Error Matrix**：OCO 的改价/撤单遇到 pacing/价格越界，会 **fix/退避**，避免“改单风暴”。
* **Reservation WD**：若 OCO 单异常挂着且 TTL 超时 → 看门狗走 `cancel()`，撤掉后释放预留，**不会卡住资金**。
