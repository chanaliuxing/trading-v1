# 🧭 P5 概要（你将获得什么）

**目标**：把行情从 IBKR **tick/秒级**稳定为 **250ms 聚合**的准实时流（含历史回填、网络抖动容错），并产出 1s/5s/10s/1m 多级 bar；策略决策**每策略独立节奏**（≥5s），并有“数据不够就跳过”的**就绪门**。

**关键模块**

* **Ingress**：IBKR tick→微批缓冲（Redis ring buffer），去重/时间单调校正。
* **Aggregator**：事件时间 250ms 滚动窗 + **水位线/迟到容忍**（如 1.5–3s）；派生 1s/5s；统一 **idempotent key = (symbol, window_end, source, ver)**。
* **Backfill**：开盘前/断流后，走 IBKR 历史接口回填至 CH/Redis，保证连续。
* **Features**：增量计算（EMA/ATR/RSI 等）+ “**数据就绪门**”（窗口不足→该策略本次跳过）。
* **Scheduler**：**每策略独立 cadence**（5s/10s/20s/1m 可调），有 TTL/防抖；若上游落后→自动放慢。
* **存储**：CH 表 `bars_250ms / bars_1s / bars_5s / features_5s`；PG 仍只管交易类。
* **监控**：发布滞后、缺窗率、乱序率、补写量、Redis backlog、CPU/GC。

**P5 退出标准（先记着）**

* 99p **bar 发布滞后 < 1.0s**（250ms 窗口 + 迟到修正），**缺窗率 < 0.1%**；
* 开盘前**历史补写完成**（近 N 分钟可依配置）；
* 策略层“**数据就绪门**”生效（不足不决策）；
* 与 IBKR TWS 图对比：1m 聚合误差 < 1 tick/1% 以内（择其严者）。
