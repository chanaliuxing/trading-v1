IBKR tick → Redis 桶聚合（watermark/emit buffer）→ Kafka `md.bar.5s.v2`（准实时）＋ `md.bar.5s.repair.v1`（迟到修复）→（你已有 CH Writer 消费写 ClickHouse）。不生成文件，全部贴出来即可直接改造成你项目里的模块。

# 1) 设计要点（交易员关注点）

* **最小粒度**：接收 **~250ms** 级 tick（`last`/`bid`/`ask`/`size`），**按 5s** 聚合为 Bar。
* **抖动容忍**：`emit_buffer_ms=300`（可调），窗口结束后再等 300ms 接受迟到 tick，**减少回修**。
* **严格窗口**：窗口 = `[floor(ts/5s)*5s, floor(ts/5s)*5s + 5s)`，open/high/low/close/vol/vwap 按标准滚动更新。
* **迟到修复**：超过 `emit_buffer_ms` 后到达的 tick → 生成 **修复事件** `md.bar.5s.repair.v1`；下游 CH Writer 以“修复优先”**覆盖**旧 Bar（你用 ClickHouse ReplacingMergeTree 时，建议用**数值递增版本列**覆盖，见注）。
* **缺口探测**：发现**整段 5s 窗口缺失** → 发 `md.gap.v1`，供回补调度（IB 历史 API）。
* **RTH 标记**：会标 `rth`；你可以在策略 ReadyCheck 里用它过滤盘外噪声。
* **幂等**：Bar 的主键（`symbol, ts_start`），发送时带 `bar_seq`（递增版本），迟到修复使用更大 `bar_seq` 确保覆盖。
* **可恢复**：Redis 保存**当前窗口桶**和**watermark**；进程重启后能把上个未发出的桶补发/修复。

> **ClickHouse 提醒**：前面我们用过 `ReplacingMergeTree(event_id)` 的例子。更稳妥是用
> `ReplacingMergeTree(bar_seq UInt32)` 做**数值版本覆盖**（推荐改造）；下面聚合器会生成 `bar_seq`。

# 2) 可直接粘贴的聚合器骨架

> 依赖：`ib_insync`, `redis>=4`（异步版：`redis.asyncio`）, `aiokafka`, `pytz`, `python-dateutil`
> 运行方式：把类粘到你的服务里，填 `symbols`、IB 连接、Kafka/Redis 地址即可。

```python
import asyncio, json, time, uuid, math, contextlib
from dataclasses import dataclass
from typing import Dict, Optional, List, Tuple

# ------ 依赖 -------
from ib_insync import IB, Stock, util as ibutil
import redis.asyncio as aioredis
from aiokafka import AIOKafkaProducer
from dateutil import tz

UTC = tz.tzutc()

# ============ 配置 ============
@dataclass
class AggConfig:
    ib_host: str = "127.0.0.1"
    ib_port: int = 7497
    ib_client_id: int = 7
    symbols: Tuple[str,...] = ("AAPL","MSFT")
    emit_buffer_ms: int = 300          # 窗口结束后等待迟到tick的缓冲
    max_late_ms: int = 2000            # 超过这个就走 repair 事件
    redis_url: str = "redis://localhost:6379/0"
    redis_key_ns: str = "agg5s"        # redis key 前缀
    kafka_bootstrap: str = "localhost:9092"
    topic_bar: str = "md.bar.5s.v2"
    topic_repair: str = "md.bar.5s.repair.v1"
    topic_gap: str = "md.gap.v1"
    rth_only: bool = False             # 是否仅标记RTH（不丢弃）
    calendar_tz: str = "America/New_York"

# ============ 工具 ============
def now_us(): return int(time.time()*1e6)

def floor_5s(ts_ms:int) -> int:
    return (ts_ms // 5000) * 5000

def vwap_update(sum_px_sz:float, sum_sz:float, px:float, size:float) -> Tuple[float,float]:
    return sum_px_sz + px*size, sum_sz + size

def is_rth(ts_epoch_sec: float, mkt_tz: str) -> bool:
    # 简化：标记RTH（9:30-16:00 ET，周一至周五），节假日由下游修正
    from datetime import datetime, time as dtime
    dt = datetime.fromtimestamp(ts_epoch_sec, tz=tz.gettz(mkt_tz))
    if dt.weekday()>4: return False
    return dtime(9,30) <= dt.timetz().replace(tzinfo=None) <= dtime(16,0)

# ============ 聚合桶结构 ============
@dataclass
class BarBucket:
    symbol: str
    ts_start_ms: int
    ts_end_ms: int
    open: Optional[float] = None
    high: Optional[float] = None
    low: Optional[float] = None
    close: Optional[float] = None
    vol: float = 0.0
    vwap_num: float = 0.0
    vwap_den: float = 0.0
    trades: int = 0
    late_count: int = 0
    bar_seq: int = 0   # 递增版本（用于覆盖）

    def on_trade(self, px: float, size: float):
        if px is None or size is None or size <= 0: return
        if self.open is None: self.open = px
        self.high = px if self.high is None else max(self.high, px)
        self.low  = px if self.low is None else min(self.low, px)
        self.close = px
        self.vol += size
        self.vwap_num, self.vwap_den = vwap_update(self.vwap_num, self.vwap_den, px, size)
        self.trades += 1

    def to_msg(self, rth_flag: bool, source: str, calc_mode: str) -> dict:
        vwap = (self.vwap_num/self.vwap_den) if self.vwap_den>0 else (self.close or self.open or 0.0)
        return {
            "schema_v": 2,
            "metadata": {
                "event_id": str(uuid.uuid4()),
                "ts_us": now_us(),
                "producer": "agg5s",
            },
            "data": {
                "symbol": self.symbol,
                "ts_start": int(self.ts_start_ms/1000),   # 秒级时间戳（ClickHouse 可用 DateTime）
                "ts_end": int(self.ts_end_ms/1000),
                "open": round(self.open or 0.0, 6),
                "high": round(self.high or 0.0, 6),
                "low":  round(self.low  or 0.0, 6),
                "close":round(self.close or 0.0, 6),
                "vol": int(self.vol),
                "vwap": round(vwap, 6),
                "rth": bool(rth_flag),
                "source": source,           # 'AGG' | 'REPAIR'
                "calc_mode": calc_mode,     # 'realtime' | 'repair'
                "late_count": int(self.late_count),
                "bar_seq": int(self.bar_seq)
            }
        }

# ============ 核心聚合器 ============
class FiveSecondAggregator:
    def __init__(self, cfg: AggConfig):
        self.cfg = cfg
        self.ib = IB()
        self.redis = None
        self.producer: Optional[AIOKafkaProducer] = None
        self.bucket: Dict[Tuple[str,int], BarBucket] = {}   # (sym, ts_start_ms) -> bucket
        self.emit_schedule: Dict[Tuple[str,int], float] = {}# 何时允许发出（ms）
        self.last_bar_seq: Dict[str, int] = {}              # 每symbol的递增版本
        self.watermark_ms: Dict[str, int] = {}              # 每symbol的“已发窗口”时间线

    # ---------- 启停 ----------
    async def start(self):
        self.redis = await aioredis.from_url(self.cfg.redis_url, decode_responses=False)
        self.producer = AIOKafkaProducer(
            bootstrap_servers=self.cfg.kafka_bootstrap,
            acks="all", linger_ms=5, compression_type="lz4",
            value_serializer=lambda v: json.dumps(v).encode("utf-8"),
            key_serializer=lambda k: k.encode("utf-8") if k else None
        )
        await self.producer.start()
        await self.ib.connectAsync(self.cfg.ib_host, self.cfg.ib_port, clientId=self.cfg.ib_client_id, timeout=5.0)
        # 订阅合约
        for sym in self.cfg.symbols:
            contract = Stock(sym, 'SMART', 'USD')
            await self.ib.qualifyContractsAsync(contract)
            self.ib.reqMktData(contract, '', False, False)  # 简化：合并 tick；可开启 `apiTickList`
        self.ib.pendingTickersEvent += self._on_ticks
        # 恢复 Redis 状态
        await self._restore_state()

        # 定时检查/发出窗口
        asyncio.create_task(self._flusher())

    async def stop(self):
        if self.producer:
            with contextlib.suppress(Exception):
                await self.producer.stop()
        if self.ib.isConnected():
            with contextlib.suppress(Exception):
                await self.ib.disconnectAsync()
        if self.redis:
            with contextlib.suppress(Exception):
                await self.redis.close()

    # ---------- Tick 处理 ----------
    def _on_ticks(self, tickers):
        # ib_insync 在事件线程里回调；把数据扔给异步队列/任务
        asyncio.create_task(self._ingest_ticks(tickers))

    async def _ingest_ticks(self, tickers):
        now_ms = int(time.time()*1000)
        for t in tickers:
            sym = t.contract.symbol
            # 取 last/size（没有 last 就跳过；也可用 mid/bid/ask 估计）
            px = float(t.last) if t.last else None
            size = float(t.lastSize) if t.lastSize else None
            if px is None or not size or size <= 0:
                continue
            # IB 的 tick 没有严格的成交时间戳；用本地 now_ms（生产可用 RTVolume 或 Time&Sales）
            ts_ms = now_ms
            win_start = floor_5s(ts_ms)
            win_end = win_start + 5000
            key = (sym, win_start)
            b = self.bucket.get(key)
            if not b:
                b = BarBucket(sym, win_start, win_end)
                b.bar_seq = self.last_bar_seq.get(sym, 0) + 1
                self.last_bar_seq[sym] = b.bar_seq
                self.bucket[key] = b
                # 允许发出的时间点（窗口结束 + emit_buffer）
                self.emit_schedule[key] = win_end + self.cfg.emit_buffer_ms
            b.on_trade(px, size)
            # 迟到统计（落在已过 window 的 tick）
            if ts_ms > b.ts_end_ms + self.cfg.emit_buffer_ms:
                b.late_count += 1
            # 持久化到 Redis（防崩溃丢桶）
            await self._persist_bucket(b)

    # ---------- 窗口冲刷（发出 bar / repair / gap） ----------
    async def _flusher(self):
        while True:
            await asyncio.sleep(0.05)
            now_ms = int(time.time()*1000)
            to_emit = [(k,b) for k,b in list(self.bucket.items()) if self.emit_schedule.get(k, 1e18) <= now_ms]
            for key, b in to_emit:
                # 发准实时 Bar
                rth_flag = is_rth(b.ts_end_ms/1000.0, self.cfg.calendar_tz) if self.cfg.rth_only else True
                msg = b.to_msg(rth_flag, source="AGG", calc_mode="realtime")
                await self._kafka_send(self.cfg.topic_bar, f"{b.symbol}:{b.ts_start_ms}", msg)
                self.watermark_ms[b.symbol] = max(self.watermark_ms.get(b.symbol, 0), b.ts_end_ms)
                # 清理内存桶，但保留最近2个窗口以便迟到修复比对
                self.bucket.pop(key, None)
                self.emit_schedule.pop(key, None)
                await self._delete_bucket(b)

            # 迟到修复：遍历最近若干窗口，若有迟到 tick 导致 OHLC 变化，可发 repair
            # 简化策略：我们只在“收到迟到tick时”即时发 repair；这里可再做扫尾
            # 缺口探测：若某symbol watermark与当前时间差> N*5s 且期间无bar，则发 gap 事件
            for sym in self.cfg.symbols:
                wm = self.watermark_ms.get(sym)
                if not wm: continue
                if now_ms - wm > 20_000:  # 20s 没有bar
                    gap = {
                        "schema_v":1,"metadata":{"event_id":str(uuid.uuid4()),"ts_us":now_us(),"producer":"agg5s"},
                        "data":{"symbol":sym,"last_bar_ts":int(wm/1000),"now_ts":int(now_ms/1000),"reason":"no_bar_20s"}
                    }
                    await self._kafka_send(self.cfg.topic_gap, sym, gap)
                    # 防抖：记录一下，避免每次都发
                    self.watermark_ms[sym] = now_ms  # 或者设置一个“gap_sent_until”

    # 当超过 emit_buffer 后仍有落入旧窗口的 tick（在 _ingest_ticks 中 late_count>0），这里立即发 repair
    async def emit_repair(self, b: BarBucket):
        rth_flag = is_rth(b.ts_end_ms/1000.0, self.cfg.calendar_tz) if self.cfg.rth_only else True
        # 递增 bar_seq 保证覆盖
        b.bar_seq = self.last_bar_seq.get(b.symbol, b.bar_seq) + 1
        self.last_bar_seq[b.symbol] = b.bar_seq
        msg = b.to_msg(rth_flag, source="REPAIR", calc_mode="repair")
        await self._kafka_send(self.cfg.topic_repair, f"{b.symbol}:{b.ts_start_ms}", msg)
        await self._persist_bucket(b)

    # ---------- Redis 持久化 ----------
    def _bucket_key(self, b: BarBucket) -> str:
        return f"{self.cfg.redis_key_ns}:bucket:{b.symbol}:{b.ts_start_ms}"
    def _wm_key(self, sym:str) -> str:
        return f"{self.cfg.redis_key_ns}:wm:{sym}"

    async def _persist_bucket(self, b: BarBucket):
        key = self._bucket_key(b)
        payload = json.dumps({
            "ts_start_ms": b.ts_start_ms, "ts_end_ms": b.ts_end_ms,
            "open": b.open, "high": b.high, "low": b.low, "close": b.close,
            "vol": b.vol, "vwap_num": b.vwap_num, "vwap_den": b.vwap_den,
            "trades": b.trades, "late_count": b.late_count, "bar_seq": b.bar_seq
        }).encode("utf-8")
        await self.redis.set(key, payload, ex=30)  # 30s TTL
        await self.redis.set(self._wm_key(b.symbol), str(b.ts_end_ms).encode("utf-8"), ex=600)

    async def _delete_bucket(self, b: BarBucket):
        await self.redis.delete(self._bucket_key(b))

    async def _restore_state(self):
        # 恢复 watermark；桶不恢复也无所谓（窗口很短）
        for sym in self.cfg.symbols:
            v = await self.redis.get(self._wm_key(sym))
            if v:
                try: self.watermark_ms[sym] = int(v.decode("utf-8"))
                except: pass

    # ---------- Kafka 发送 ----------
    async def _kafka_send(self, topic:str, key:str, msg:dict):
        await self.producer.send_and_wait(topic, key=key, value=msg)
```

> 说明：
>
> 1. **迟到修复**：我在 `_ingest_ticks` 里给 `BarBucket.late_count` 计数；当检测到 tick 落入**已过窗口**并且**超过 buffer**，你可以直接 `await self.emit_repair(b)`（为简洁上面留了注释位，按需要调用）。
> 2. **缺口探测**：`_flusher` 里用 `watermark` 粗检 20s 无 bar，发 `md.gap.v1` 让回补调度去跑 IB 历史接口。
> 3. **版本覆盖**：每个 symbol 维护 `last_bar_seq`，每次生成/修复都递增；CH 写入时用 `bar_seq` 做 ReplacingMergeTree 的版本列确保覆盖。

# 3) CH Writer 与修复消费（简要规范）

* 消费 `md.bar.5s.v2` 与 `md.bar.5s.repair.v1`，两者写**同一张表** `qsys.bar_5s_v2`：

  * 主键：`(symbol, ts_start)`；
  * **版本列**：`bar_seq UInt32`；
  * ReplacingMergeTree **用 `bar_seq` 作为版本**（推荐替换我们之前用的 `event_id` 做版本）。
* 修复消息（`source="REPAIR", calc_mode="repair"`）由于 `bar_seq` 更大，自动覆盖。
* `late_count` 可统计迟到质量。

表定义（建议替换版）：

```sql
CREATE TABLE qsys.bar_5s_v2
(
  symbol LowCardinality(String),
  ts_start DateTime,
  ts_end   DateTime,
  open Float64, high Float64, low Float64, close Float64,
  vol UInt64, vwap Float64,
  rth UInt8, source LowCardinality(String),
  calc_mode LowCardinality(String),
  late_count UInt16,
  bar_seq UInt32     -- 版本列：越大越新
)
ENGINE = ReplacingMergeTree(bar_seq)
PARTITION BY toDate(ts_start)
PRIMARY KEY (symbol, ts_start)
ORDER BY (symbol, ts_start)
SETTINGS index_granularity=8192;
```

# 4) 回补调度（缺口→历史拉取→补写）——执行流程（简化）

1. 消费 `md.gap.v1`：`{symbol, last_bar_ts, now_ts, reason}`
2. 调用 IB 历史 API（或你的历史源）拉取 `[last_bar_ts, now_ts]` 的 **5s** Bar（或 tick→本地聚合），做**限速**防 ban。
3. 逐条写入 Kafka `md.bar.5s.repair.v1`（或直接 CH），`bar_seq = 当前 seq + 1`，`calc_mode='backfill'`。
4. CH Writer 统一落库覆盖。

> **熔断**：连续 N 次历史调用超时或错误，暂停 M 分钟；**并发**控制每账户 ≤2。
