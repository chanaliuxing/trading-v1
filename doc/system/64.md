好，进入**第 11 步：动态资金配额（cap）与风险预算曲线**——把“每策略资金池、每标的上限、下单强度”做成**可度量、可回滚、可审计**的自适应系统（与前 1–10 步无缝对接）。下面是**完整规范 + 计算公式 + SQL 与控制器骨架**（直接可粘贴用，仍不生成文件）。

# 1) 目标与边界

**目标**

* 让每个策略与每个标的的**可用资金上限**、**下单强度/风险预算**随**波动、业绩与回撤**按规则**自动调节**；
* **每策略独立**（不同 cadence 与权重），**互不影响**；与 **Reservation Ledger / Arbiter** 实时联动；
* 有**速率限制、冷却期、回退**，避免“追涨杀跌”的**顺周期风险**。

**不变约束（硬护栏）**

* 永不超过治理层静态上限：`cap_usd_static`、`per_symbol_cap_static`；
* 不下穿**当前已占用**（不强平，采用“**只减不增**/bleed-down”策略）；
* 任一时间点，**变更幅度 ≤ 10–20%/5min**（策略可配）；
* 任何自动降档由**回撤恢复**或**人工复位**后方可升档（带**冷却期**）。

# 2) 架构与数据流

```
ClickHouse 指标视图  →  Cap Orchestrator（计算建议） →  预检/速率限制/冷却
                                                     →  提交到 RiskService.set_strategy_caps()

                                                     →  审计/可观测（caps_audit）
```

* **Cap Orchestrator**：独立后台服务（与第 10 步 Rollout Controller 并列）。
* **生效原则**：对**新增意图**立即生效；若现有持仓>新上限 → **停止加仓/只允许减仓**，并按“bleed-down”政策渐退。

# 3) 指标定义（输入信号）

> 统一从 CH 计算；窗口与去噪都可配置。

* **波动率**

  * `σ_30m`：5s 收益（`ret_5s = log(close_t/close_{t-1})`）做 **EWMA**（λ=0.94）/或标准差；
  * `ATR_14`：来自 `features_*`；
* **业绩/质量**

  * `E[P&L]` / `Var[P&L]`：近 `W_trades`（如 100 笔）逐笔收益期望与方差；
  * **PSR（Probabilistic Sharpe Ratio）**：去偏的稳健指标（不要求你实现精确公式，可近似 `Sharpe / sqrt(max(1,n-1))`）；
  * `win_rate_lookback`、`avg_gain/avg_loss`；
* **风险状态**

  * `DD_60m`（近 60 分钟峰谷最大回撤）、`DD_day`（当日回撤）；
* **流动性/参与率**

  * `mkt_volume_5m`、`participation_5m = my_traded_5m / mkt_volume_5m`；
* **数据质量**

  * `qscore_avg_5m`、缺口率（gap_ratio）。

# 4) 动态配额规则（三层叠加）

## 4.1 层 0：治理静态上限（硬顶）

* `cap_usd_static`（策略）与 `per_symbol_cap_static`（标的硬顶）来自配置/审批。

## 4.2 层 1：风险均衡（逆波动/风险平价）

* **目标**：用**逆波动**分配策略资金，保证等风险贡献。
* **权重**：

  * `w_i^vol ∝ 1 / max(σ_i, σ_floor)`；
  * **行业/相关性因子（可选）**：添加 `Σ^{-1}` 的近似（去相关），这里先给简版：`w_i^rp ∝ w_i^vol`；
* **归一**：`w_i = w_i^rp / Σ w_j^rp`；
* **策略级 cap**：`cap_strategy_eff = cap_usd_static * f_regime(σ_port, DD)`，见 4.3；
* **标的 cap**：`cap_symbol_target_i = clamp(w_i * cap_strategy_eff, floor_i, per_symbol_cap_static)`

  * `floor_i`：防止过小（如 $2k），保证最小建仓粒度。

## 4.3 层 2：业绩与回撤的动态缩放（策略整体倍率）

定义**动态倍率** `M ∈ [M_min, M_max]` 作用于 `cap_strategy_eff`：

* **波动/回撤抑制**（任取其低者）

  * `g_vol = clip(σ_target / σ_real, 0.5, 1.0)`（σ_real 高于目标则降档）
  * `g_dd = piecewise(DD_day)`：

    * `DD_day < 0.5% → 1.0`
    * `0.5–1.0% → 0.7`
    * `>1.0% → 0.4`（并进入**冷却**）
* **业绩提振（保守）**

  * 采用**半 Kelly**近似： `f* ≈ (E / Var) / 2`，以 `E,Var` 取近 100 笔逐笔；
  * 转换为倍率：`g_edge = clip(1 + k * f* , 0.8, 1.2)`（`k` 小于 1，防止过度）；
* 组合：`M = min(g_vol, g_dd) * g_edge`，再施加**速率限制**与**冷却期**（见 6）。

**最终：**

* `cap_strategy_final = cap_usd_static * M`
* `cap_symbol_final_i = clamp(w_i * cap_strategy_final, floor_i, per_symbol_cap_static)`

> **说明**：这样既避免顺周期（回撤降档）又允许在稳健期小幅提档；所有倍率**单调有界**。

# 5) ClickHouse 计算视图（核心 SQL）

## 5.1 5s 收益与 EWMA 波动（近 30 分钟）

```sql
WITH ret AS (
  SELECT symbol, ts_end,
         log(close/lagInFrame(close,1) OVER (PARTITION BY symbol ORDER BY ts_end)) AS r
  FROM bars_5s
  WHERE ts_end > now() - INTERVAL 40 MINUTE
),
ewma AS (
  SELECT symbol, ts_end,
         sumExpWeighted(r*r, 0.94) OVER (PARTITION BY symbol ORDER BY ts_end ROWS BETWEEN 120 PRECEDING AND CURRENT ROW) AS v_ewma
  FROM ret
)
SELECT symbol,
       sqrt(anyLast(v_ewma)) AS sigma_30m
FROM ewma
GROUP BY symbol;
```

## 5.2 近 60 分钟回撤（策略级，基于 `pnl_pos_5s`）

```sql
WITH pnl AS (
  SELECT ts_end, strategy_id,
         sum(mtm + upl) OVER (PARTITION BY strategy_id ORDER BY ts_end ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS nav
  FROM pnl_pos_5s
  WHERE ts_end > now() - INTERVAL 1 DAY
),
dd AS (
  SELECT strategy_id, ts_end, nav,
         max(nav) OVER (PARTITION BY strategy_id ORDER BY ts_end ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS peak
  FROM pnl
)
SELECT strategy_id,
       max((peak - nav)/nullIf(peak,0)) FILTER (WHERE ts_end > now() - INTERVAL 60 MINUTE) AS dd_60m,
       max((peak - nav)/nullIf(peak,0)) FILTER (WHERE toDate(ts_end)=toDate(now())) AS dd_day
FROM dd
GROUP BY strategy_id;
```

## 5.3 近 100 笔逐笔期望/方差（策略或策略+标的）

```sql
WITH last100 AS (
  SELECT strategy_id, symbol, ts, realized_pnl
  FROM pnl_fills
  WHERE ts > now() - INTERVAL 5 DAY
  ORDER BY ts DESC
  LIMIT 100 BY strategy_id, symbol
)
SELECT strategy_id, symbol,
       avg(realized_pnl) AS E_pnl,
       varSamp(realized_pnl) AS Var_pnl,
       count() AS n
FROM last100
GROUP BY strategy_id, symbol;
```

> PSR 近似可由 `Sharpe = E/√Var` 与 `n` 得到一个下限（例如 `Sharpe_adj = Sharpe * sqrt( (n-1)/n )`），用于 gating。

# 6) Orchestrator 控制器（骨架）

```python
# -*- coding: utf-8 -*-
import asyncio, time, math
from dataclasses import dataclass
from typing import Dict, List

@dataclass
class CapsPolicy:
    step_pct_limit: float = 0.1           # 5min 变更上限（10%）
    cooldown_min: int = 30                # 冷却期（回撤触发后）
    floor_usd: float = 2000               # 标的最小可用 cap
    sigma_target: float = 0.02            # 30m 目标波动（按 5s-σ 解释）
    g_edge_k: float = 0.2                 # 半Kelly缩放系数

class CapOrchestrator:
    def __init__(self, ch, risk, arbiter, ledger, audit, policy: CapsPolicy, logger, metrics):
        self.ch, self.risk, self.arb, self.ledger, self.audit = ch, risk, arbiter, ledger, audit
        self.p = policy; self.log = logger; self.m = metrics
        self.cooldown_until: Dict[str,int] = {}       # strategy_id -> epoch seconds
        self.last_caps: Dict[str,Dict[str,float]] = {}# strategy_id -> {symbol:cap}

    async def fetch_metrics(self, strategy_id: str, symbols: List[str]):
        # 从 CH 读 5.1/5.2/5.3 三个视图（可做物化视图）
        sigma = await self.ch.dict_sigma_30m(symbols)       # {sym: σ}
        dd = await self.ch.get_dd(strategy_id)              # {dd_60m, dd_day}
        perf = await self.ch.get_perf(strategy_id, symbols) # {sym: E, Var, n}
        return sigma, dd, perf

    def scaling_M(self, dd_day: float, sigma_port: float, E: float, Var: float, n: int, now_s:int, sid:str):
        g_vol = min(1.0, max(0.5, self.p.sigma_target / max(1e-9, sigma_port)))
        if dd_day < 0.005: g_dd = 1.0
        elif dd_day < 0.01: g_dd = 0.7
        else:
            g_dd = 0.4
            self.cooldown_until[sid] = max(self.cooldown_until.get(sid,0), now_s + self.p.cooldown_min*60)
        # 半Kelly近似
        g_edge = 1.0
        if Var > 1e-9 and n >= 30:
            f = (E/Var)/2.0
            g_edge = min(1.2, max(0.8, 1 + self.p.g_edge_k * f))
        M = min(g_vol, g_dd) * g_edge
        # 冷却期禁止上调
        if now_s < self.cooldown_until.get(sid, 0):
            M = min(M, 1.0)  # 不允许超过基线
        return max(0.2, min(1.2, M))       # 全局夹紧

    def rate_limit(self, old: float, new: float) -> float:
        limit = self.p.step_pct_limit
        max_up = old*(1+limit)
        max_dn = old*(1-limit)
        return min(max(new, max_dn), max_up)

    async def propose_caps(self, strategy_id:str, symbols:List[str], static_cap:float, sym_static_cap:Dict[str,float]):
        now_s = int(time.time())
        sigma, dd, perf = await self.fetch_metrics(strategy_id, symbols)
        # 组合波动（等权/或按上期权重），简化取中位数
        sigma_port = sorted([sigma.get(s,0.02) for s in symbols])[len(symbols)//2]
        # 业绩聚合（简化：全标的加总）
        E = sum(perf[s]["E"] for s in symbols if s in perf); Var = sum(perf[s]["Var"] for s in symbols if s in perf); n = sum(perf[s]["n"] for s in symbols if s in perf)

        M = self.scaling_M(dd["dd_day"], sigma_port, E, Var, n, now_s, strategy_id)
        cap_strategy_eff = static_cap * M

        # 风险平价权重（逆波动）
        inv = {s: 1.0/max(1e-6, sigma.get(s, 0.02)) for s in symbols}
        s_inv = sum(inv.values())
        w = {s: inv[s]/s_inv for s in symbols}
        # 目标标的上限
        caps = {}
        for s in symbols:
            raw = w[s] * cap_strategy_eff
            floor = self.p.floor_usd
            hard = sym_static_cap.get(s, cap_strategy_eff)
            caps[s] = min(max(raw, floor), hard)

        # 速率限制 & bleed-down 保护
        last = self.last_caps.get(strategy_id, {})
        eff = {}
        for s in symbols:
            if s in last:
                eff[s] = self.rate_limit(last[s], caps[s])
                # 若现有占用 > eff，标注只减不增
                used = await self.ledger.used(strategy_id, s)  # 当前占用（绝对市值或预留）
                if used > eff[s]:
                    eff[s] = used       # 不强平；通过 Arbiter/Reserve 停加仓逐步回落
            else:
                eff[s] = caps[s]
        return cap_strategy_eff, eff

    async def apply(self, strategy_id, cap_strategy_eff, per_symbol_caps):
        await self.risk.set_strategy_caps(strategy_id, cap_strategy_eff, per_symbol_caps)
        await self.arb.set_symbol_caps(strategy_id, per_symbol_caps)
        await self.audit.record(strategy_id, cap_strategy_eff, per_symbol_caps, reason="auto")
        self.last_caps[strategy_id] = per_symbol_caps

    async def loop(self):
        while True:
            try:
                for strat in await cfg.strategies():  # 从配置/DB 获取上线策略与静态上限
                    sid = strat.id; syms = strat.symbols
                    cap_eff, per_sym = await self.propose_caps(sid, syms, strat.cap_usd_static, strat.per_symbol_cap_static)
                    await self.apply(sid, cap_eff, per_sym)
                    self.log.info(f"[cap] {sid} cap_eff={cap_eff:.0f} per_sym={per_sym}")
                    self.m.cap_updates_total.inc()
            except Exception as e:
                self.log.exception(f"[cap] error: {e}")
            await asyncio.sleep(300)  # 每 5 分钟评估一次
```

# 8) 与交易链路对接细节

* **Reservation Ledger**：使用 `per_symbol_caps` 作为**入场前**的**配额检查与预留上限**；
* **Arbiter**：对同标的不同策略，取**全局最小 cap**或按**优先级**裁剪（不抢占模式下更保守）；
* **Bleed-down**：若 cap 下调低于**当前占用**，**不强平**；禁止新开/加仓，仅允许减仓/保护单被动触发；
* **回退**：当 `DD_day` 触发最低档时，控制器写入**暂停标志**至 StateBus，可自动进入 `PAUSED`（参考第 10 步）。

* `cap_cooldown_active{strategy_id}`（冷却期标志）

# 10) 回测与上线验收

**离线回测（强烈建议）**

* 用历史 `bars_5s/pnl_fills` 回放计算视图，离线运行 Orchestrator，得到 `caps_timeline`；
* 在回测撮合上施加这些 caps，比较**收益/回撤/参与率**与**静态 cap**对照；
* 验收门槛（示例）：`maxDD ↓ ≥10%` 且 `PNL 年化不下降 > 5%`、`参与率不过阈值`。

**金丝雀上线**

* 仅 1–2 个标的开启动态 cap（其余静态），速率上限**设 5%/5min**，冷却**60min**；
* 1–2 天稳定后放开到全标的、再逐步放宽速率限制。

---

# 11) 风险提示与反模式

* **顺周期放大**：仅按收益提升 cap 会放大尾部风险 → 必须搭配 `g_vol` 与回撤冷却；
* **噪声升档**：交易数过少（`n<30`）时禁止用 `g_edge`；
* **跃迁过快**：没有速率限制/冷却会导致上下跳变；
* **误伤流动性**：过度逆波动可能把低波动但低流动性标的分到过多名额 → 加上**参与率阈值**和**最小成交量过滤**。

## 小结

这套“**动态资金配额与风险预算曲线**”让你的系统：

* 在**高波动/高回撤**时**自动收敛**，在稳健期**温和放量**；
* 每策略、每标的**独立**、**速率受限**、**可回滚**；
* 与 **Reservation / Arbiter / Rollout** 无缝联动，**不强平、只减不增**地实现平滑过渡。
