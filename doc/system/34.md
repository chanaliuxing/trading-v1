# 一、现状复盘：能否端到端跑通？

**我们已提供/改造的关键模块：**

1. **行情侧**

* 5s 聚合器（支持 IB **Time&Sales** 时间戳，迟到修复、缺口上报、Prom 指标）。
* **历史回补服务**（IB 历史→Kafka 修复→CH 覆盖，令牌桶 + 熔断 + 幂等）。
* **ClickHouse Writer**（你已有，已补指标）。
* **MarketDataFacade（CH 读层）**（去重后再聚合、TTL 缓存，策略读取 5s/1m/Ns）。

2. **策略与执行侧**

* **策略引擎**节拍器（每策略独立 5/10/60s，可自动“节奏降噪”）。
* **追踪止损策略模块**（ATR / 通道 / 斜率 / 组合器 + 单向收紧 + Hysteresis）。
* **执行安全内核**（首填即挂 OCO、部分成交按比例调整、Stop-MKT 兜底）。
* **CRS 强一致撤改状态机**（取消/改单“直到权威完成”+ 巡检 + 领养）。

3. **可观测性**

* 三端 Prom 指标：聚合器 / CH Writer / 策略引擎 / 执行内核 / 回补器，附 Grafana 查询建议。

**还差哪些，导致现在“不能完全跑通”？（阻断项）**

* 🔴 **组合账本 / 资金池（Portfolio & Capital Ledger）服务**：
  需要一个**权威实时账本**来维护：账户现金、IB 保证金、每策略资本池、持仓与均价、已实/未实现 PnL、订单级资金**预留/释放**。
  没它，风控无法在下单前做“可用资金→预留→下单→终态释放”的闭环，**“每策略资金上限”也无法落地**。

* 🔴 **RiskService 最小路径**：
  起码要把策略引擎发出的“OrderIntent”转成“Approved/Rejected（并在通过时**先预留资金**）”。
  你原仓库已有 `risk_service.py / risk_sector_tracker.py / phase5_riskd.py`，但与我们新接口要**对齐 Topic+字段**。

* 🔴 **IB 适配器的真实实现**：
  我提供了 `IBAdapter` 接口与 Mock；需要你将其对接到 ib_insync 或你已有的 IB 网关（含 `orderRef/ocaGroup` 的正确映射、状态/成交回流到 Kafka）。

**重要但不阻断（建议尽快做）：**

* 🟡 **Postgres DDL 与幂等约束**：orders/fills/reservations 三张核心表的**唯一约束**（idempotency_key、(order_id, ts, qty, price) 去重）。
* 🟡 **Topic 契约固定版**：`risk.decision.v2 / exec.order.status.v2 / exec.fill.v2 / broker.account.v1 / md.bar.5s.v2 / md.bar.5s.repair.v1` 的**字段清单**。
* 🟡 **RTH/交易日历**：所有“是否 RTH”的判断统一用一个组件（避免聚合器/策略/风控口径不一致）。
* 🟡 **Dead-letter（DLQ）**：Writer、内核、回补的不可恢复错误统一送 DLQ，便于排障与补数。
* 🟡 **冷启动领养 2.0**：CRS 现在能按 `order_ref` 领养；再加“模糊匹配”（symbol+方向+价位+时间窗）容忍老单没 `orderRef` 的情况。

**可迭代（不影响 MVP）：**

* ⚪ 统一配置中心（热更新 + 参数哈希）。
* ⚪ 行业/板块风险与“策略组额度”上限。
* ⚪ /ready 探针 + 滚动升级剧本。
* ⚪ Sandbox（离线回放/单测）——我后面可以给。

> 结论：**差“组合账本 & 资金池”和“风控最小路径 + IB 真实适配”。**
> 我先把**组合账本**贴出来；风控最小路径你可以先沿用现有代码，按我给的 Topic 契约打一个“透传 + 预留”的最小版。

# 二、先补“组合账本 & 资金池（Portfolio & Capital Ledger）”——可直接粘贴骨架

## 1) Kafka 约定（与现有命名对齐）

* 输入：

  * `exec.fill.v2`：`{data:{order_id,symbol,side,qty,price,ts_us,strategy_id}}`
  * `exec.order.status.v2`：`{data:{order_id,status,symbol,side,qty,price?,ts_us}}` （用于终态释放）
  * `broker.account.v1`：`{data:{cash, initial_margin, maintenance_margin, currency, ts_us}}`
* 输出：

  * `portfolio.snapshot.v1`（周期性/事件触发快照，供引擎/风控/仪表盘）
  * `risk.capital.event.v1`（预留/释放/拒绝等账本事件）

## 2) Postgres 极简 DDL（幂等关键）

```sql
-- strategies：每策略资金池上限
CREATE TABLE strategies(
  strategy_id TEXT PRIMARY KEY,
  capital_limit NUMERIC(18,2) NOT NULL,
  notes TEXT
);

-- reservations：下单前冻结（预留），终态释放
CREATE TABLE reservations(
  res_id UUID PRIMARY KEY,
  strategy_id TEXT NOT NULL,
  order_ref TEXT NOT NULL,                  -- 引擎/内核贯穿的 idempotency_key
  amount NUMERIC(18,2) NOT NULL,
  state TEXT NOT NULL CHECK (state IN ('HELD','RELEASED','COMMITTED','REJECTED')),
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE(strategy_id, order_ref)            -- 幂等：同一单只会预留一次
);

-- fills：去重唯一索引（防重复回放）
CREATE TABLE fills(
  order_id BIGINT,
  ts_us BIGINT,
  qty NUMERIC(18,6),
  price NUMERIC(18,6),
  strategy_id TEXT,
  symbol TEXT,
  PRIMARY KEY(order_id, ts_us, qty, price)
);

-- positions：可做派生视图/物化；也可实时维护一张快照表
CREATE TABLE positions(
  strategy_id TEXT,
  symbol TEXT,
  qty NUMERIC(18,6) NOT NULL,
  avg_px NUMERIC(18,6) NOT NULL,
  realized NUMERIC(18,2) NOT NULL DEFAULT 0,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY(strategy_id, symbol)
);
```

> 你也可以把 `orders` 表留给执行内核使用（带 `idempotency_key UNIQUE`），但账本闭环最关键的是 `reservations` 与 `fills`。

## 3) 可运行骨架（异步，含预留/释放/承诺 + PnL/仓位计算 + 指标）

```python
import asyncio, os, time, json, uuid, contextlib
from dataclasses import dataclass
from typing import Dict, Optional
from aiokafka import AIOKafkaConsumer, AIOKafkaProducer
import asyncpg
from prometheus_client import Counter, Gauge, Histogram, start_http_server

# ---------- 指标 ----------
start_http_server(int(os.getenv("PORTF_METRICS_PORT","9106")))
PM = dict(
  pf_reserve_req = Counter("pf_reserve_requested_total","reserve requested"),
  pf_reserve_ok  = Counter("pf_reserve_ok_total","reserve ok"),
  pf_reserve_rej = Counter("pf_reserve_rejected_total","reserve rejected",["reason"]),
  pf_release     = Counter("pf_release_total","reserve released"),
  pf_commit      = Counter("pf_commit_total","reserve committed"),
  pf_pnl_unreal  = Gauge("pf_unrealized_pnl","unrealized pnl",["strategy"]),
  pf_cap_avail   = Gauge("pf_capital_available","capital available",["strategy"]),
  pf_latency     = Histogram("pf_apply_latency_ms","apply fill/status latency")
)

# ---------- 配置 ----------
@dataclass
class PfCfg:
    kafka_bootstrap:str = os.getenv("KAFKA_BOOTSTRAP","localhost:9092")
    group_id:str = os.getenv("PF_GROUP","portfolio-v1")
    topic_fill:str = os.getenv("TOPIC_FILL","exec.fill.v2")
    topic_status:str = os.getenv("TOPIC_STATUS","exec.order.status.v2")
    topic_acct:str = os.getenv("TOPIC_ACCT","broker.account.v1")
    topic_snapshot:str = os.getenv("TOPIC_SNAP","portfolio.snapshot.v1")
    topic_event:str = os.getenv("TOPIC_EVT","risk.capital.event.v1")
    pg_dsn:str = os.getenv("PG_DSN","postgres://user:pass@localhost:5432/trade")
    slip_bps:int = int(os.getenv("PF_SLIP_BPS","10"))      # 预留时的成本缓冲（bps）
    lot_mult:float = float(os.getenv("PF_LOT_MULT","1.0")) # 期权/期货可调
    snapshot_interval_s:int = int(os.getenv("PF_SNAP_SEC","5"))

# ---------- 内存镜像（权威仍以 PG 为准） ----------
class InMemState:
    def __init__(self):
        self.cash: float = 0.0
        self.initial_margin: float = 0.0
        self.maintenance_margin: float = 0.0
        self.cap_limit: Dict[str,float] = {}      # strategy_id→上限
        self.reserved: Dict[str,float] = {}       # strategy_id→已冻结
        self.pos: Dict[tuple, dict] = {}          # (strategy,symbol)→{qty,avg_px,realized}
        self.last_px: Dict[str,float] = {}        # symbol→last price for UPNL
    def cap_avail(self, sid:str) -> float:
        limit = self.cap_limit.get(sid, 0.0)
        realized = sum(v["realized"] for (s,_),v in self.pos.items() if s==sid)
        reserves = self.reserved.get(sid, 0.0)
        # 这里示例按“策略独立资金池”计算，不与账户级初始保证金耦合；若要全局耦合，可在这里扣减 IB 初保占用
        return limit + realized - reserves

# ---------- 主服务 ----------
class PortfolioService:
    def __init__(self, cfg:PfCfg):
        self.cfg=cfg
        self.pg: Optional[asyncpg.Pool]=None
        self.producer=None
        self.c_fill=None; self.c_status=None; self.c_acct=None
        self.s=InMemState()

    async def start(self):
        self.pg = await asyncpg.create_pool(self.cfg.pg_dsn, min_size=1, max_size=4)
        # 初始化策略上限
        async with self.pg.acquire() as con:
            rows = await con.fetch("SELECT strategy_id, capital_limit FROM strategies")
            self.s.cap_limit = {r["strategy_id"]: float(r["capital_limit"]) for r in rows}

        self.producer = AIOKafkaProducer(
            bootstrap_servers=self.cfg.kafka_bootstrap, acks="all", linger_ms=5, compression_type="lz4",
            value_serializer=lambda v: json.dumps(v).encode("utf-8"),
            key_serializer=lambda k: k.encode("utf-8") if k else None
        )
        await self.producer.start()

        self.c_fill = AIOKafkaConsumer(self.cfg.topic_fill, bootstrap_servers=self.cfg.kafka_bootstrap,
            group_id=self.cfg.group_id, value_deserializer=lambda b: json.loads(b.decode("utf-8")), auto_offset_reset="latest")
        self.c_status = AIOKafkaConsumer(self.cfg.topic_status, bootstrap_servers=self.cfg.kafka_bootstrap,
            group_id=self.cfg.group_id, value_deserializer=lambda b: json.loads(b.decode("utf-8")), auto_offset_reset="latest")
        self.c_acct = AIOKafkaConsumer(self.cfg.topic_acct, bootstrap_servers=self.cfg.kafka_bootstrap,
            group_id=self.cfg.group_id, value_deserializer=lambda b: json.loads(b.decode("utf-8")), auto_offset_reset="latest")
        await self.c_fill.start(); await self.c_status.start(); await self.c_acct.start()

        asyncio.create_task(self._loop_fill())
        asyncio.create_task(self._loop_status())
        asyncio.create_task(self._loop_acct())
        asyncio.create_task(self._loop_snapshot())

    async def stop(self):
        for c in (self.c_fill, self.c_status, self.c_acct):
            if c: with contextlib.suppress(Exception): await c.stop()
        if self.producer: with contextlib.suppress(Exception): await self.producer.stop()
        if self.pg: with contextlib.suppress(Exception): await self.pg.close()

    # ---------- 预留 API（给 RiskService 调用） ----------
    async def reserve(self, strategy_id:str, order_ref:str, est_cost_usd:float) -> bool:
        PM["pf_reserve_req"].inc()
        async with self.pg.acquire() as con:
            async with con.transaction():
                # 幂等：若已存在，直接视为 OK
                exists = await con.fetchval("SELECT 1 FROM reservations WHERE strategy_id=$1 AND order_ref=$2", strategy_id, order_ref)
                if exists:
                    PM["pf_reserve_ok"].inc(); return True
                # 检查可用资金
                avail = self.s.cap_avail(strategy_id)
                if est_cost_usd > avail:
                    PM["pf_reserve_rej"].labels(reason="insufficient").inc()
                    await con.execute("INSERT INTO reservations(res_id,strategy_id,order_ref,amount,state) VALUES($1,$2,$3,$4,'REJECTED')",
                                      uuid.uuid4(), strategy_id, order_ref, est_cost_usd)
                    await self._emit_evt("RESERVE_REJECTED", strategy_id, order_ref, est_cost_usd, {"avail":avail})
                    return False
                # 写入并更新内存
                await con.execute("INSERT INTO reservations(res_id,strategy_id,order_ref,amount,state) VALUES($1,$2,$3,$4,'HELD')",
                                  uuid.uuid4(), strategy_id, order_ref, est_cost_usd)
                self.s.reserved[strategy_id] = self.s.reserved.get(strategy_id,0.0) + est_cost_usd
                PM["pf_reserve_ok"].inc()
                await self._emit_evt("RESERVED", strategy_id, order_ref, est_cost_usd, {})
                return True

    async def release(self, strategy_id:str, order_ref:str, commit:bool):
        async with self.pg.acquire() as con:
            async with con.transaction():
                row = await con.fetchrow("SELECT amount,state FROM reservations WHERE strategy_id=$1 AND order_ref=$2 FOR UPDATE",
                                         strategy_id, order_ref)
                if not row: return
                amt = float(row["amount"]); st=row["state"]
                if st not in ("HELD","COMMITTED"): 
                    return
                # 内存释放
                self.s.reserved[strategy_id] = max(0.0, self.s.reserved.get(strategy_id,0.0)-amt)
                if commit:
                    PM["pf_commit"].inc()
                    await con.execute("UPDATE reservations SET state='COMMITTED' WHERE strategy_id=$1 AND order_ref=$2", strategy_id, order_ref)
                    await self._emit_evt("COMMITTED", strategy_id, order_ref, amt, {})
                else:
                    PM["pf_release"].inc()
                    await con.execute("UPDATE reservations SET state='RELEASED' WHERE strategy_id=$1 AND order_ref=$2", strategy_id, order_ref)
                    await self._emit_evt("RELEASED", strategy_id, order_ref, amt, {})

    # ---------- 消费 Fills：更新仓位与已实现 ----------
    async def _loop_fill(self):
        async for msg in self.c_fill:
            t0=time.time()
            d = msg.value["data"]
            oid=int(d["order_id"]); sym=d["symbol"]; side=d["side"].upper()
            qty=float(d["qty"]); px=float(d["price"]); sid=d.get("strategy_id") or "UNKNOWN"
            # PnL 与均价
            s = 1 if side=="BUY" else -1
            key=(sid,sym)
            p = self.s.pos.get(key) or {"qty":0.0,"avg_px":0.0,"realized":0.0}
            new_qty = p["qty"] + s*qty
            realized = p["realized"]
            if (p["qty"]>0 and s<0) or (p["qty"]<0 and s>0):
                # 减仓/平仓部分的已实现：按原均价计算
                close_qty = min(abs(p["qty"]), qty)
                sign = 1 if p["qty"]>0 else -1
                realized += (px - p["avg_px"])*sign*close_qty*self.cfg.lot_mult
            if new_qty == 0:
                avg_px = 0.0
            elif (p["qty"]==0) or (p["qty"]>0 and new_qty>0) or (p["qty"]<0 and new_qty<0):
                # 同向加仓：加权均价
                avg_px = ((abs(p["qty"])*p["avg_px"] + qty*px) / (abs(p["qty"])+qty))
            else:
                # 反转：余量以本次价为均价
                avg_px = px
            self.s.pos[key] = {"qty":new_qty,"avg_px":avg_px,"realized":realized}
            PM["pf_latency"].observe((time.time()-t0)*1000.0)

    # ---------- 消费订单状态：终态释放 ----------
    async def _loop_status(self):
        async for msg in self.c_status:
            d = msg.value["data"]
            st = d["status"].upper(); order_ref = msg.value.get("metadata",{}).get("idempotency_key")
            sid = d.get("strategy_id") or "UNKNOWN"
            if not order_ref: 
                continue
            # FILLED/CANCELLED/INACTIVE 都可释放（commit 的含义按你业务决定）
            if st in ("FILLED","CANCELLED","INACTIVE"):
                await self.release(sid, order_ref, commit=(st=="FILLED"))

    # ---------- 消费账户：更新现金/保证金 ----------
    async def _loop_acct(self):
        async for msg in self.c_acct:
            a = msg.value["data"]
            self.s.cash = float(a.get("cash") or 0.0)
            self.s.initial_margin = float(a.get("initial_margin") or 0.0)
            self.s.maintenance_margin = float(a.get("maintenance_margin") or 0.0)

    # ---------- 周期快照（给风控/引擎/看板） ----------
    async def _loop_snapshot(self):
        while True:
            await asyncio.sleep(self.cfg.snapshot_interval_s)
            snap = {
              "schema_v":1,
              "metadata":{"ts_us":int(time.time()*1e6),"producer":"portfolio"},
              "data":{
                "cash":self.s.cash,
                "initial_margin":self.s.initial_margin,
                "maintenance_margin":self.s.maintenance_margin,
                "strategies":{sid:{
                    "capital_limit": self.s.cap_limit.get(sid,0.0),
                    "reserved": self.s.reserved.get(sid,0.0),
                    "available": self.s.cap_avail(sid),
                    "positions":[{"symbol":sym,"qty":v["qty"],"avg_px":v["avg_px"],"realized":v["realized"]}
                                 for (s,sym),v in self.s.pos.items() if s==sid]
                } for sid in self.s.cap_limit.keys()}
              }
            }
            for sid in self.s.cap_limit.keys():
                PM["pf_cap_avail"].labels(strategy=sid).set(self.s.cap_avail(sid))
                # 估算未实现（需 last_price，可接 MarketDataFacade 或行情）
                upnl = 0.0
                for (s,sym),v in self.s.pos.items():
                    if s!=sid: continue
                    px = self.s.last_px.get(sym) or v["avg_px"]
                    sign = 1 if v["qty"]>0 else -1
                    upnl += (px - v["avg_px"])*sign*abs(v["qty"])*self.cfg.lot_mult
                PM["pf_pnl_unreal"].labels(strategy=sid).set(upnl)
            await self.producer.send_and_wait(self.cfg.topic_snapshot, key="portfolio", value=snap)

    async def _emit_evt(self, evt:str, sid:str, order_ref:str, amt:float, extra:dict):
        msg={"schema_v":1,"metadata":{"ts_us":int(time.time()*1e6),"producer":"portfolio"},
             "data":{"event":evt,"strategy_id":sid,"order_ref":order_ref,"amount":amt,"extra":extra}}
        await self.producer.send_and_wait(self.cfg.topic_event, key=f"{sid}:{order_ref}", value=msg)
```

**如何用：**

* 风控收到策略意图时：先估算下单名义金额（`est_cost = qty*price*(1+slip_bps)`），调用 `reserve(sid, order_ref, est_cost)` → 通过才把 `risk.decision.v2` 放行。
* 执行内核收到**终态**（Filled/Cancelled/Inactive）后，账本消费到 `exec.order.status.v2` 自动 `release(commit=...)`。
* 每策略资本上限：写入 `strategies(strategy_id, capital_limit)` 即生效。
* 账本输出 `portfolio.snapshot.v1`，策略引擎/看板/风控可直接消费。

# 三、把链路“跑通”的最小剧本（MVP）

1. **数据库**：建好上面的四张表；插入每个策略的 `capital_limit`。
2. **行情链路**：起聚合器（T&S）、CH Writer、回补器；CH 有连续 5s bar。
3. **Portfolio 服务**：起本账本服务（连 PG + Kafka）。
4. **策略引擎**：跑 1–2 个策略（5s/10s 不同节拍），用 MarketDataFacade 拉 CH。
5. **风控最小路径**：

   * 引擎发 `order.intent.v1` → 风控估算成本 → 调账本 `reserve` → 放行为 `risk.decision.v2`。
6. **执行安全内核**：消费 `risk.decision.v2` 下单，回流 `exec.order.status.v2 / exec.fill.v2`。
7. **观察面板**：聚合延迟、CH 写入、策略 p95、执行撤改/OCO、账本可用资金曲线。
