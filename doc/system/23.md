它满足：**每策略独立节奏(≥5s)、就绪检查智能跳过、只发一次的幂等决策、可热更参数、与我们已定的 Kafka/PG/CH/执行内核事件契约完全对齐**。

# Ⅰ. 单文件骨架（直接粘贴即可）

> 说明：这是一个**聚合的单文件**，包含：`StrategyAlgorithm` 基类、`Engine`、`Context`、`ReadyCheck`、`内存 Bus`、`简易 DAL stub`、以及**一个最小示例策略**（ORB 的极简触发）。
> 你已有自己的策略模板库时，只需删掉下面“示例策略”那段并在配置里指向你的模块路径即可。

```python
# ================== Strategy Engine v1 (IoC) ==================
# 依赖：Python 3.10+，异步；无三方库（便于先本地跑通）
# 把 Bus 换成你的 Kafka 适配层，把 DAL 换成 ClickHouse 实现即可上生产链路。

import asyncio, importlib, json, time, uuid, types
from dataclasses import dataclass, field
from collections import defaultdict, deque
from typing import Any, Dict, List, Optional

now_us = lambda: int(time.time()*1e6)

# ---------- 0) 事件契约（与全系统一致，简版） ----------
ENGINE_ORDER_TOPIC = "engine.order.request.v2"
MD_BAR5S_TOPIC     = "md.bar.5s.v2"

def make_idem_key(strategy_id, symbol):
    return f"ord:req:{strategy_id}:{symbol}:{uuid.uuid4()}"

# ---------- 1) 内存总线（先跑通；换 KafkaAdapter 即可） ----------
class Bus:
    def __init__(self): self._subs = defaultdict(list)
    def subscribe(self, topic:str) -> "asyncio.Queue":
        q = asyncio.Queue(); self._subs[topic].append(q); return q
    async def publish(self, topic:str, key:str, value:dict):
        for q in self._subs.get(topic, []):
            await q.put({"topic": topic, "key": key, "value": value})

# ---------- 2) 简易 DAL（ClickHouse Stub；换成真实现） ----------
class RingCache:
    def __init__(self, capacity=128): self._cap=capacity; self._dct={}; self._dq=deque()
    def get(self, k): return self._dct.get(k)
    def set(self, k, v):
        if k in self._dct: self._dq.remove(k)
        self._dct[k]=v; self._dq.append(k)
        if len(self._dq)>self._cap: old=self._dq.popleft(); self._dct.pop(old, None)

class CHDalStub:
    """把这层换成你 ClickHouse 的异步客户端实现（保持方法签名不变）"""
    def __init__(self): self.cache = RingCache()
    async def last_n(self, symbol:str, n:int, res:str='5s'):
        # 仅示例：真实实现应查询 ClickHouse，返回 pandas/ndarray/列表
        key=(symbol,n,res); v=self.cache.get(key); return v
    async def set_last_n_for_demo(self, symbol, rows, res='5s'):  # demo 辅助
        self.cache.set((symbol,len(rows),res), rows)
    async def features_intraday(self, symbol:str, fields:List[str], window:str='30m'):
        return None  # 替换为真实特征查询
    async def daily_snapshot(self, symbols:List[str], asof:str|None=None):
        return None

# ---------- 3) 策略作者基类 ----------
class StrategyAlgorithm:
    """策略作者只需继承并重写这些回调"""
    def initialize(self, ctx): pass
    def on_bar_5s(self, ctx, bar): pass
    def on_timer(self, ctx): pass
    def on_order_update(self, ctx, status): pass
    def on_fill(self, ctx, fill): pass
    def on_position_update(self, ctx, pos_snapshot): pass
    def on_shutdown(self, ctx): pass

# ---------- 4) 引擎注入的 ctx（API/就绪/下单/状态） ----------
class SizingHelper:
    def __init__(self, ctx): self.ctx=ctx
    def fixed_usd(self, notional_usd:float, price:float) -> float:
        if price<=0: return 0.0
        return round(notional_usd/price, 4)

class StrategyContext:
    def __init__(self, engine:"StrategyEngine", sid:str, config:dict, dal:CHDalStub, bus:Bus):
        self._engine = engine
        self.sid = sid
        self.config = config
        self.dal = dal
        self.bus = bus
        self._decision_open = False
        self._decision_id = None
        self._last_skip_reason = None
        self.state: Dict[str, Any] = {}           # 可持久化（引擎保存/恢复）
        self.metrics = engine.metrics_proxy(sid)  # 这里简单返回打印器；你可接 Prom
        self.logger  = engine.logger_proxy(sid)
        self.sizing  = SizingHelper(self)

    # --- 时间/工具 ---
    def now(self): return time
    def set_config(self, new_cfg): self.config = new_cfg

    # --- 数据读取（换成真实 DAL 后即可） ---
    async def history(self, symbol:str, window:str|None=None, res:str='5s', n:int|None=None):
        if n is not None: return await self.dal.last_n(symbol, n, res=res)
        # 简化：window->n 的换算交给 DAL 实现
        return None
    async def features(self, symbol:str, fields:List[str], at:str='now'):
        return await self.dal.features_intraday(symbol, fields)

    # --- 就绪守门/智能跳过 ---
    async def ready(self, symbol:str, need_5s:int=0, need_1m:int=0) -> bool:
        if need_5s>0:
            bars = await self.dal.last_n(symbol, need_5s, res='5s')
            if not bars or len(bars)<need_5s:
                self._last_skip_reason = "DATA_WINDOW_SHORT_5S"; return False
        if need_1m>0:
            bars = await self.dal.last_n(symbol, need_1m, res='1m')
            if not bars or len(bars)<need_1m:
                self._last_skip_reason = "DATA_WINDOW_SHORT_1M"; return False
        # 可加入更多：RTH/系统降级/风控暂停
        self._last_skip_reason = None
        return True

    def skip(self, reason:str):
        self._last_skip_reason = reason
        self.metrics["skips"] += 1
        self.logger(f"skip: {reason}")

    def skip_reason(self): return self._last_skip_reason

    # --- 决策回合生命周期：只发一次 ---
    def _begin_decision(self):
        self._decision_open = True
        self._decision_id = str(uuid.uuid4())
    def _end_decision(self):
        self._decision_open = False
        self._decision_id = None

    # --- 下单 API：生成 engine.order.request.v2 ---
    async def order_limit(self, symbol:str, side:str, qty:float, px:float, tags:List[str]|None=None, exec_overrides:dict|None=None):
        if not self._decision_open:
            self.logger("order_limit called outside of decision window; suppressed"); return
        if getattr(self, "_fired_once", False):
            self.logger("duplicate order suppressed in this decision"); self.metrics["dedup"] += 1; return
        idem = make_idem_key(self.sid, symbol)
        payload = {
            "schema_v": 2,
            "metadata": {
                "event_id": str(uuid.uuid4()), "ts_us": now_us(),
                "producer": "engine", "idempotency_key": idem,
                "decision_id": self._decision_id, "params_hash": self._engine.param_hash(self.sid)
            },
            "data": {
                "strategy_id": self.sid, "symbol": symbol, "side": side.upper(),
                "order_type": "LMT", "qty": float(qty), "limit_px": float(px),
                "stop_px": None, "tif": "DAY",
                "notional_hint_usd": abs(qty*px), "slippage_buffer_bps": int(self.config.get("exec_defaults", {}).get("slippage_buffer_bps", 8)),
                "tags": tags or [], "exec_overrides": exec_overrides or self.config.get("exec_defaults", {})
            }
        }
        await self.bus.publish(ENGINE_ORDER_TOPIC, key=f"{self.sid}:{symbol}", value=payload)
        self.metrics["orders"] += 1
        self._fired_once = True

    # 便捷别名
    async def order(self, *a, **k): return await self.order_limit(*a, **k)

    # --- 简易 logger/metrics 代理（可替换为真正 Prom/结构化日志） ---
    def __repr__(self): return f"<Ctx sid={self.sid}>"

# ---------- 5) 引擎主体 ----------
@dataclass
class StrategySpec:
    strategy_id: str
    module: str          # "pkg.mod.ClassName"
    symbols: List[str]
    cadence_s: int
    params: Dict[str, Any] = field(default_factory=dict)
    sizing: Dict[str, Any] = field(default_factory=dict)
    exec_defaults: Dict[str, Any] = field(default_factory=dict)

class StrategyEngine:
    def __init__(self, bus:Bus, dal:CHDalStub, specs:List[StrategySpec]):
        self.bus = bus; self.dal = dal; self.specs = {s.strategy_id: s for s in specs}
        self._workers: Dict[str, asyncio.Task] = {}
        self._instances: Dict[str, StrategyAlgorithm] = {}
        self._ctxs: Dict[str, StrategyContext] = {}
        self._params_hash: Dict[str, str] = {}
        self._bar_q = bus.subscribe(MD_BAR5S_TOPIC)
        self._metrics = defaultdict(lambda: {"orders":0, "skips":0, "dedup":0, "lat_ms":0.0})
        self._logger_prefix = "[ENGINE]"

    # ----- 工具接口 -----
    def metrics_proxy(self, sid): return self._metrics[sid]
    def logger_proxy(self, sid):
        def _log(msg): print(f"[{sid}] {msg}")
        return _log
    def param_hash(self, sid): return self._params_hash.get(sid, "NA")

    # ----- 生命周期 -----
    async def start(self):
        # 装载与实例化
        for sid, spec in self.specs.items():
            cls = self._import_class(spec.module)
            inst: StrategyAlgorithm = cls()
            ctx = StrategyContext(self, sid, self._spec_to_cfg(spec), self.dal, self.bus)
            inst.initialize(ctx)
            self._instances[sid] = inst; self._ctxs[sid] = ctx
            self._params_hash[sid] = self._calc_params_hash(ctx.config)
            # 每策略独立 worker
            self._workers[sid] = asyncio.create_task(self._worker_loop(sid))
        # 统一的 bar 分发器
        asyncio.create_task(self._bar_dispatcher())
        print(self._logger_prefix, "started with", list(self.specs.keys()))

    async def stop(self):
        for sid, inst in self._instances.items():
            try: inst.on_shutdown(self._ctxs[sid])
            except Exception as e: print(f"[{sid}] on_shutdown err: {e}")

    # ----- 事件：bar 分发给订阅该 symbol 的策略，并按 cadence 节拍调用 -----
    async def _bar_dispatcher(self):
        # 为每个策略维护下一次 bar 回调的最早触发时间（节拍器）
        next_ts: Dict[str, float] = {sid: 0.0 for sid in self.specs}
        while True:
            m = await self._bar_q.get()
            bar = m["value"]["data"]; sym = bar["symbol"]
            ts_end = bar["ts_end_us"] if "ts_end_us" in bar else None
            for sid, spec in self.specs.items():
                if sym not in spec.symbols: continue
                cadence = max(int(spec.cadence_s), 5)
                now_t = time.time()
                if now_t < next_ts[sid]: 
                    continue
                # 触发策略 on_bar_5s（策略节拍≥5s，收到 bar 时触发）
                ctx = self._ctxs[sid]; inst = self._instances[sid]
                ctx._begin_decision(); ctx._fired_once = False
                t0 = time.time()
                try:
                    inst.on_bar_5s(ctx, bar)
                except Exception as e:
                    ctx.logger(f"on_bar_5s error: {e}")
                finally:
                    ctx._end_decision()
                    self._metrics[sid]["lat_ms"] = (time.time()-t0)*1000
                # 下一次允许触发的时间
                next_ts[sid] = now_t + cadence

    # ----- 策略本地定时器（心跳/时间止损等） -----
    async def _worker_loop(self, sid:str):
        spec = self.specs[sid]; inst = self._instances[sid]; ctx = self._ctxs[sid]
        while True:
            try:
                await asyncio.sleep(max(int(spec.cadence_s), 5))
                ctx._begin_decision(); ctx._fired_once = False
                t0 = time.time()
                try:
                    inst.on_timer(ctx)
                except Exception as e:
                    ctx.logger(f"on_timer error: {e}")
                finally:
                    ctx._end_decision()
                    self._metrics[sid]["lat_ms"] = (time.time()-t0)*1000
            except asyncio.CancelledError:
                break

    # ----- 热更新（简单版：替换 config，不打断在途保护） -----
    def hot_update(self, sid:str, new_cfg:dict):
        if sid not in self._ctxs: return False
        self._ctxs[sid].set_config(new_cfg)
        self._params_hash[sid] = self._calc_params_hash(new_cfg)
        self._ctxs[sid].logger("config hot-updated")
        return True

    # ----- 工具：导入/参数哈希/配置聚合 -----
    def _import_class(self, path:str):
        mod, cls = path.rsplit(".", 1)
        m = importlib.import_module(mod)
        return getattr(m, cls)
    def _calc_params_hash(self, cfg:dict)->str:
        s = json.dumps(cfg, sort_keys=True, separators=(",",":"))
        # 简写 hash；生产建议 sha256
        return str(abs(hash(s)))
    def _spec_to_cfg(self, spec:StrategySpec)->dict:
        return {
            "strategy_id": spec.strategy_id,
            "symbols": spec.symbols,
            "cadence_s": spec.cadence_s,
            "params": spec.params,
            "sizing": spec.sizing,
            "exec_defaults": spec.exec_defaults
        }

# ---------- 6) （示例）一个极简 ORB 策略：仅演示引擎 API ----------
class DemoORBBreakout(StrategyAlgorithm):
    """示例：开盘 10 分钟区间突破后回测到上沿入场（极简，仅示范接口；逻辑可换成你的模板库）"""
    def initialize(self, ctx):

        self.open_min=p.get("opening_minutes", 10); self.retest_bps=p.get("retest_bps", 8)
        self.orb = {s: {"H":None,"L":None,"done":False} for s in self.syms}

    def on_bar_5s(self, ctx, bar):
        sym=bar["symbol"]; c=bar["close"]
        # 1) 就绪：需要至少 open_min 分钟的 5s bar
        need_5s = self.open_min*60//5
        # 真实实现里可由 ctx.ready(symbol, need_5s=...) 完成；这里演示直接跳过接口：
        # if not await ctx.ready(sym, need_5s=need_5s): ctx.skip(ctx.skip_reason()); return
        # 由于 stub DAL 无数据，这里演示逻辑只用 runtime 构建 ORB：
        ref = self.orb[sym]
        if not ref["done"]:
            # 用传入 bar 逐步累计高低（示例，无 RTH 判断）
            ref["H"] = c if ref["H"] is None else max(ref["H"], c)
            ref["L"] = c if ref["L"] is None else min(ref["L"], c)
            # 假定 10 分钟后完成（仅示例）
            ref["done"] = True
            ctx.logger(f"ORB built(H={ref['H']:.2f}, L={ref['L']:.2f})")
            return
        H = ref["H"]; 
        if H and abs(c-H)/H*1e4 <= self.retest_bps:
            # 2) 只发一次：示范下单 API
            qty = ctx.sizing.fixed_usd(ctx.config["sizing"].get("notional_usd", 5000), price=c)
            asyncio.create_task(ctx.order_limit(sym, "BUY", qty, c, tags=["demo","orb"]))
            # 触发一次后标记，避免重复（真实引擎也会在同一 decision 内抑制）
            ref["done"] = False
```

# Ⅱ. 如何切到生产链路（一步替换）

1. **把内存 Bus → Kafka**
   将上面 `Bus` 替换为你已经拿到的 `KafkaProducerAdapter / KafkaConsumerAdapter`（我前面给过）。

* 在 `StrategyEngine.__init__` 里用 `bus.subscribe("md.bar.5s.v2")` 接 Kafka 消费；
* `ctx.order_limit()` 内的 `bus.publish(ENGINE_ORDER_TOPIC, ...)` 由 Kafka 生产者 `send_and_wait()` 发送。

2. **把 CHDalStub → ClickHouse DAL**
   实现与 `CHDalStub` 同签名的异步 DAL：

* `last_n(symbol, n, res)`：查询 `qsys.bar_5s_v2 / bar_1m_v2`；带 RingCache（2s TTL）
* `features_intraday(symbol, fields)`：查 `feat_intraday_v2`
* 超时（≥800ms）返回 `None`，策略用 `ctx.ready()`/`ctx.skip()` 智能跳过，不阻塞。

3. **策略接入**
   把你的模板库类（ORB/VWAP/Trend/Range/Pair）以 `module: "pkg.mod.ClassName"` 方式写入策略配置；
   `StrategySpec` 从 YAML/DB 读入后实例化（代码里我直接传 list）。

4. **风控/执行**
   引擎只发 `engine.order.request.v2`；你的 RiskSvc（PG 存储过程）审批+预留→`risk.decision.v2`；
   执行安全内核（OCO/追踪止损）与 IB 适配层处理真实下单与状态/成交回流（我们已定过）。

# Ⅲ. 验收点（引擎本体）

* **每策略独立节奏**：同一时刻两策略 `cadence_s` 不互相拖慢（代码里 per-strategy worker + bar 调度）。
* **只发一次**：同一次 `on_bar_5s/on_timer` 内，重复下单调用会被 `ctx` 抑制（`decision_id` 机制）。
* **智能跳过**：`ctx.ready(symbol, need_5s, need_1m)` 不满足 → `ctx.skip(reason)`，不产生下单意图。
* **热更新**：`engine.hot_update(sid, new_cfg)` 替换参数与 `params_hash`，不打断在途保护（执行层独立）。
* **可观测**：`self._metrics[sid]` 记录 `orders/skips/dedup/lat_ms`（替换为 Prom 指标即生产级）。
