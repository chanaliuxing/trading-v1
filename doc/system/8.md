# 1) 设计目标 & 运行模型

* **IoC/事件驱动**：引擎分发事件，策略被动响应；策略只能通过引擎提供的 API 表达意图（下单/撤单/查询）。
* **强隔离**：每个策略**独立运行时**（协程/线程），独立**资金池**、**节奏（最小 5s，可 10/20/60s …）**、**数据依赖**、**风险上限**；策略间互不影响。
* **数据口径**：行情与特征统一来自 **ClickHouse**（tick/5s/10s/1m）与实时流；缺数据**智能跳过**本次执行。
* **幂等与回放**：每个“会产生副作用”的动作都有 `idempotency_key`；消息与状态可重放验证。
* **回测=实盘口径**：相同回调/状态机，唯一差别是撮合/滑点模型。

# 2) StrategyAlgorithm 抽象接口（必须实现/可选）

```python
class StrategyAlgorithm:
    # ---- 2.1 生命周期 ----
    def initialize(self, ctx: "Context") -> None:
        """启动一次，仅用于订阅、加载快照、设置节奏等（<300ms）。"""

    def on_microbar(self, ctx: "Context", bars_5s: list["Bar5s"]) -> None:
        """5s/10s 等微周期触发（由策略独立 cadence 决定）。预算：P95 < 200ms。"""

    def on_bar(self, ctx: "Context", bar_1m: "Bar1m") -> None:
        """1m 慢周期触发（可选）。预算：P95 < 200ms。"""

    def on_order_update(self, ctx: "Context", upd: "OrderUpdate") -> None:
        """订单状态变更回调（非阻塞，<50ms）。"""

    def on_position_update(self, ctx: "Context", pos: "PositionSnapshot") -> None:
        """持仓/PnL 变化回调（非阻塞，<50ms）。"""

    def on_shutdown(self, ctx: "Context", reason: str) -> None:
        """停机/卸载清理（<200ms），严禁阻塞。"""

    # ---- 2.2 可选：异常钩子 ----
    def on_error(self, ctx: "Context", err: Exception, where: str) -> None:
        """引擎捕获到策略代码异常时回调（记录或自降级）。"""
```

> **超时/背压**
>
> * `on_microbar/on_bar` 超时会被**打断/标记超预算**，引擎可能**拉长该策略 cadence**或临时**只许平仓**。
> * 回调内部**禁止阻塞 IO**（网络/磁盘）；如需慢计算请使用**离线预计算**或引擎提供的异步任务设施。

# 4) 引擎提供的 Context API（只读状态 + 交易指令 + 数据访问）

```python
class Context:
    # ---- 4.1 时钟/节奏/订阅 ----
    def now(self) -> datetime: ...
    def set_cadence(self, *, default_s: int | None = None) -> None:
        """仅收紧或在交易外放宽；实际值受守门与系统负载限制。"""

    def subscribe(self, symbol: str, *, resolutions: list[str]) -> None:
        """resolutions ∈ {'5s','10s','1m'}；只对当前策略生效。"""

    # ---- 4.2 只读状态 ----
    @property
    def portfolio(self) -> "PortfolioView": ...
    @property
    def open_orders(self) -> list["OrderUpdate"]: ...
    def position(self, symbol: str) -> "PositionSnapshot": ...

    # ---- 4.3 数据访问（ClickHouse 优先）----
    def history(self, symbol: str, *, resolution: str, limit: int) -> list[Bar5s | Bar1m]: ...
    def features_intraday(self, symbol: str, names: list[str], *, max_staleness_s: int = 15) -> dict: ...
    def features_snapshot(self, symbol: str) -> dict:
        """读取收市后快照（feat_daily_snapshot_v2），含 params_hash/version。"""

    # ---- 4.4 交易指令（异步，进入事件流水线） ----
    def market_order(self, symbol: str, qty: float, *, tif: str = "DAY",
                     notional_hint_usd: float | None = None, tags: list[str] = []) -> "Ticket": ...

    def limit_order(self, symbol: str, qty: float, limit_px: float, *, tif: str = "DAY",
                    notional_hint_usd: float | None = None, tags: list[str] = []) -> "Ticket": ...

    def stop_limit(self, symbol: str, qty: float, stop_px: float, limit_px: float,
                   *, tif: str = "DAY", tags: list[str] = []) -> "Ticket": ...

    def cancel(self, order_id: str) -> None: ...
    def cancel_all(self, symbol: str | None = None) -> None: ...
    def liquidate(self, symbol: str) -> "Ticket": ...

    # ---- 4.5 执行参数提示（可选）----
    def set_protective_hints(self, symbol: str, *,
                             take_profit_rr: float | None = None,
                             trailing_atr_k: float | None = None,
                             time_stop_s: int | None = None) -> None:
        """仅提示；最终 OCO/止损由执行服务依据全局/策略默认与风控守门落地。"""

@dataclass
class Ticket:
    idempotency_key: str
    strategy_id: str
    symbol: str
    side: str            # 引擎基于 qty 与当前净仓方向自动推导 BUY/SELL
    order_type: str      # 'MKT'/'LMT'/'STP_LMT'
    qty: float
    limit_px: float | None
    stop_px: float | None
    submitted: bool      # 进入事件流水线成功（不代表已到券商）
```

> **重要语义**
>
> * 所有下单接口都需要 `notional_hint_usd`（引擎可自动生成），用于**风控资金预留**。
> * **幂等**：同一回调内重复对同一 `symbol` 产生相同意图，引擎**自动去重**。
> * 策略**不直接**构建 OCO/止损，执行层会**首填即挂**、三层止损（我们已在“安全内核”规范里定了）。

# 5) 策略独立节奏 & 数据就绪（智能跳过）

* 每策略在 `initialize()` 指定或保留默认：

  ```python
  ctx.set_cadence(default_s=5)  # 可 10/20/60…；全局守门确保 min=5s
  ctx.subscribe("AAPL", resolutions=["5s","1m"])
  ```
* 引擎在触发前做 **ReadyCheck**：

  * 最近 `N5s`/`N1m` 根 bar **齐全**（RTH 标志一致）
  * Intraday/快照特征**新鲜**（≤ 15s）
  * 系统非降级（非 only-flatten）
  * **若未满足** → 本次 `on_microbar` **跳过**，引擎记录 `skip_reason`（数据缺口/特征过旧/系统降级/限流）。

---

# 6) 错误语义与限流

* **调用失败返回**

  * `RiskDenied(reason)`：资金上限/集中度/黑名单/时窗
  * `RateLimited(kind)`：每策略撤改/全局 QPS 限流
  * `SystemHalted()`：全局只许平仓
* 策略**不得捕获并沉默**这类异常后无限重试；引擎已做幂等与退避。
* 任何回调抛出未处理异常 → 引擎调用 `on_error()`，并可能**暂停该策略**、提升 cadence 或切 only-flatten。

# 8) 典型策略实现（伪代码，5s 执行）

```python
class TrendPullback(StrategyAlgorithm):
    def initialize(self, ctx):
        self.syms = ["AAPL","MSFT"]
        for s in self.syms:
            ctx.subscribe(s, resolutions=["5s","1m"])
        ctx.set_cadence(default_s=5)
        self.snap = {s: ctx.features_snapshot(s) for s in self.syms}  # 收市快照
        self.params_hash = {s: self.snap[s].get("params_hash") for s in self.syms}

    def on_microbar(self, ctx, bars_5s):
        for bar in bars_5s:
            pos = ctx.position(bar.symbol)
            h5 = ctx.history(bar.symbol, resolution="5s", limit=12)     # 最近1分钟
            h1 = ctx.history(bar.symbol, resolution="1m", limit=30)     # 最近30分钟
            feats = ctx.features_intraday(bar.symbol, ["atr_1m","trend_slope_20"])
            if not feats:   # 引擎通常在触发前会检查，这里双保险
                continue

            # 简单入场条件（示意）
            microATR = feats["atr_1m"] / 12.0
            trend_up = feats["trend_slope_20"] > 0
            pullback_ok = bar.close <= np.min([b.low for b in h5[-6:]]) + 0.5 * microATR

            if pos.pos_qty == 0 and trend_up and pullback_ok:
                notional = bar.close * 100
                ctx.set_protective_hints(bar.symbol, trailing_atr_k=2.0, time_stop_s=900)
                ctx.limit_order(bar.symbol, qty=+100, limit_px=bar.close, notional_hint_usd=notional)

            # 出场：交给执行层的 OCO/追踪止损，策略不重复下反向单
```

# 9) 回测语义（与实盘一致）

* **事件序列**：`md.bar.5s.v2` → `engine.order.request.v2` → `risk.decision.v2` → `exec.order.status/fill.v2` → `portfolio.snapshot.v2`
* **撮合**：限价按“下一根 bar 高/低是否触达”成交；滑点模型与佣金按全局默认或策略覆盖。
* **一致性校验**：同一数据与参数下，回测与影子实盘的**订单状态序列**一致（容许毫秒差）。

---

# 10) 安全与约束

* 策略代码**不得**：直接网络 IO、写磁盘、创建线程/子进程、访问系统随机端口。
* 仅通过 `Context` 调用下单/查询；任何直接触达风控/执行/数据库的行为会被引擎拒绝。
* 引擎对每策略执行**令牌桶限速**（下单/撤改），避免“重试风暴”。

# 12) 验收清单（策略侧）

* `initialize()` 能在**缺快照**时自降级（等下一次，有日志）
* `on_microbar()` 下单不重复（同回调多次命中也只发一单；引擎会幂等去重）
* 数据不足 → 自动**跳过**且无异常；数据恢复 → 自动继续
* 5s/10s/20s **独立可调**；热更后下一个周期生效
* 与执行安全内核联测：首填即 OCO、追踪止损改价节流、无保护窗口=0
