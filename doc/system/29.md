好，那我们先把**“历史回补服务（IB 历史 → Kafka 修复流 → CH 覆盖）”**完整落地，跟你现有链路无缝对接。按照你的要求，我直接贴**可运行骨架**（不生成文件），内含：**限流（令牌桶）+ 熔断器 + 去重幂等 + 分片回补 + 指标导出**。接上你前面已经有的聚合器、CH Writer、策略引擎，就形成**数据完整性闭环**。

## 一、回补服务设计要点（对齐我们前面共识）

* **输入**：

  * `md.gap.v1`（聚合器发的缺口事件）
  * `md.backfill.request.v1`（手动/批量触发的回补请求，便于运维）
* **输出**：

  * `md.bar.5s.repair.v1`（与聚合器修复流一致；CH Writer 同表写入，用 `ReplacingMergeTree(bar_seq)` 覆盖）
* **回补策略**：

  * 按缺口区间切片（默认 **600s** 一片），逐片从 IB 拉 **5秒** bar。
  * **令牌桶限流**（默认 2 req/sec，窗口可配）+ **并发上限**（默认 1–2）。
  * **熔断器**：连续失败或错误率超阈值 → 打开熔断，冷却后半开探测。
  * **幂等/去重**：对每个 `(symbol, ts_start)` 用 Redis key 去重，避免重复发修复。
  * **版本覆盖**：`bar_seq = ts_end * 10 + 9`（比实时聚合的小序号**更大**，天然覆盖）。
* **容灾**：

  * Redis 记录在途 job 进度（游标），重启后可继续。
* **指标**：

  * 回补成功/失败计数、错误率、熔断状态、平均单片耗时、输出行数等（Prometheus）。

## 三、**可直接粘贴运行的回补服务骨架**

> 依赖：`ib_insync`, `aiokafka>=0.8`, `redis>=4`（`redis.asyncio`）, `prometheus_client`。
> 与我们前面发的 `KafkaBusAdapter`、`metrics_exporter` 完全兼容（本段直接内嵌适配）。

```python
import os, asyncio, json, time, uuid, contextlib
from dataclasses import dataclass
from typing import Optional, List, Tuple, Dict

# ---- 依赖 ----
from ib_insync import IB, Stock, util as ibutil
from aiokafka import AIOKafkaProducer, AIOKafkaConsumer
import redis.asyncio as aioredis

# ---- 指标（沿用前面给的 metrics_exporter 接口）----
from prometheus_client import Counter, Gauge, Histogram, start_http_server

# ============ 配置 ============
@dataclass
class BackfillConfig:
    kafka_bootstrap: str = "localhost:9092"
    group_id: str = "backfill-v1"
    topic_gap: str = "md.gap.v1"
    topic_req: str = "md.backfill.request.v1"
    topic_repair: str = "md.bar.5s.repair.v1"

    ib_host: str = "127.0.0.1"
    ib_port: int = 7497
    ib_client_id: int = 88

    # 回补切片大小：每片秒数
    chunk_secs: int = 600                   # 10分钟为一片
    # 并发与限流
    max_concurrency: int = 1               # 同时仅1个片在跑（IB 比较“娇气”）
    rate_tokens: int = 2                   # 每窗口允许请求数
    rate_window_sec: int = 1               # 令牌窗口秒
    # 熔断器
    cb_fail_threshold: int = 5             # 连续失败次数阈值
    cb_error_ratio: float = 0.5            # 窗口错误率阈值
    cb_window: int = 20                    # 滑动窗口大小（请求数）
    cb_cooldown_sec: int = 60              # 熔断后冷却秒
    # 业务参数
    use_rth: bool = True                   # 只取 RTH
    what_to_show: str = "TRADES"           # IB 历史：TRADES/BID/ASK/MIDPOINT
    tz_calendar: str = "America/New_York"  # 用于日志，可按需扩展
    # Redis
    redis_url: str = "redis://localhost:6379/1"
    redis_ns: str = "backfill5s"
    # 指标端口
    metrics_port: int = 9104

# ============ 指标 ============
BF_ROWS_OK   = Counter("bf_rows_ok_total", "backfilled bars emitted ok", ["symbol"])
BF_ROWS_SKIP = Counter("bf_rows_skip_total", "bars skipped (dup)", ["symbol"])
BF_ROWS_ERR  = Counter("bf_rows_err_total", "bars build/emit error", ["symbol"])
BF_REQ_OK    = Counter("bf_req_ok_total", "ib historical ok")
BF_REQ_ERR   = Counter("bf_req_err_total", "ib historical err")
BF_CB_STATE  = Gauge("bf_circuit_open", "circuit breaker open (1 open / 0 closed)")
BF_LAT       = Histogram("bf_chunk_latency_ms", "chunk fetch latency", buckets=(100,200,500,1000,2000,5000,10000,20000))
BF_INFLIGHT  = Gauge("bf_inflight_chunks", "chunks in flight")
BF_QUEUE     = Gauge("bf_pending_chunks", "chunks pending")
BF_RATE_TOK  = Gauge("bf_rate_tokens", "rate limiter tokens")

def boot_metrics(port:int):
    # 避免多次 start
    static = getattr(boot_metrics, "_on", None)
    if not static:
        start_http_server(port)
        setattr(boot_metrics, "_on", True)

# ============ 简易令牌桶 ============
class TokenBucket:
    def __init__(self, capacity:int, refill_per_sec:int):
        self.capacity = capacity
        self.tokens = capacity
        self.refill = refill_per_sec
        self.ts = time.time()
    def take(self, n:int=1) -> bool:
        now = time.time()
        elapsed = now - self.ts
        self.ts = now
        self.tokens = min(self.capacity, self.tokens + elapsed * self.refill)
        BF_RATE_TOK.set(self.tokens)
        if self.tokens >= n:
            self.tokens -= n
            BF_RATE_TOK.set(self.tokens)
            return True
        return False

# ============ 熔断器 ============
class CircuitBreaker:
    def __init__(self, fail_threshold:int, error_ratio:float, window:int, cooldown:int):
        self.fail_threshold = fail_threshold
        self.error_ratio = error_ratio
        self.window = window
        self.cooldown = cooldown
        self.hist: List[bool] = []
        self.consec_fail = 0
        self.opened_until = 0.0
    def on_result(self, ok:bool):
        self.hist.append(ok)
        self.hist = self.hist[-self.window:]
        self.consec_fail = 0 if ok else self.consec_fail + 1
        if not ok and self.consec_fail >= self.fail_threshold:
            self.opened_until = time.time() + self.cooldown
        elif len(self.hist) >= self.window:
            err_ratio = 1 - sum(1 for x in self.hist if x)/len(self.hist)
            if err_ratio >= self.error_ratio:
                self.opened_until = time.time() + self.cooldown
    def allow(self) -> bool:
        if time.time() < self.opened_until:
            BF_CB_STATE.set(1)
            return False
        BF_CB_STATE.set(0)
        return True

# ============ 回补 Job ============
@dataclass
class BackfillJob:
    symbol: str
    from_ts: int   # epoch 秒（含）
    to_ts: int     # epoch 秒（含）
    use_rth: bool
    reason: str

def split_range(from_ts:int, to_ts:int, chunk:int) -> List[Tuple[int,int]]:
    out=[]
    cur=from_ts
    while cur < to_ts:
        end=min(cur+chunk, to_ts)
        out.append((cur, end))
        cur=end
    return out

# ============ 主服务 ============
class BackfillService:
    def __init__(self, cfg:BackfillConfig):
        self.cfg = cfg
        self.ib = IB()
        self.producer: Optional[AIOKafkaProducer] = None
        self.consumer: Optional[AIOKafkaConsumer] = None
        self.redis = None
        self.bucket = TokenBucket(cfg.rate_tokens, cfg.rate_tokens/cfg.rate_window_sec)
        self.cb = CircuitBreaker(cfg.cb_fail_threshold, cfg.cb_error_ratio, cfg.cb_window, cfg.cb_cooldown_sec)
        self.q: asyncio.Queue[BackfillJob] = asyncio.Queue()
        self.inflight = 0

    async def start(self):
        boot_metrics(self.cfg.metrics_port)
        self.redis = await aioredis.from_url(self.cfg.redis_url, decode_responses=False)
        self.producer = AIOKafkaProducer(
            bootstrap_servers=self.cfg.kafka_bootstrap, acks="all", linger_ms=5, compression_type="lz4",
            value_serializer=lambda v: json.dumps(v).encode("utf-8"),
            key_serializer=lambda k: k.encode("utf-8") if k else None
        )
        await self.producer.start()
        self.consumer = AIOKafkaConsumer(
            self.cfg.topic_gap, self.cfg.topic_req,
            bootstrap_servers=self.cfg.kafka_bootstrap,
            group_id=self.cfg.group_id, enable_auto_commit=True,
            value_deserializer=lambda b: json.loads(b.decode("utf-8")),
            key_deserializer=lambda b: b.decode("utf-8") if b else "",
            auto_offset_reset="latest"
        )
        await self.consumer.start()
        await self.ib.connectAsync(self.cfg.ib_host, self.cfg.ib_port, clientId=self.cfg.ib_client_id, timeout=5.0)
        # 消费缺口/请求
        asyncio.create_task(self._consume_loop())
        # 工作者
        for _ in range(self.cfg.max_concurrency):
            asyncio.create_task(self._worker())

    async def stop(self):
        if self.consumer:
            with contextlib.suppress(Exception): await self.consumer.stop()
        if self.producer:
            with contextlib.suppress(Exception): await self.producer.stop()
        if self.ib.isConnected():
            with contextlib.suppress(Exception): await self.ib.disconnectAsync()
        if self.redis:
            with contextlib.suppress(Exception): await self.redis.close()

    async def _consume_loop(self):
        while True:
            msg = await self.consumer.getone()
            try:
                d = msg.value["data"]
                if msg.topic == self.cfg.topic_gap:
                    # 从聚合器缺口：把 [last_bar_ts, now_ts] 作为候选窗口（可适当回撤 10s）
                    sym = d["symbol"]
                    from_ts = int(d["last_bar_ts"])
                    to_ts   = int(d["now_ts"])
                    # 安全垫：向左回撤 10s，覆盖可能未发出的尾部
                    job = BackfillJob(sym, max(0, from_ts-10), to_ts, self.cfg.use_rth, d.get("reason","gap"))
                else:
                    # 手动请求
                    job = BackfillJob(d["symbol"], int(d["from_ts"]), int(d["to_ts"]), bool(d.get("use_rth", self.cfg.use_rth)), d.get("reason","manual"))
                await self.q.put(job)
                BF_QUEUE.set(self.q.qsize())
            except Exception:
                # 忽略坏消息
                pass

    async def _worker(self):
        while True:
            job = await self.q.get()
            BF_QUEUE.set(self.q.qsize())
            # 切片
            chunks = split_range(job.from_ts, job.to_ts, self.cfg.chunk_secs)
            for (a,b) in chunks:
                # 熔断检查
                if not self.cb.allow():
                    await asyncio.sleep(1.0)
                    continue
                # 限流
                while not self.bucket.take(1):
                    await asyncio.sleep(0.05)
                BF_INFLIGHT.inc(); self.inflight += 1
                t0 = time.time()
                ok = await self._fetch_and_emit(job.symbol, a, b, job.use_rth)
                BF_LAT.observe((time.time()-t0)*1000.0)
                BF_INFLIGHT.dec(); self.inflight -= 1
                self.cb.on_result(ok)
            self.q.task_done()
            BF_QUEUE.set(self.q.qsize())

    async def _fetch_and_emit(self, symbol:str, from_ts:int, to_ts:int, use_rth:bool) -> bool:
        """
        调 IB 历史 5秒 bar，逐条发 md.bar.5s.repair.v1
        """
        try:
            contract = Stock(symbol, 'SMART', 'USD')
            await self.ib.qualifyContractsAsync(contract)
            # IB 历史参数：endDateTime / durationStr / barSize
            # 我们以右端对齐逐片请求（以 to_ts 为 end）
            end_dt = ibutil.formatIBDatetime(to_ts)  # ib_insync会转成 IB 字符串
            duration_str = f"{to_ts - from_ts} S"
            bars = await self.ib.reqHistoricalDataAsync(
                contract=contract,
                endDateTime=end_dt,
                durationStr=duration_str,
                barSizeSetting="5 secs",
                whatToShow=self.cfg.what_to_show,
                useRTH=use_rth,
                formatDate=2,
                keepUpToDate=False
            )
            BF_REQ_OK.inc()
        except Exception:
            BF_REQ_ERR.inc()
            return False

        # 逐条转 schema，并经 Redis 幂等去重后发出
        emitted = 0; skipped = 0; failed = 0
        for bar in bars:
            # 注意 IB 返回的是以 bar 结束时间为标识；我们换算 ts_start/ts_end（秒）
            ts_end = int(bar.date.timestamp())
            ts_start = ts_end - 5
            if ts_end < from_ts or ts_start > to_ts:  # 保护
                continue
            # 幂等去重
            if await self._seen(symbol, ts_start):
                BF_ROWS_SKIP.labels(symbol=symbol).inc(); skipped += 1
                continue
            try:
                msg = self._mk_repair_msg(symbol, ts_start, ts_end, bar.open, bar.high, bar.low, bar.close, bar.volume)
                await self._send(self.cfg.topic_repair, f"{symbol}:{ts_start}", msg)
                await self._mark_seen(symbol, ts_start)
                BF_ROWS_OK.labels(symbol=symbol).inc(); emitted += 1
            except Exception:
                BF_ROWS_ERR.labels(symbol=symbol).inc(); failed += 1
        # 可按需打印/日志
        return failed == 0

    # ---- 幂等 ----
    def _key_seen(self, symbol:str, ts_start:int) -> str:
        return f"{self.cfg.redis_ns}:seen:{symbol}:{ts_start}"
    async def _seen(self, symbol:str, ts_start:int) -> bool:
        return bool(await self.redis.exists(self._key_seen(symbol, ts_start)))
    async def _mark_seen(self, symbol:str, ts_start:int):
        # TTL 30天，避免无穷积累
        await self.redis.set(self._key_seen(symbol, ts_start), b"1", ex=30*24*3600)

    # ---- 组消息（bar_seq 用 ts_end*10+9，确保覆盖实时）----
    def _mk_repair_msg(self, symbol:str, ts_start:int, ts_end:int, o,h,l,c, vol:int) -> dict:
        bar_seq = ts_end * 10 + 9
        vwap = c if vol==0 else c  # 若有更细分数据可计算 vwap，这里用 close 兜底
        return {
            "schema_v": 2,
            "metadata": {"event_id": str(uuid.uuid4()), "ts_us": int(time.time()*1e6), "producer":"backfill5s"},
            "data": {
                "symbol": symbol, "ts_start": ts_start, "ts_end": ts_end,
                "open": float(o), "high": float(h), "low": float(l), "close": float(c),
                "vol": int(vol), "vwap": float(vwap),
                "rth": bool(self.cfg.use_rth),
                "source": "BACKFILL", "calc_mode": "backfill",
                "late_count": 0, "bar_seq": int(bar_seq)
            }
        }

    async def _send(self, topic:str, key:str, msg:dict):
        await self.producer.send_and_wait(topic, key=key, value=msg)

# ---- 启动入口（环境变量驱动）----
```

## 四、如何与现有链路拼起来（3 步烟测）

1. **确保 CH Writer 正在消费** `md.bar.5s.repair.v1`（我们之前的 Writer 已支持）。
2. **启动回补服务**（上面骨架）。
3. **制造缺口**：

   * 暂停聚合器 30 秒再启动；聚合器会发 `md.gap.v1`。
   * 或手动发一条请求到 `md.backfill.request.v1`：

     ```bash
     kcat -P -t md.backfill.request.v1 -K: <<EOF
     AAPL: {"schema_v":1,"metadata":{"event_id":"x","ts_us":1730000200000000,"producer":"ops"},"data":{"symbol":"AAPL","from_ts":1730000000,"to_ts":1730000600,"use_rth":true,"reason":"manual_smoke"}}
     EOF
     ```
4. **观察**：

   * Prom 指标端口 `http://localhost:9104/metrics`：

     * `bf_req_ok_total` 增长，`bf_req_err_total` 不持续增长
     * `bf_rows_ok_total{symbol="AAPL"}` 增长
     * `bf_circuit_open` 始终 0（正常）
   * ClickHouse 查询：

     ```sql
     SELECT symbol, ts_start, close, bar_seq, source, calc_mode
     FROM qsys.bar_5s_v2
     WHERE symbol='AAPL' AND ts_start>=toDateTime(1730000000)
     ORDER BY ts_start
     LIMIT 50;
     ```

     能看到 `source='BACKFILL'`, `calc_mode='backfill'`, `bar_seq` 数值**显著大于**实时写入的版本。

* `sum(rate(bf_req_err_total[10m])) / clamp_min(sum(rate(bf_req_ok_total[10m]))+sum(rate(bf_req_err_total[10m])),1) < 0.2`

* `sum(rate(bf_rows_err_total[5m])) == 0`

## 六、为何先做它

* 这是**最小侵入**补全数据闭环的关键模块；有它，策略在开盘前/中均可拿到**连续**的 5s 历史，用于你的 5–10 秒决策节拍。
* 配好限流/熔断，你基本不会触发 IB 的节流保护；幂等/覆盖保证了**可重复跑**且**不会脏写**。
* Prom 指标与我们现有面板直接打通，上生产之前就能发现隐患。
