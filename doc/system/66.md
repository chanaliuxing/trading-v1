# P3：生产优化与“自动驾驶”阶段（启动）

P3 目标：在可观测、可回退的前提下，让系统具备**高可用事故处置、自动降档与规则模板化**的生产韧性与效率。

## 第 13 步｜实盘事故演练 Runbook（10 种常见故障）

**1) IBKR 断连/不接单**

* 侦测：`ibgw_disconnects_total` 上升、提交超时 > 阈值。
* 立即动作：`KillSwitch(strategy)` → 撤单+平仓+释放预留；`statebus.pause_strategy(...)`。
* 恢复检查：重连稳定 ≥ 5 分钟、拒单率 < 1% → 手动恢复到上一发布步。

**2) Kafka 堵塞/滞后**

* 侦测：`consumer_lag` > 阈值、`bar/features publish lag` > 2s。
* 动作：自动触发 **TTL 三闸**；暂停新意图；排查上游 publisher。
* 恢复：lag 回到 < 1s 且连续 10 分钟稳定 → 解除暂停。

**3) ClickHouse 写入错误/堆积**

* 侦测：`pnl_ch_insert_errors_total`、`parts mutations` 异常。
* 动作：账本作业指数退避重试；超过 N 次入 DLQ；不提交 offset，防丢。
* 恢复：写入恢复后自动追平；日终跑一次“区间重算”。

**4) OCO 失配/保护缺腿**

* 侦测：`oco_invariant_breaks_total > 0`。
* 动作：OCO 看门狗执行 `cancel→reapply`；如多次失败 → KillSwitch。
* 恢复：巡检 5 分钟 0 违规后解封。

**5) 反手编舞中断（先平后建半途失败）**

* 侦测：反手事务日志未闭合、持仓与挂单不一致。
* 动作：进入互斥锁自愈：撤残腿 → 平仓 → 重新建仓 → 挂保护；如两次失败 → KillSwitch。
* 恢复：对账一致（仓位=期望，OCO 完整）后继续。

**6) Reservation 泄漏/未释放**

* 侦测：`ledger_snapshot.used` 未回落、`arb_finalize_total` 未增加。
* 动作：资金看门狗强撤 `release_all(strategy)`；记录泄漏来源并告警。
* 恢复：泄漏归零后恢复。

**7) 时间漂移/NTP 异常**

* 侦测：`chronyc tracking` RMS > 50ms。
* 动作：暂停下单，强制对时；确认 bars/features 时间轴单调。
* 恢复：RMS < 50ms 且 10 分钟稳定。

**8) 数据异常（零价/尖刺/缺口）**

* 侦测：`qscore` 下降、`gap_ratio` 超阈。
* 动作：数据质量网关屏蔽该 symbol 的信号；告警。
* 恢复：质量回升 > 阈值 10 分钟解封。

**9) 合规限制（停牌/SSR/LULD）触发**

* 侦测：规则钩子拒单计数上升；清单更新失败。
* 动作：禁新单、撤违规在挂；强制刷新清单源。
* 恢复：清单新鲜度 < 60s 且违规为 0。

**10) 回撤过线/拒单率过线（策略级断路器）**

* 侦测：`DD_day` > 1% 或 `reject_rate` > 1%。
* 动作：自动降档至最小档并进入冷却；必要时 KillSwitch。
* 恢复：冷却期结束且指标回到绿区，控制器才允许升档。

> 上述每条都已有操作脚本/探针在前面步骤提供：KillSwitch、OCO 看门狗、三闸 TTL、Reconciler、资金看门狗等。

---

## 第 14 步｜自动诊断与自愈（“安全自动驾驶”）

* **降档矩阵**：当 `gates` 任一破线 → 自动将策略 cap 下调 50%（或到 floor），标记冷却 30–60 分钟；
* **止损编排**：风控触发“快速市况恶化”事件（如指数急跌）→ 所有策略写 `max_open_intents=0`，仅允许减仓；
* **数据自愈**：某 symbol 质量低 → 动态把该 symbol 移出**白名单**，但保留其平仓与保护动作；
* **失败重试**：Error-Matrix（券商侧）+ 提交退避（执行侧）+ CH 写入退避（账本侧）全链路协同。

## 第 15 步｜策略模板库（Rule DSL 模板落地）

> 你前面已确认要有“策略模板库”。这里给出三套**可直接粘贴的 YAML 模板**（与第 12 步 DSL 引擎对齐）。
> 说明：只贴要点字段，实际可直接用；如需我可把完整 YAML 全量贴出。

**A. 均值回归（MeanRev）**

```yaml
name: meanrev_v2_tpl
defaults: { cadence_s: 5, ttl_ms: 2000, min_lot: 10, lot_round: 10, atr_k: 1.6, time_limit_s: 1200, trail_atr_mult: 1.4 }
rules:
  - id: gate; when: { all: [ "f.qscore>=70", "f.gap_ratio<=0.05" ] }; then: continue
  - id: size; when: "signal.side!=0"
    compute:
      lot_abs: "floor( 2000 / max(0.01, atr_k*f.atr_14), lot_round )"
      layers:
        - { trigger: "abs(f.zscore_20)>=1.0", qty_mult: 1.0 }
        - { trigger: "abs(f.zscore_20)>=1.5", qty_mult: 1.5 }
        - { trigger: "abs(f.zscore_20)>=2.0", qty_mult: 2.0 }
    emit: { type: target, mode: net, qty: "lot_abs*qty_mult*sign(signal.side)", style: {kind: LMT, limit_px: "signal.ref_px"} }
  - id: protect; when: "position.qty!=0"; emit: { type: protect, oco: { trail_atr_mult: "trail_atr_mult", time_stop_s: "time_limit_s" } }
  - id: reverse; when: { all: [ "position.qty*signal.side<0", "abs(signal.strength)>=0.6" ] }; emit: { type: reverse, atomic: true, style: { kind: LMT, limit_px: "signal.ref_px"} }
```

**B. 突破分批（Breakout）**

```yaml
name: breakout_v1_tpl
defaults: { cadence_s: 5, ttl_ms: 1500, min_lot: 10, lot_round: 10, time_limit_s: 900, trail_atr_mult: 2.0 }
rules:
  - id: gate; when: { all: [ "f.qscore>=75", "f.trend_slope>0" ] }
  - id: enter; when: "f.breakout_up"
    compute: { lot: "floor( 1500 / max(0.01, 1.2*f.atr_14), lot_round )" }
    emit: { type: target, qty: "lot", style: {kind: LMT, limit_px: "signal.ref_px"} }
  - id: add1; when: "f.pullback_ok"; emit: { type: target, qty: "position.qty+lot" , style: {kind: LMT, limit_px: "signal.ref_px"} }
  - id: protect; when: "position.qty!=0"; emit: { type: protect, oco: { trail_atr_mult: "trail_atr_mult", time_stop_s: "time_limit_s" } }
```

**C. 趋势跟随（TrendFollow）**

```yaml
name: trend_v1_tpl
defaults: { cadence_s: 10, ttl_ms: 2500, min_lot: 10, lot_round: 10, time_limit_s: 1800, trail_atr_mult: 1.8 }
rules:
  - id: gate; when: { all: [ "f.qscore>=70", "f.ema_fast>f.ema_slow" ] }
  - id: pullback_entry; when: "f.close<=f.ema_fast"
    compute: { lot: "floor( 2500 / max(0.01, 1.5*f.atr_14), lot_round )" }
    emit: { type: target, qty: "lot", style: { kind: LMT, limit_px: "signal.ref_px" } }
  - id: pyramid; when: "position.qty>0 and f.profit_atr>=1.0"; emit: { type: target, qty: "position.qty+lot" }
  - id: reduce; when: "position.qty>0 and f.drawdown_atr>=1.0"; emit: { type: target, qty: "max(0, position.qty - 0.5*position.qty)" }
  - id: protect; when: "position.qty!=0"; emit: { type: protect, oco: { trail_atr_mult: "trail_atr_mult", time_stop_s: "time_limit_s" } }
```
