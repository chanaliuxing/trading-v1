# ① TTL 三闸自测（队列/风控/执行前）

> 目的：任何过期意图都应**就地作废**，且计数器有记录：`intent_expired_total{stage="queue|approve|submit"}`。

```python
# --- TTL 自测工具 ---
import time, uuid
from dataclasses import dataclass

def now_us(): return int(time.time()*1e6)

@dataclass
class Freshness: ttl_ms: int

@dataclass
class OrderStyle:
    kind: str; limit_px: float=None; stop_px: float=None

@dataclass
class DecisionEnvelope:
    decision_id: str; strategy_id: str; symbol: str
    ts_bar_end_us: int; target_qty: float; tif: str
    order_style: OrderStyle; freshness: Freshness
    extras: dict

# 假装的 metrics
class M:
    def __init__(self): self.expired = {"queue":0,"approve":0,"submit":0}
    def inc(self, stage): self.expired[stage]+=1
METRICS = M()

# ---- 阶段1：队列入口闸 ----
def queue_gate(env):
    age_ms = (now_us() - env.ts_bar_end_us)//1000
    ttl = env.freshness.ttl_ms
    if age_ms > ttl:
        METRICS.inc("queue")
        return False, f"expired@queue age={age_ms} ttl={ttl}"
    return True, "ok"

# ---- 阶段2：风控批准闸（approve）----
def approve_gate(env):
    age_ms = (now_us() - env.ts_bar_end_us)//1000
    if age_ms > env.freshness.ttl_ms:
        METRICS.inc("approve")
        return False, "expired@approve"
    return True, "ok"

# ---- 阶段3：执行前闸（submit）----
def submit_gate(env):
    age_ms = (now_us() - env.ts_bar_end_us)//1000
    if age_ms > env.freshness.ttl_ms:
        METRICS.inc("submit")
        raise RuntimeError(f"expired@submit age={age_ms} ttl={env.freshness.ttl_ms}")

# ---- 自测用例 ----
def mk_env(age_ms, ttl_ms=2000):
    return DecisionEnvelope(
        decision_id=str(uuid.uuid4()),
        strategy_id="meanrev_v2", symbol="AAPL",
        ts_bar_end_us=now_us() - age_ms*1000,
        target_qty=100, tif="DAY",
        order_style=OrderStyle(kind="LMT", limit_px=100.0),
        freshness=Freshness(ttl_ms=ttl_ms),
        extras={"ref_px":100.0}
    )

# 用例1：刚出炉（不过期，三闸全过）
e1 = mk_env(age_ms=100, ttl_ms=2000)
assert queue_gate(e1)[0] and approve_gate(e1)[0]
submit_gate(e1)

# 用例2：在队列中卡超时（queue_gate 拦截）
e2 = mk_env(age_ms=2500, ttl_ms=2000)
ok, why = queue_gate(e2); assert not ok and "expired@queue" in why

# 用例3：风控环节超时（approve_gate 拦截）
e3 = mk_env(age_ms=2100, ttl_ms=2000)
# 假设队列到风控路上又过了 50ms，这里直接检查 approve
assert not approve_gate(e3)[0]

# 用例4：执行前超时（submit_gate 抛错）
e4 = mk_env(age_ms=1990, ttl_ms=2000)
# 假设风控到执行又过了 20ms
time.sleep(0.02)
try:
    submit_gate(e4)
    assert False, "should have expired@submit"
except RuntimeError as ex:
    assert "expired@submit" in str(ex)

print("TTL gates OK, counters:", METRICS.expired)
# 期望：{"queue":1,"approve":1,"submit":1}
```

**验收要点**

* 把上面 3 个闸门逻辑分别挂到你们的**队列消费入口**、`RiskService.approve()`、`Executor.submit()` 前；
* 跑脚本时，应看到三个阶段分别能拦截超时；
* Grafana/Prometheus 上 `intent_expired_total` 计数同步增长。

# ② 仲裁/资金预留/执行：所有出口必须 `finalize/release`

> 目的：任何**拒绝/过期/提交失败**都**不残留“名额/预留”**。

**管线模板（把核心链路放进 try/finally）：**

```python
async def pipeline(env):
    reservation_id = None
    arb_acquired = False
    try:
        # 1) 仲裁
        ok, allow_qty, meta = await arbiter.admit(env)
        if not ok:
            audit.log(env.decision_id, "DEFER", meta)
            return
        arb_acquired = True
        if allow_qty != abs(env.target_qty):
            env.target_qty = allow_qty if env.target_qty>0 else -allow_qty

        # 2) 风控 + 资金预留
        ok, ri_or_meta = await risk.approve_and_reserve(env)   # 返回 reservation_id
        if not ok:
            audit.log(env.decision_id, "REJECT", ri_or_meta)
            return
        reservation_id = ri_or_meta

        # 3) 执行提交（可能抛错：TTL/价格修复失败/券商拒绝）
        await executor.submit(env, reservation_id=reservation_id)
        audit.log(env.decision_id, "SUBMITTED", {})

    except Exception as e:
        audit.log(env.decision_id, "ERROR", {"err": str(e)})
        raise
    finally:
        # 4) 一定要在所有出口回收资源
        if arb_acquired:
            # 提交成功也要 finalize（把临时名额从仲裁器移除；名义硬约束在Ledger）
            await arbiter.finalize(env, status="submitted" if reservation_id else "reject")
        if reservation_id and not executor.is_tracking(env.decision_id):
            # 如果没进入跟踪（提交失败/异常），释放预留
            await ledger.release(reservation_id, cause="not_submitted")
```

**验收要点**

* 用“风控拒绝/执行抛错/TTL 过期”三种情形逐个触发；
* 检查：`arbiter` 活动集为空、`ledger.snapshot().used` 回到原值；
* SQL 层（如有）预留记录应标记 `released_at`。

# ③ Reconciler 演练（重启后 OCO 领养）

> 目的：进程重启后**能找到券商在挂的子单**，按 `order_ref` 或“合约+方向+价差”**重建 OCO 上下文**。

**演练步骤**

1. 运行策略 → 触发一次真实成交 → OCO 子单挂到 IB。
2. **强制重启** Phase4/执行器进程。
3. Reconciler 流程应：

   * `fetch_open_orders()` → 取回所有在挂；
   * 用 `order_ref`（或附加 `note/decision_id`）**精确匹配**；
   * 若缺失 `order_ref`：用 `(symbol, side, limit/stop px, tif)` 做**模糊匹配**；
   * 组回 `plan.oco = {tp_id, sl_id, base_qty}`；
   * 对不匹配/超额的子单，发 `cancel` 清理“幽灵”。

**关键匹配伪代码**

```python
def adopt_ib_orders(open_orders):
    # open_orders: 来自 IB 的在挂单列表
    for od in open_orders:
        ref = od.orderRef or od.tif_comment or ""
        dec_id = parse_decision_id(ref)
        if dec_id in plan_index:
            plan = plan_index[dec_id]
            if is_oco_leg(od):
                plan.oco.attach(od)    # 绑定 tp/sl 子单
            else:
                plan.entry = od
        else:
            # 模糊匹配
            k = (od.symbol, od.action, round(od.lmtPrice or od.auxPrice, 4))
            cand = find_plan_by_signature(k)
            if cand: cand.oco.attach(od)
            else:
                mark_as_orphan(od)     # 记录并巡检里清理
```

**验收要点**

* 重启后，仪表盘/日志中能看到“已领养 OCO: tp_id=…, sl_id=…”；
* 数据库/内存 `plan.oco` 恢复完整，数量与方向匹配；
* 对“无主”单，5 秒内被取消并标记为 `STALE_CLOSED`。

# ④ OCO 不变量巡检 + 自愈

> 目的：**永远**保证“持仓有保护、方向数量匹配”；一旦破坏 → 立刻**自愈**（取消并重置）。

**巡检协程（每 5s）**

```python
import asyncio

async def oco_watchdog():
    while True:
        try:
            for plan in plans.active():   # 遍历所有活跃计划
                pos = portfolio.position(plan.symbol)
                if pos.qty == 0:
                    continue
                tp, sl = plan.oco.tp, plan.oco.sl
                # 不变量：两腿都在、方向与数量匹配、价格合理（相对 avg_px/side）
                broken = (
                    (tp is None or sl is None) or
                    (tp.qty != abs(pos.qty) or sl.qty != abs(pos.qty)) or
                    (plan.side == "BUY" and (tp.price <= pos.avg_px or sl.price >= pos.avg_px)) or
                    (plan.side == "SELL" and (tp.price >= pos.avg_px or sl.price <= pos.avg_px))
                )
                if broken:
                    metrics.oco_invariant_breaks_total.inc()
                    log.error(f"[OCO] invariant broken; repairing plan={plan.id}")
                    # 自愈：取消旧的 → 重新挂保护
                    await executor.cancel_siblings(plan)
                    await executor.apply_oco(plan, pos)   # 依据当前仓位重建 TP/SL
        except Exception as e:
            log.exception(f"[OCO] watchdog error: {e}")
        await asyncio.sleep(5)
```

**验收要点**

* 人为删除一腿（在 IB/TWS 手工取消一个止盈/止损）→ 5 秒内系统**自动重挂**；
* 指标 `oco_invariant_breaks_total` 增加；
* 修复后，价格/数量/方向正确。

def hard_market_rules(symbol, side, qty):
    if is_halt(symbol):         return False, "halted"
    if is_luld_down(symbol):    return False, "LULD-down"
