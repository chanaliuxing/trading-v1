下面给你一份**策略模板库 v1（可直接粘贴改造）**。全部与我们已定的引擎/DAL/事件合约保持一致：

* 每个模板都：①给出**适用场景**与**依赖数据**；②一段**配置 Schema**（YAML 片段）；③**信号与风控设计**；④**Python 策略类骨架**（实现 `StrategyAlgorithm` 接口）；⑤**监控指标与常见陷阱**。
* 统一约定：下单通过 `ctx.order.*` 发出 `engine.order.request.v2`，并在 `tags/exec_overrides` 里传递执行/止损意图；就绪不足统一 `ctx.skip(reason)`。

# 统一约定（所有模板通用）

**策略节奏**

* `cadence_s` 每策略独立（5s/10s/20s/1m…），模板均默认 5s，可在 YAML 调整。

**ReadyCheck 依赖**

* bars_5s：近 N 根（各模板给出 N）
* features_intraday：`atr_1m / vwap / ema / adx / rsi …`（按模板需用）
* daily_snapshot：`atr_1d / beta / volatility_rank …`（可选）

**下单 API 约定（引擎会统一封装）**

* `ctx.order.limit(symbol, side, qty, px, tags=[], exec_overrides=dict(...))`
  典型 `exec_overrides`（执行层会识别，不识别则用默认）：

  ```python
  exec_overrides={
    "stop_mode": "MIXED",           # HARD_% | ATR_K | CHANNEL | MIXED
    "hard_stop_pct": 0.8,           # 0.8% (仅 stop_mode 包含 HARD_% 时)
    "atr_k": 2.5,                   # 2.0~3.5
    "stop_limit_offset_bps": 10,    # 止损限价回撤
    "time_stop_s": 900,             # 15 分钟
    "take_profit_bps": 40,          # 可选：止盈
    "trail_hysteresis_bps": 6,
    "trail_min_step_bps": 4,
    "min_modify_secs": 5,
    "max_updates_per_min": 6
  }
  ```
* 资金上限由 PG 账本**强约束**；策略侧 sizing 只给 hint。

**幂等与只发一次**

* 每次 `on_*` 回调内至多发**一次**下单意图；引擎会以 `decision_id` 去重抑制重复。

## 模板 A｜**开盘区间突破/回测（ORB Breakout & Retest）**

**适用**：日内动量、强势股；RTH 前 15–30 分钟最有效。
**依赖**：bars_5s（N≥180，↔15m）、feat_daily_snapshot(可选：昨收/当日ATR)。

**配置（示例）**

```yaml
strategy_id: ORBBreakout
module: orb.ORBBreakout
symbols: [AAPL, NVDA, META]
cadence_s: 5
params:
  opening_minutes: 15        # ORB 时间窗
  confirm_closes: 2          # 突破后连续收在区间外的根数
  retest_bps: 8              # 回测允许回撤幅度
  max_trades_per_symbol: 1   # 每日每标的至多1次
sizing:
  notional_usd: 10000
exec_defaults:
  stop_mode: MIXED
  hard_stop_pct: 0.9
  atr_k: 2.5
  take_profit_bps: 40
```

**信号**

1. 计算开盘前 `opening_minutes` 的高低区间 `[H_open, L_open]`。
2. **突破确认**：收盘价连续 `confirm_closes` 根在区间外；
3. **回测入场**（推荐）：突破后回测到区间边界±`retest_bps` 以内触发下单（更稳）。
4. **过滤**：当日 `ATR_1d`/`vol_rank` 太低跳过；大缺口开盘（gap>1.5%）可降权或跳过。

**风控/执行**

* OCO 首填即挂；止损 `MIXED`（HARD_% 或 ATR_K 取最近），止盈 0.4–0.6% 机动。
* Time-Stop = 15–30 分钟，防止拖单。
* `max_trades_per_symbol` 保证每日只打一枪。

**骨架**

```python
class ORBBreakout(StrategyAlgorithm):
    def initialize(self, ctx):
        p = ctx.config["params"]; self.syms = ctx.config["symbols"]
        self.open_min = p.get("opening_minutes", 15)
        self.confirm_n = p.get("confirm_closes", 2)
        self.retest_bps = p.get("retest_bps", 8)
        self.max_trades = p.get("max_trades_per_symbol", 1)
        self.trades_done = {s:0 for s in self.syms}
        self.orb = {}  # sym -> (H_open, L_open, ready_ts)

    def on_bar_5s(self, ctx, bar):
        sym = bar["symbol"]
        if ctx.skip_if_not_ready(sym, need_5s=self.open_min*60//5): return
        # 建立 ORB
        rth_secs = ctx.session.seconds_since_open()
        if rth_secs <= self.open_min*60:
            rng = self.orb.get(sym, (bar["high"], bar["low"], None))
            self.orb[sym] = (max(rng[0], bar["high"]), min(rng[1], bar["low"]), None)
            return
        # ORB 完成
        H, L, _ = self.orb.get(sym, (None, None, None))
        if H is None: return
        c = bar["close"]; tags=["orb"]
        # 突破确认：近 confirm_n 根都在区间外
        df = ctx.history(sym, window=f"{self.confirm_n*5*2}s", res="5s")
        if df is None or len(df) < self.confirm_n: return
        closes = df["close"].to_numpy()[-self.confirm_n:]
        # 多头突破 & 回测到边界
        if all(x > H for x in closes) and abs(c - H)/H*1e4 <= self.retest_bps:
            if self.trades_done[sym] >= self.max_trades: return
            qty = ctx.sizing.fixed_usd(ctx.config["sizing"]["notional_usd"], price=c)
            ctx.order.limit(sym, "BUY", qty, c, tags=tags,
                exec_overrides=ctx.config.get("exec_defaults", {}))
            self.trades_done[sym] += 1
        # 空头对称逻辑（略）
```

**监控**

* `engine_strategy_skips_total{reason="DATA_WINDOW_SHORT|VOL_TOO_LOW|GAP_TOO_LARGE"}`
* `orders_fired_total{tag="orb"}` / 胜率、R/R

**常见陷阱**

* 开盘跳空后即刻“突破”→改为回测入场能显著降低假突破；
* ORB 窗口过长导致错过行情，过短噪声大，建议 10–20min 网格回测选型。

## 模板 B｜**趋势回撤到均线（Trend Pullback to EMA/VWAP）**

**适用**：顺势低风险加仓；5s 触发，1m 确认。
**依赖**：bars_5s, bars_1m, feat_intraday(ema/vwap/atr)

**配置**

```yaml
strategy_id: TrendPullback
module: trend.PullbackEMA
symbols: [AAPL, MSFT]
cadence_s: 5
params:
  trend_ma: 20          # 1m EMA20 作为趋势锚
  pullback_bps: 20      # 回撤幅度阈值
  confirm_5s: 2         # 回落后再度上穿短均的5s确认根数
  max_adds: 2           # 允许加仓次数
sizing:
  base_notional_usd: 8000
  add_notional_usd: 4000
exec_defaults:
  stop_mode: ATR_K
  atr_k: 2.8
  take_profit_bps: 35
```

**信号**

* 趋势判定：1m EMA20 斜率 > 0 且价在 EMA20 上方（多头）；
* 回撤：5s close 距 EMA20 回撤 ≥ `pullback_bps`；
* 触发：5s 级别重新上穿 5s EMA5（或上一根高点）且 `confirm_5s` 根确认；
* 支持 `max_adds` 次分批加仓（每次距离前高/EMA 的回撤再次满足）。

**风控**

* 止损：`ATR_K`；追踪启用，`trail_hysteresis_bps ≥ 6` 防抖；
* 加仓后 OCO qty 自动同步；
* Time-Stop：20–30 分钟；
* 大波动（5s range/EMA 偏差异常）禁入。

**骨架**

```python
class PullbackEMA(StrategyAlgorithm):
    def initialize(self, ctx):
        p=ctx.config["params"]; self.syms=ctx.config["symbols"]
        self.trend_ma=p.get("trend_ma",20); self.pull_bps=p.get("pullback_bps",20)
        self.confirm=p.get("confirm_5s",2); self.max_adds=p.get("max_adds",2)
        self.added={s:0 for s in self.syms}

    def on_bar_5s(self, ctx, bar):
        sym=bar["symbol"]; 
        if ctx.skip_if_not_ready(sym, need_5s=120, need_1m=60): return
        ema1m=ctx.features(sym, fields=[f"ema1m_{self.trend_ma}"])  # 近窗取最后一条
        if ema1m is None: return
        ema=ema1m.iloc[-1,0]; c=bar["close"]
        # 趋势过滤
        if c < ema: return
        # 回撤幅度
        pull = (ema - c)/ema*1e4
        if pull < self.pull_bps: return
        # 重新上穿确认（5s）
        df=ctx.history(sym, window=f"{self.confirm*5*2}s", res="5s")
        if df is None or len(df)<self.confirm: return
        if not all(df["close"].to_numpy()[-self.confirm:] > df["close"].to_numpy()[-self.confirm-1]):
            return
        # sizing
        base=ctx.config["sizing"]["base_notional_usd"]
        add =ctx.config["sizing"]["add_notional_usd"]
        notional = base if self.added[sym]==0 else (add if self.added[sym] < self.max_adds else 0)
        if notional<=0: return
        qty=ctx.sizing.fixed_usd(notional, price=c)
        ctx.order.limit(sym,"BUY",qty,c,tags=["trend","pullback"],exec_overrides=ctx.config["exec_defaults"])
        self.added[sym]+=1
```

**监控**

* `add_count{symbol}`、`skip_reason=VOL_SPIKE/GAP/NO_TREND`
* `holding_time_min` 分布（检验 Time-Stop 设置）

**陷阱**

* 震荡市里 EMA 回撤极多 → 用 ADX>阈值 或 1m slope+R² 过滤。

## 模板 C｜**VWAP 偏离均值回归（VWAP Revert）**

**适用**：区间盘整/强资金回归；需要流动性好。
**依赖**：feat_intraday(vwap), bars_5s

**配置**

```yaml
strategy_id: VWAPRevert
module: mr.VWAPRevert
symbols: [QQQ, SPY]
cadence_s: 5
params:
  dev_entry_bps: 25     # 对 vwap 偏离 25bps 触发
  re_cross_confirm: 1   # 回归重新穿越 vwap 确认根数
  zscore_window_5s: 60  # 5s 收益 zscore 限制 |z|<zmax 降噪
  zmax: 1.5
sizing:
  notional_usd: 15000
exec_defaults:
  stop_mode: CHANNEL     # 或 ATR_K
  take_profit_bps: 20
```

**信号**

* 偏离：`dev = (price - vwap)/vwap * 1e4`；多头：`dev <= -dev_entry_bps`；
* 回归：随后 **上穿 vwap**（多）且 `re_cross_confirm` 根确认；
* 过滤：5s `zscore(|ret|)` < zmax（太剧烈波动不做均值回归）。

**风控**

* CHANNEL 止损（最近 N*5s 的低点 + band_bps），或 ATR_K；
* 止盈较近（20–30bps），胜率>R/R 取舍。

**骨架**

```python
class VWAPRevert(StrategyAlgorithm):
    def initialize(self, ctx):
        p=ctx.config["params"]; self.syms=ctx.config["symbols"]
        self.dev=p.get("dev_entry_bps",25); self.rc=p.get("re_cross_confirm",1)
        self.w=p.get("zscore_window_5s",60); self.zmax=p.get("zmax",1.5)

    def on_bar_5s(self, ctx, bar):
        sym=bar["symbol"]; 
        if ctx.skip_if_not_ready(sym, need_5s=max(self.w, 120)): return
        v=ctx.features(sym,["vwap"])
        if v is None: return
        vwap=v.iloc[-1,0]; c=bar["close"]; dev=(c-vwap)/vwap*1e4
        # 偏离在下侧，等待回归上穿
        if dev < -self.dev:
            df=ctx.history(sym, window=f"{(self.rc+2)*5}s", res="5s")
            if df is None or len(df)<self.rc+1: return
            last=df["close"].to_numpy()
            if not all(x > vwap for x in last[-self.rc:]): return
            # zscore 过滤
            ret=df["close"].pct_change().dropna().to_numpy()[-self.w:]
            if len(ret)==0: return
            z= (ret[-1]-ret.mean())/(ret.std()+1e-9)
            if abs(z)>self.zmax: return
            qty=ctx.sizing.fixed_usd(ctx.config["sizing"]["notional_usd"], price=c)
            ctx.order.limit(sym,"BUY",qty,c,tags=["vwap","revert"],exec_overrides=ctx.config["exec_defaults"])
        # 反向（上偏离后下穿）卖出对称
```

**监控**

* `dev_at_entry_bps` 分布；`win_rate` 对比 `take_profit_bps` 调参。

**陷阱**

* 趋势日“均值回归”容易逆势亏损 → 加入趋势过滤（1m EMA 斜率近零）。

## 模板 D｜**区间均值回归（Bollinger/Z-Score）**

**适用**：震荡日的回线策略；对单标的或 ETF 有效。
**依赖**：bars_5s（N≥240）

**配置**

```yaml
strategy_id: RangeMR
module: mr.RangeMR
symbols: [IWM, DIA]
cadence_s: 5
params:
  bb_window_5s: 120
  bb_dev: 2.0           # 布林带倍数
  reenter_cooldown_s: 300
sizing:
  notional_usd: 8000
exec_defaults:
  stop_mode: HARD_%
  hard_stop_pct: 0.7
  take_profit_bps: 18
```

**信号**

* 布林带：5s close 触及/穿越下轨 → 反向（买入）；穿越上轨 → 做空；
* 触发后在带内快速回归；
* `reenter_cooldown_s` 冷却避免频繁打脸。

**骨架**

```python
class RangeMR(StrategyAlgorithm):
    def initialize(self, ctx):
        p=ctx.config["params"]; self.syms=ctx.config["symbols"]
        self.w=p.get("bb_window_5s",120); self.k=p.get("bb_dev",2.0)
        self.cool=p.get("reenter_cooldown_s",300); self.last_ts={s:0 for s in self.syms}

    def on_bar_5s(self, ctx, bar):
        sym=bar["symbol"]; now=ctx.now().timestamp()
        if now - self.last_ts[sym] < self.cool: return
        if ctx.skip_if_not_ready(sym, need_5s=self.w): return
        df=ctx.history(sym, window=f"{self.w*5}s", res="5s")
        px=df["close"].to_numpy()
        mu=px.mean(); sd=px.std()+1e-9; upper=mu+self.k*sd; lower=mu-self.k*sd
        c=bar["close"]
        if c <= lower:
            qty=ctx.sizing.fixed_usd(ctx.config["sizing"]["notional_usd"], price=c)
            ctx.order.limit(sym,"BUY",qty,c,tags=["bb","mr"],exec_overrides=ctx.config["exec_defaults"])
            self.last_ts[sym]=now
        elif c >= upper:
            qty=ctx.sizing.fixed_usd(ctx.config["sizing"]["notional_usd"], price=c)
            ctx.order.limit(sym,"SELL",qty,c,tags=["bb","mr"],exec_overrides=ctx.config["exec_defaults"])
            self.last_ts[sym]=now
```

**陷阱**

* 趋势日将连环亏 → 加“趋势过滤”（1m EMA 斜率近零 or ADX<20）后效果稳定。

## 模板 E｜**配对交易（Beta 中性价差回归，Pairs Trading）**

**适用**：同业双标的（如 MSFT/GOOGL），中低频。
**依赖**：bars_1m（N≥240），feat_daily_snapshot(beta/行业分类，可选）

**配置**

```yaml
strategy_id: PairMR
module: statarb.PairMR
symbols: [[MSFT, GOOGL], [XOM, CVX]]
cadence_s: 20
params:
  hedge_beta_mode: "rolling"   # rolling | static
  beta_window_1m: 120
  z_entry: 2.0
  z_exit: 0.5
sizing:
  spread_notional_usd: 15000   # 总名义（两腿合计）
exec_defaults:
  stop_mode: ATR_K
  atr_k: 3.0
  time_stop_s: 1800
```

**信号**

* 估计对冲比 `β`（rolling OLS 或静态 Sector Beta）；
* 构造价差 `S = ln(P_A) - β*ln(P_B)`；
* `z = (S - μ)/σ`；`|z| > z_entry` 入场，回归到 `z_exit` 平仓；
* 持仓对称：做多 A 做空 B（取决于 z 正负）。

**骨架**

```python
class PairMR(StrategyAlgorithm):
    def initialize(self, ctx):
        p=ctx.config["params"]; self.pairs=ctx.config["symbols"]
        self.mode=p.get("hedge_beta_mode","rolling"); self.win=p.get("beta_window_1m",120)
        self.zin=p.get("z_entry",2.0); self.zout=p.get("z_exit",0.5)

    def on_timer(self, ctx):
        for A,B in self.pairs:
            if ctx.skip_if_not_ready(A, need_1m=self.win) or ctx.skip_if_not_ready(B, need_1m=self.win):
                continue
            a=ctx.history(A, window=f"{self.win}m", res="1m")["close"].to_numpy()
            b=ctx.history(B, window=f"{self.win}m", res="1m")["close"].to_numpy()
            import numpy as np
            la, lb = np.log(a+1e-9), np.log(b+1e-9)
            beta = self._beta(la, lb) if self.mode=="rolling" else 1.0
            s = la[-1] - beta*lb[-1]
            mu, sd = (la - beta*lb).mean(), (la - beta*lb).std()+1e-9
            z = (s - mu)/sd
            notional = ctx.config["sizing"]["spread_notional_usd"]
            if z >= self.zin:
                # 做空 A 做多 B
                qtyA = ctx.sizing.fixed_usd(notional/2, price=a[-1])
                qtyB = ctx.sizing.fixed_usd(notional/2, price=b[-1])
                ctx.order.limit(A,"SELL",qtyA,a[-1],tags=["pair","mr"])
                ctx.order.limit(B,"BUY", qtyB,b[-1],tags=["pair","mr"])
            elif abs(z) <= self.zout:
                ctx.order.flatten(A); ctx.order.flatten(B)

    def _beta(self, la, lb):
        import numpy as np
        x=lb - lb.mean(); y=la - la.mean()
        return (x@y)/((x*x).sum()+1e-9)
```

**陷阱**

* 合约最小价位/tick 需对齐到两腿；
* 交易成本对价差收益侵蚀显著，需严格设 `take_profit_bps` 与 `time_stop_s`。

# 监控与可观测（模板公共）

建议为每个模板加以下自定义指标（在 `ctx.metrics` 上报）：

* `signal_fired_total{strategy, symbol, tag}`
* `data_ready_lag_ms{strategy}`（就绪→决策延迟）
* `switch_filter_total{reason="NO_TREND|VOL_LOW|OUTLIER"}`
* `entry_dev_bps / exit_dev_bps`（VWAP/BB 相关）
* `cooldown_suppressed_total`（冷却抑制次数）

**告警建议**

* `skips_total` 急剧上升（数据缺口/CH 超时）
* `stop_to_market_upgrade_total` 异常升高（执行/节流问题）
* 策略胜率/持仓时长/盈亏分布偏移（信号漂移）

# 如何落地

1. 把模板类粘到你的 `strategies/` 目录，模块路径与 YAML 的 `module` 对齐。
2. 在 `strategies.yml` 中为每个模板开一份配置（上面的片段可直接改符号与阈值）。
3. 引擎启动后，逐个策略在**影子模式**验证：

   * ReadyCheck 是否合理跳过；
   * 是否只发一次；
   * `exec_overrides` 是否被执行层正确识别（止损/止盈/追踪节流）。
4. 通过影子 → 小额实盘 → 放量。
