# IB 执行适配层 v1（ib_insync 方向）

## 0) 目标与边界

* **幂等**：同 `idempotency_key` 只生成一套实单；重连/重放不重复下。
* **始终有保护**：首填 ≤1s 附挂 OCO；失败立即 **Stop-MKT** 兜底。
* **节流**：下单/改价/撤单均有 **令牌桶 + 节流**，命中配额自动退避重试。
* **可恢复**：重连后**采集实挂单**，按 `orderRef/parentId/ocaGroup` 重建上下文。
* **事件桥**：把 IB Trade/OrderStatus → 标准化为 `exec.order.status.v2` / `exec.fill.v2`。

---

## 1) 错误分类与映射（可配置）

统一分 4 类：`QUOTA`（配额/节流）、`TRANSIENT`（临时网络/超时）、`PERM`（永久错误/参数非法）、`REJECT`（交易所或风控拒绝）。

> 默认映射（可在 YAML/DB 配置，真实编码随 IB 版本调整）

* **QUOTA**：常见“pacing violation/速率限制”类错误码（示例：`10197` 等）
* **TRANSIENT**：断线/超时（示例：`1100/1101/1102`、超时）
* **PERM**：合约无效、权限不足、价格越界等（示例：`200/201/202` 等）
* **REJECT**：下单被拒（交易所/经纪侧风控），无重试价值

命中 `QUOTA/TRANSIENT` → **指数退避 + 抖动**；`PERM/REJECT` → 直接失败并走兜底或回退。

---

## 2) 速率限制与节流（令牌桶）

为不同操作独立限流：

* `place_tokens = 10/min`，`modify_tokens = 30/min`，`cancel_tokens = 30/min`（起步建议，之后按实测调整）
* 每操作取 1 令牌；不足则等待或排队
* 命中 `QUOTA` → **降配**（短时间内减少令牌补充速率）

---

## 3) 核心接口（供执行安全内核调用）

---

## 4) OCO/Bracket 生成要点（ib_insync）

* **父单**：`Order(type=LMT, totalQuantity=qty, lmtPrice=limit_px, tif, transmit=False, orderRef=idemp_key)`
* **子单**：

  * 止损：`Order(type=STP_LMT, auxPrice=stop_px, lmtPrice=stop_lmt_px, parentId=parent.orderId, ocaGroup=oco_group_id, transmit=False)`
  * 止盈（可选）：`Order(type=LMT, lmtPrice=take_px, parentId=parent.orderId, ocaGroup=oco_group_id, transmit=True)`
  * 若无止盈：止损 `transmit=True`
* **注意**：最后一单 `transmit=True` 才会一次性把整套发出。
* **价格对齐**：使用 `ContractDetails.minTick` 对 `limit/stop/stopLmt` 做 **tick 对齐**。

---

## 5) 幂等策略

* `idempotency_key` → 写入 parent 的 `orderRef`，并在 PG `core_order(idempotency_key)` 唯一；
* 本地 `inflight` map 以 `idemp_key` 去重（避免瞬时重试重复 place）；
* 重连后 `reqOpenOrders()` / `openTrades()`，按 `orderRef` 反查并补齐 PG。

---

## 6) 事件桥（统一产出）

* **订单状态**：把 `trade.orderStatus.status` 映射为 `NEW/SUBMITTED/WORKING/PARTIAL/FILLED/CANCELLED/REPLACED/REJECTED` → 发布 `exec.order.status.v2`。
* **成交**：`exec.fill.v2`（`order_id/qty/px/ts/liquidity?`）；同时落 PG `core_fill`（唯一索引去重）。
* **OCO 附挂结果**：可选发 `exec.oco.attach.v1` 供监控。

---

## 7) 重连与恢复

* **断线**：监听 `IB.connected` 变化；`1100/1101/1102` 走 `TRANSIENT` 分支
* **恢复**：

  1. `reqOpenOrders()` 拉全量实挂单
  2. 基于 `orderRef/parentId/ocaGroup` 构图，重建 parent→children
  3. 修复：缺失保护 → 立即补挂；重复保护 → 撤旧保新
  4. 补发状态事件（去重）并对齐 PG

---

## 8) 指标（Prom）

* `ib.place.latency_ms / ib.modify.latency_ms / ib.cancel.latency_ms`
* `ib.error_total{class}`（quota/transient/perm/reject）
* `ib.retry_total{op}`、`ib.backoff_seconds{op}`
* `ib.oco_attach_success_total / fail_total`
* `ib.open_trades_count`

## 9) 伪代码骨架（关键路径）

```python
class IBAdapter:
    def __init__(self, ib: IB, rate_limits, logger, metrics):
        self.ib = ib
        self.tok_place = TokenBucket(rate_limits.place_rps, rate_limits.place_burst)
        self.tok_modify = TokenBucket(rate_limits.modify_rps, rate_limits.modify_burst)
        self.tok_cancel = TokenBucket(rate_limits.cancel_rps, rate_limits.cancel_burst)
        self.inflight = {}  # idemp_key -> orderId
        self.status_pub = self.fill_pub = None
        self.minTickCache = {}

    def bind_event_sink(self, status_pub, fill_pub):
        self.status_pub, self.fill_pub = status_pub, fill_pub

    async def _round_px(self, contract, px):
        tick = await self._min_tick(contract)
        return round(px / tick) * tick

    async def place_parent_limit(self, contract, side, qty, limit_px, idemp_key, tif="DAY"):
        if idemp_key in self.inflight:
            return self.inflight[idemp_key]  # 幂等命中
        await self.tok_place.take(1)

        limit_px = await self._round_px(contract, limit_px)
        parent = Order(action=side, orderType='LMT', totalQuantity=qty, lmtPrice=limit_px,
                       tif=tif, transmit=False, orderRef=idemp_key)

        trade = await self._retry(lambda: self.ib.placeOrder(contract, parent), op='place')
        self.inflight[idemp_key] = trade.order.orderId
        await self._publish_status(trade, state="SUBMITTED")
        return trade.order.orderId

    async def attach_oco_children(self, parent_oid, stop_px, stop_lmt_px, take_px, oco_group_id):
        await self.tok_place.take(1)
        # 组装两个子单
        stop = Order(action='SELL', orderType='STP_LMT', totalQuantity=None,
                     auxPrice=stop_px, lmtPrice=stop_lmt_px, parentId=parent_oid,
                     ocaGroup=oco_group_id, transmit= not bool(take_px))
        if take_px:
            tp = Order(action='SELL', orderType='LMT', totalQuantity=None,
                       lmtPrice=take_px, parentId=parent_oid, ocaGroup=oco_group_id,
                       transmit=True)
            await self._retry(lambda: self.ib.placeOrder(None, stop), op='place')
            await self._retry(lambda: self.ib.placeOrder(None, tp), op='place')
        else:
            stop.transmit = True
            await self._retry(lambda: self.ib.placeOrder(None, stop), op='place')
        # 成功：计数 +1
        self.metrics.inc("ib.oco_attach_success_total")

    async def replace_stop_lmt(self, order_id, new_stop_px, new_lmt_px, replace_key):
        await self.tok_modify.take(1)
        def _do():
            o = Order(orderId=order_id, orderType='STP_LMT',
                      auxPrice=new_stop_px, lmtPrice=new_lmt_px)
            return self.ib.placeOrder(None, o)  # modify
        try:
            await self._retry(_do, op='modify')
            return True
        except QuotaError:
            self.metrics.inc("ib.error_total", {"class":"quota"}); return False
        except Exception:
            self.metrics.inc("ib.error_total", {"class":"other"}); return False

    async def cancel_order(self, order_id):
        await self.tok_cancel.take(1)
        return await self._retry(lambda: self.ib.cancelOrderById(order_id), op='cancel')

    async def _retry(self, f, op):
        backoff = 0.25
        for i in range(5):
            try:
                return await f()
            except IBError as e:
                cls = classify(e)  # QUOTA/TRANSIENT/PERM/REJECT
                if cls in ("QUOTA","TRANSIENT") and i < 4:
                    await asyncio.sleep(backoff); backoff *= 2; continue
                raise  # PERM/REJECT 或重试上限

    async def start(self):
        await self.ib.connectAsync()   # 细节略
        self.ib.execDetailsEvent += self._on_fill
        self.ib.orderStatusEvent  += self._on_status

    async def _on_status(self, trade: Trade):
        # 规范化状态并 self.status_pub(...)
        ...

    async def _on_fill(self, trade: Trade, fill: Fill):
        # 组装 exec.fill.v2 并 self.fill_pub(...)
        ...
```

> 说明：`classify(e)` 使用“错误映射表”把 ib 异常分到四类；`TokenBucket` 用之前的实现；`_round_px` 缓存 `minTick`。

## 10) 自测要点（接你们的离线 Harness）

* **T1：幂等下单**：同 `idemp_key` 连续调用 `place_parent_limit` 只返回同 `orderId`；PG 唯一键不冲突。
* **T2：配额退避**：模拟抛出 `QUOTA`，观察指数退避 + 降频；最终成功或合理失败。
* **T3：OCO 失败兜底**：`attach_oco_children` 连续失败 3 次 → 自动下 **Stop-MKT**；指标 `stop_to_market_upgrade_total==1`。
* **T4：重连恢复**：mock `openTrades()` 返回一套 parent+children，`adopt_existing` 能重建映射并补发状态。
