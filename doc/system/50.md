好，我直接把三块**交易决策核心落地件**贴出来（不生成文件，直接可粘贴进你工程）：

1. **Decision Envelope 规范**（统一输入/输出字段与校验）
2. **Pre-Decision Validator**（新鲜度/数据质量/市场状态/成本覆盖的强校验）
3. **Intent Translation 策略**（按点差/波动/流动性自适应选择单型＋价格围栏＋子单计划＋OCO）

## 1) Decision Envelope 规范（统一决策载体）

> 所有策略只产出 **Envelope**，其余都交给验证与翻译层。缺字段→拒绝。

```python
from dataclasses import dataclass, field
from typing import Optional, Dict, List

@dataclass
class PriceIntent:
    ref: str                     # 'mid' | 'last' | 'best' (由翻译层解释)
    offset_ticks: float          # +买入抬价/-卖出压价的tick偏移
    hard_ceiling_px: Optional[float] = None
    hard_floor_px: Optional[float] = None

@dataclass
class RiskOverrides:
    catastrophic_stop_px: Optional[float] = None  # 入场即设
    trailing_atr_mult: Optional[float] = None     # 跟踪止损ATR倍数
    time_stop_s: Optional[int] = None             # 时间止损

@dataclass
class CostEstimates:
    slippage_bp: float           # 预估滑点（bp）
    fees_bp: float               # 交易费率（bp）
    impact_bp: float             # 冲击成本（bp）
    confidence: float            # 0..1

@dataclass
class Freshness:
    dlb_ms: int                  # 从bar_end起允许的判定时延预算
    ttl_ms: int                  # 意图有效期（超时自动作废）

@dataclass
class DecisionEnvelope:
    decision_id: str
    strategy_id: str
    strategy_version: Optional[str]
    param_hash: Optional[str]

    symbol: str
    bar_id: str
    ts_bar_start_us: int
    ts_bar_end_us: int
    regime_tag: str              # e.g. 'open30m','trend','meanrev','hiVol'

    signal_score: float          # 0..1（强度归一化）
    target_qty: float            # 目标持仓（正多负空，单位股/合约）
    max_notional: float          # 单笔/本次名义上限（美元）
    max_participation: float     # 最大参与率（%ADV或盘口占比）

    price_intent: PriceIntent
    risk_overrides: RiskOverrides
    cost_estimates: CostEstimates
    freshness: Freshness

    tags: List[str] = field(default_factory=list)
    reason_codes: List[str] = field(default_factory=list)  # 策略侧简要触发摘要
    extras: Dict[str, float] = field(default_factory=dict) # 特征快照(可选)
```

## 2) Pre-Decision Validator（强校验 → 通过/跳过）

> 统一四类校验：**新鲜度/窗口充分/数据质量与市场状态/成本覆盖**。任何未达标 → **SKIP** 并记录原因（不会发单）。

```python
from dataclasses import dataclass
from typing import Tuple, List, Dict
import math, time

@dataclass
class ValidateCfg:
    min_hist_bars: int = 36             # 最少历史窗口（5s bar计）
    bar_gap_ms_max: int = 1200          # 允许聚合器尾延迟
    require_nbbo: bool = True           # 市价必须有NBBO
    min_volume: float = 1.0             # 本bar最小成交量
    min_atr_bp: float = 1.0             # 过低波动过滤（防噪音）
    edge_buffer_bp: float = 2.0         # 边际大于成本+缓冲才放行

@dataclass
class ValidateResult:
    ok: bool
    skip_reasons: List[str]
    now_us: int
    effective_ttl_ms: int

class PreDecisionValidator:
    def __init__(self, cfg: ValidateCfg, market_state_provider, bar_store, feature_store, cost_model):
        self.cfg = cfg
        self.ms = market_state_provider   # 提供 bid/ask/last/luld/ssr/halt/tick/lot
        self.bars = bar_store             # 取历史5s bar窗口
        self.feats = feature_store        # 取策略所需特征（可为空）
        self.cost = cost_model            # 估算成本（滑点/冲击/费用）

    async def validate(self, env: DecisionEnvelope) -> ValidateResult:
        reasons: List[str] = []
        now_us = int(time.time()*1e6)

        # 0) Freshness（判定时延预算）
        if now_us - env.ts_bar_end_us > env.freshness.dlb_ms * 1000:
            reasons.append("stale_decision:dlb_exceeded")

        # 1) 历史窗口充分
        bars = await self.bars.window(env.symbol, end_us=env.ts_bar_end_us, count=self.cfg.min_hist_bars)
        if not bars or len(bars) < self.cfg.min_hist_bars:
            reasons.append("insufficient_history")
        else:
            # 聚合器延迟/缺口
            if (env.ts_bar_end_us - bars[-1]["ts_end_us"]) > self.cfg.bar_gap_ms_max * 1000:
                reasons.append("bar_lag_too_large")

        # 2) 数据质量（ATR/量/NaN/极值）
        if bars:
            atr_bp = max(1e-9, bars[-1].get("atr_bp", 0.0))
            vol = bars[-1].get("volume", 0.0)
            if atr_bp < self.cfg.min_atr_bp: reasons.append("too_low_volatility")
            if vol < self.cfg.min_volume:    reasons.append("too_low_volume")
            qflags = bars[-1].get("quality", "GOOD")
            if qflags not in ("GOOD","REPAIRED"):
                reasons.append(f"bar_quality:{qflags}")

        # 3) 市场状态（NBBO/LULD/SSR/HALT）
        m = await self.ms.get(env.symbol)
        if m.halted: reasons.append("halted")
        if env.price_intent and env.price_intent.ref == "mid" and (m.bid_px is None or m.ask_px is None):
            reasons.append("no_nbbo_for_mid")
        if self.cfg.require_nbbo and m.bid_px is None and m.ask_px is None:
            reasons.append("no_nbbo")

        # 4) 成本覆盖（edge > cost + buffer）
        c = self.cost.estimate(env, market=m, bars=bars)
        edge_bp = max(0.0, env.signal_score * 100.0)  # 例：将强度映射为“理论edge(bp)”
        total_cost_bp = c["slippage_bp"] + c["fees_bp"] + c["impact_bp"] + self.cfg.edge_buffer_bp
        if edge_bp <= total_cost_bp:
            reasons.append(f"edge_insufficient:{edge_bp:.2f}<=cost:{total_cost_bp:.2f}")

        ok = len(reasons) == 0
        # TTL：从发布时刻起（执行层再二次校验）
        effective_ttl_ms = env.freshness.ttl_ms
        return ValidateResult(ok=ok, skip_reasons=reasons, now_us=now_us, effective_ttl_ms=effective_ttl_ms)
```

**极简成本模型占位（可替换为你的 ClickHouse/历史回放回归）：**

```python
class SimpleCostModel:
    def estimate(self, env: DecisionEnvelope, market, bars) -> Dict[str,float]:
        spread = 0.0
        if market.bid_px and market.ask_px:
            spread = (market.ask_px - market.bid_px) / ((market.ask_px + market.bid_px)/2) * 1e4  # bp
        # 粗略：滑点 ~ max(spread的一半, k * volatility)
        atr_bp = bars[-1].get("atr_bp", 5.0) if bars else 5.0
        slippage_bp = max(spread/2, 0.2*atr_bp)
        return {"slippage_bp": slippage_bp, "fees_bp": 0.3, "impact_bp": 0.0, "confidence": 0.6}
```

## 3) Intent Translation 策略（单型/价格围栏/子单/OCO）

> 策略只管**方向/目标/强度**，**翻译层**按**点差/波动/流动性**自动选择：`LMT / STP_LMT / IOC / TWAP/POV`，并附上**价格围栏**与**OCO保护**。

### 3.2 翻译器骨架

```python
from dataclasses import dataclass
from typing import Optional, Dict, Any

@dataclass
class ExecPlan:
    order_type: str              # MKT/LMT/STP_LMT
    side: str                    # BUY/SELL/SELL_SHORT
    qty: float
    limit_px: Optional[float]
    stop_px: Optional[float]
    tif: str                     # DAY/IOC
    price_collar_pct: float
    oco: Dict[str, Any]          # {'tp_px':..., 'sl_px':..., 'trail_atr':...}
    child: Dict[str, Any]        # TWAP/POV 计划或 NONE
    notes: Dict[str, Any]

class IntentTranslator:
    def __init__(self, policy_cfg, market_state_provider, tick_size_provider):
        self.cfg = policy_cfg
        self.ms = market_state_provider
        self.tick = tick_size_provider  # 提供 tick/lot

    def _px_from_ref(self, m, ref) -> Optional[float]:
        if ref == "mid":  return m.mid_px
        if ref == "last": return m.last_px
        if ref == "best":
            # 买用 ask，卖用 bid；调用处决定
            return None
        return m.mid_px

    def _clamp_collar(self, ref_px, limit_px, collar_pct):
        if not (ref_px and limit_px): return limit_px
        dev = abs(limit_px - ref_px)/ref_px*100.0
        if dev > collar_pct:
            return ref_px*(1.0 + collar_pct/100.0) if limit_px>ref_px else ref_px*(1.0 - collar_pct/100.0)
        return limit_px

    def _round_tick(self, px, t): 
        return None if px is None else round(round(px/t)*t, 10)

    async def translate(self, env: DecisionEnvelope) -> ExecPlan:
        m = await self.ms.get(env.symbol)
        tick = m.tick_size or 0.01
        side = "BUY" if env.target_qty>0 else ("SELL" if env.target_qty<0 else "BUY")
        qty = abs(env.target_qty)

        # 计算环境指标
        spread_bp = 0.0
        if m.bid_px and m.ask_px:
            spread_bp = (m.ask_px - m.bid_px)/((m.ask_px+m.bid_px)/2)*1e4
        atr_bp = env.extras.get("atr_bp", 6.0)
        top_liq = env.extras.get("top_liquidity_shares", 0)
        target_notional = env.max_notional

        # 按 policy 选桶
        bucket = "tight_spread_low_vol"
        for b in self.cfg["buckets"]:
            ok=True
            w=b["when"]
            def chk(k, cond):
                v = {"spread_bp":spread_bp,"atr_bp":atr_bp,"top_liquidity_shares":top_liq,"target_notional_usd":target_notional}.get(k, None)
                if v is None: return False
                if "lte" in cond and not (v <= cond["lte"]): return False
                if "lt"  in cond and not (v <  cond["lt"] ): return False
                if "gte" in cond and not (v >= cond["gte"]): return False
                if "gt"  in cond and not (v >  cond["gt"] ): return False
                return True
            for k,cond in w.items():
                if not chk(k,cond): ok=False; break
            if ok: bucket=b["name"]; action=b["action"]; break
        else:
            action=self.cfg["buckets"][0]["action"]

        # 价格参考
        ref_px = self._px_from_ref(m, action.get("ref","mid"))
        if action.get("ref")=="best":
            ref_px = m.ask_px if side=="BUY" else m.bid_px

        # 组装价格
        limit_px, stop_px = None, None
        if action["order_type"] in ("LMT","STP_LMT"):
            limit_px = (ref_px or m.last_px) + (action.get("offset_ticks",1) * (tick if side=="BUY" else -tick))
        if action["order_type"] in ("STP","STP_LMT"):
            stop_ticks = action.get("stop_offset_ticks",3)
            # BUY 触发在上方/ SELL 在下方
            stop_px = (ref_px or m.last_px) + (stop_ticks * (tick if side=="BUY" else -tick))

        # SSR 修正：卖空需高于bid至少1 tick
        if getattr(m, "ssr_active", False) and side in ("SELL_SHORT",) or (side=="SELL" and env.target_qty<0):
            if limit_px and m.bid_px:
                limit_px = max(limit_px, m.bid_px + tick)

        # 围栏与tick
        collar = self.cfg["defaults"]["price_collar_pct"]
        limit_px = self._round_tick(self._clamp_collar(ref_px, limit_px, collar), tick)
        stop_px  = self._round_tick(stop_px, tick)

        # OCO 保护
        oco_cfg = self.cfg["defaults"]["oco"]
        tp_px, sl_px = None, None
        if env.risk_overrides.catastrophic_stop_px:
            sl_px = env.risk_overrides.catastrophic_stop_px
        else:
            # 按 bp 近似设置
            ref = ref_px or m.last_px
            if ref:
                hard = oco_cfg["hard_stop_bp"]/1e4
                sl_px = ref*(1-hard) if side=="BUY" else ref*(1+hard)
        if env.risk_overrides.trailing_atr_mult:
            # 记录trail参数（执行器里按ATR移动，不在此算价）
            pass
        # 止盈
        if tp_px is None and (ref_px or m.last_px):
            bp = self.cfg["defaults"]["oco"]["take_profit_bp"]/1e4
            ref = ref_px or m.last_px
            tp_px = ref*(1+bp) if side=="BUY" else ref*(1-bp)
        tp_px = self._round_tick(tp_px, tick) if tp_px else None
        sl_px = self._round_tick(sl_px, tick) if sl_px else None

        # 子单（TWAP/POV）
        child = {"type":"NONE"}
        if action.get("child") == "TWAP_OR_POV":
            child = {"type":"TWAP","horizon_s": max(300, env.risk_overrides.time_stop_s or 600)}
        elif action.get("child") == "IOC_IF_LIQ_LOW" and top_liq < 200:
            child = {"type":"IOC","sweep_levels":1}

        tif = action.get("tif","DAY")
        # 最终计划
        plan = ExecPlan(
            order_type=action["order_type"], side=side, qty=qty,
            limit_px=limit_px, stop_px=stop_px, tif=tif,
            price_collar_pct=collar,
            oco={"tp_px":tp_px, "sl_px":sl_px, "trail_atr":env.risk_overrides.trailing_atr_mult},
            child=child,
            notes={"bucket": bucket, "spread_bp": spread_bp, "atr_bp": atr_bp, "top_liq": top_liq}
        )
        return plan
```

## 4) 策略引擎中的接线（最小工作流）

```python
# Tick (每策略独立 cadence_s 调度)
env = strategy.produce_envelope(symbol)     # 只做研究/打分 → 产出 Envelope

vres = await validator.validate(env)
if not vres.ok:
    audit.log(decision_id=env.decision_id, status="SKIP", reasons=vres.skip_reasons)
    return

# （可选）仲裁：同symbol相反方向只保留优先级高者
if not arbiter.admit(env):
    audit.log(decision_id=env.decision_id, status="DEFER", reasons=["arbitrated_out"])
    return

plan = await translator.translate(env)      # 单型/价格/OCO/子单/围栏 决策
# 风控（含 Reg-Lite）→ 资金预留 → 执行
risk_ok, risk_hits = await risk.approve(env, plan, ttl_ms=vres.effective_ttl_ms)
if not risk_ok:
    audit.log(decision_id=env.decision_id, status="REJECT", reasons=risk_hits)
    return

await executor.submit(env, plan)            # 下单（带幂等/错误矩阵/预留）
audit.log(decision_id=env.decision_id, status="SUBMITTED", notes=plan.notes)
```

## 6) 监控与指标（与决策质量强相关）

* `decision_freshness_ms_p95/p99`（bar_end→intent_publish）
* `decision_skipped_total{reason=...}`（分原因：stale/insufficient_history/no_nbbo/edge_insufficient…）
* `translator_bucket_selection_total{bucket=...}`（各桶命中占比）
* `order_type_histogram`（LMT/STP_LMT/IOC/TWAP/POV占比）
* `edge_minus_cost_p50/p90`（事前估 vs 事后实现对齐度）
* `oco_activation_rate{branch=tp|sl}` 与 `post-stop slippage p50/p90`

---

### 你现在可以立刻做的两步

1. 把 **Envelope/Validator/Translator** 三段直接贴进你的策略引擎（或作为独立模块被引擎调用）；
2. 用一支策略跑 **影子模式**：记录 `SKIP/REJECT/SUBMITTED` 分布与 `bucket` 命中，验证新鲜度与成本覆盖是否按预期工作。
