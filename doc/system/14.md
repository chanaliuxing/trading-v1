# ① Redis Key 生命周期状态机（用于 5s Bar 聚合器）

**Key 前缀**：`bar5s:{symbol}`
**Value（JSON）**：

```json
{
  "bucket": "UTC秒对齐起点(例如 2025-10-02T15:04:55Z)",
  "open": 221.10, "high": 221.50, "low": 221.05, "close": 221.32,
  "vol": 12000,
  "vwap_num": 2.6e9, "vwap_den": 12000,
  "wm_ts": "最近合并tick的时间戳(UTC)",
  "late_count": 0
}
```

**状态机（文字版）**

* `EMPTY → ACTIVE`：首次 tick 到达，创建新桶（`bucket=floor_to_5s(ts)`），TTL=15s
* `ACTIVE(同桶)`：tick 合并 OHLCV；更新 `wm_ts`；TTL 刷新为 15s
* `ACTIVE(切桶)`：若 `now ≥ bucket+5s+emit_buffer`，**发出**旧桶（变 FINAL），删除旧 Key；然后 `ACTIVE` 新桶
* `ACTIVE(迟到 tick)`：若 `tick.ts > bucket+5s+max_late` → 丢入 `late_count+1`（不改历史），交给回补
* `KILL/重启`：读 Key 恢复到 `ACTIVE`；若 Key 缺失，允许从 CH 拉最近 1–2 桶兜底
* `SWEEP`：后台每 1s 扫描，凡 `bucket+5s+emit_buffer ≤ now` 的 Key 全部发出并删除

**推荐参数**

* `emit_buffer_ms = 200~400`（吸收最后抖动）
* `max_late_ms = 2000`（迟到阈）
* Key TTL = `2*window + 60s`（默认 15s）

# ② 回补（Backfill）SQL 与 IB 历史接口参数模板

## 2.1 缺口探针（ClickHouse）

**当日某 symbol 是否缺 5s 桶：**

```sql
WITH arr AS (
  SELECT groupArray(toUnixTimestamp(ts_start)) AS a
  FROM qsys.bar_5s_v2
  WHERE symbol = {sym:String} AND trade_date = today()
)
SELECT arrayFilter((x, y) -> y - x > 5, a, arrayConcat([a[1]], a)) AS gaps
FROM arr;
```

> 若 `gaps` 非空，表示有间隔>5s 的缺口，需要回补。

## 2.2 回补写入（5s）

```sql
INSERT INTO qsys.bar_5s_v2
(symbol, ts_start, ts_end, open, high, low, close, vol, vwap, rth, source, calc_mode, event_id)
VALUES
-- 多行批量插入，每行 event_id 唯一，calc_mode='backfill'
```

**去重策略**：`ReplacingMergeTree(event_id)`；回补 vs 实时冲突时，以**更后写入**为准（或比较 `_version`）。

## 2.3 IB 历史接口（`ib_insync`）参数模板

### A) 拉 1 分钟 K（作为 5s 插值近似，权限稳定）

```python
# 合约：Stock('AAPL','SMART','USD') 或具体交易所
ib.reqHistoricalData(
    contract,
    endDateTime='',              # 现在
    durationStr='2 D',           # 回补常用：缺一段取稍大范围
    barSizeSetting='1 min',
    whatToShow='TRADES',
    useRTH=True,                 # 与RTH一致
    formatDate=2, keepUpToDate=False
)
```

* 将 1m bar 线性或基于成交量分配成 5s（**近似**），用于应急回补。

### B) 拉 5s（若账户有权限，优选）

```python
ib.reqHistoricalData(
    contract,
    endDateTime='',
    durationStr='1800 S',        # 最多 1800s; 分批回补
    barSizeSetting='5 secs',
    whatToShow='TRADES',
    useRTH=True,
    formatDate=2, keepUpToDate=False
)
```

* 直接标准化为 5s 桶，`calc_mode='backfill'` 写入即可。

**注意**

* IB 历史限流严格：分批 + 退避（指数回退）；
* 回补任务应节流：**单 symbol 并发=1**，全局并发≤5；
* 回补完成后，触发一次“缺口复检”。

# ③ M1 自动化验收：离线 E2E Harness（纯 Python，内存总线）

> 目标：**不连 Kafka/PG/CH/Redis** 也能在本机跑通 **资金预留→下单→OCO→释放** 与 **tick→5s bar 聚合** 的核心逻辑。
> 用它先验“算法正确性/幂等/时序”，等服务化后再接真环境。

## 3.1 内存消息总线（代替 Kafka）

```python
import asyncio, time, uuid
from collections import defaultdict, deque
from dataclasses import dataclass

class Bus:
    def __init__(self):
        self.topics = defaultdict(list)   # topic -> list[asyncio.Queue]

    def subscribe(self, topic):
        q = asyncio.Queue()
        self.topics[topic].append(q)
        return q

    async def publish(self, topic, key, value):
        for q in self.topics[topic]:
            await q.put({"key": key, "value": value})

bus = Bus()
now_us = lambda: int(time.time() * 1e6)
```

## 3.2 假 PG 账本（幂等预留/释放 + 咨询锁模拟）

```python
class FakeLedger:
    def __init__(self, cap_usd):
        self.cap = cap_usd
        self.reserved = 0.0
        self.lock = asyncio.Lock()
        self.res_map = {}  # idem -> reserved_usd

    async def approve_and_reserve(self, notional_usd, buffer_bps, idem):
        async with self.lock:  # 模拟 advisory_xact_lock
            if idem in self.res_map:  # 幂等
                return True, self.res_map[idem]
            need = notional_usd * (1 + buffer_bps/10000.0)
            if self.reserved + need > self.cap:
                return False, 0.0
            self.reserved += need
            self.res_map[idem] = need
            return True, need

    async def release(self, idem):
        async with self.lock:
            if idem not in self.res_map:
                return True, 0.0
            amt = self.res_map.pop(idem)
            self.reserved = max(self.reserved - amt, 0.0)
            return True, amt
```

## 3.3 风控服务（消费请求→产出决策）

```python
class RiskService:
    def __init__(self, bus, ledger):
        self.bus, self.ledger = bus, ledger

    async def run(self):
        q = self.bus.subscribe("engine.order.request.v2")
        while True:
            msg = await q.get()
            data = msg["value"]["data"]; meta = msg["value"]["metadata"]
            ok, reserved = await self.ledger.approve_and_reserve(
                notional_usd=data["notional_hint_usd"],
                buffer_bps=data.get("slippage_buffer_bps", 10),
                idem=meta["idempotency_key"]
            )
            out = {
                "schema_v": 2,
                "metadata": {"event_id": str(uuid.uuid4()), "ts_us": now_us(),
                             "producer":"risk", "idempotency_key": meta["idempotency_key"]},
                "data": {
                    "decision": "APPROVED" if ok else "DENIED",
                    "reservation": {"reservation_id": str(uuid.uuid4()),
                                    "reserved_usd": reserved, "buffer_bps": data.get("slippage_buffer_bps", 10)},
                    "limits_snapshot": {"strategy_capital_limit_usd": self.ledger.cap,
                                        "strategy_reserved_usd": self.ledger.reserved}
                }
            }
            await self.bus.publish("risk.decision.v2", key=msg["key"], value=out)
```

## 3.4 执行器（首填即 OCO + 终态释放）

```python
class ExecService:
    def __init__(self, bus, ledger):
        self.bus, self.ledger = bus, ledger
        self.oco_attached = set()      # order_id set
        self.orders = {}               # idem -> order_id

    async def run(self):
        q = self.bus.subscribe("risk.decision.v2")
        while True:
            msg = await q.get()
            meta, dec = msg["value"]["metadata"], msg["value"]["data"]["decision"]
            idem = meta["idempotency_key"]
            if dec != "APPROVED":   # 拒单不下
                continue
            oid = self.orders.get(idem) or str(uuid.uuid4())
            self.orders[idem] = oid
            # 提交订单
            await self._status(oid, state="SUBMITTED", idem=idem)
            # 模拟首笔成交→立即挂 OCO
            await asyncio.sleep(0.05)
            await self._fill(oid, qty=100, px=221.34, idem=idem)
            await self._attach_oco(oid)
            # 模拟触发止盈→终态释放
            await asyncio.sleep(0.05)
            await self._status(oid, state="FILLED", idem=idem)
            await self._release(idem)

    async def _status(self, oid, state, idem):
        payload = {"schema_v":2, "metadata":{"event_id":str(uuid.uuid4()),"ts_us":now_us(),
                    "producer":"exec","idempotency_key":idem},
                   "data":{"order_id":oid,"state":state}}
        await self.bus.publish("exec.order.status.v2", key=oid, value=payload)

    async def _fill(self, oid, qty, px, idem):
        payload = {"schema_v":2, "metadata":{"event_id":str(uuid.uuid4()),"ts_us":now_us(),
                    "producer":"exec","idempotency_key":idem},
                   "data":{"order_id":oid,"qty":qty,"px":px}}
        await self.bus.publish("exec.fill.v2", key=oid, value=payload)

    async def _attach_oco(self, oid):
        self.oco_attached.add(oid)
        # 这里可发布两个子单的 status 事件（省略）

    async def _release(self, idem):
        await self.ledger.release(idem)
```

## 3.5 5s 聚合器（内存版，含 watermark/emit_buffer）

```python
@dataclass
class Tick: symbol:str; ts_us:int; px:float; qty:int

class InMemAgg:
    def __init__(self, bus, emit_buffer_ms=300, max_late_ms=2000):
        self.bus = bus
        self.emit_buf = emit_buffer_ms*1000; self.max_late = max_late_ms*1000
        self.state = {}  # sym -> dict

    def _bucket(self, ts_us): return (ts_us//5_000_000)*5_000_000  # 5s 对齐(us)

    async def on_tick(self, t: Tick):
        b = self._bucket(t.ts_us)
        st = self.state.get(t.symbol)
        if not st:
            st = {"bucket": b, "open": t.px, "high": t.px, "low": t.px, "close": t.px,
                  "vol": t.qty, "vwap_num": t.px*t.qty, "vwap_den": t.qty, "wm_ts": t.ts_us, "late_count":0}
            self.state[t.symbol] = st; return
        # 切桶
        if b != st["bucket"]:
            # 是否可以发出
            if t.ts_us >= st["bucket"] + 5_000_000 + self.emit_buf:
                await self._emit(t.symbol, st)
                self.state.pop(t.symbol, None)
            # 新桶
            st = {"bucket": b, "open": t.px, "high": t.px, "low": t.px, "close": t.px,
                  "vol": t.qty, "vwap_num": t.px*t.qty, "vwap_den": t.qty, "wm_ts": t.ts_us, "late_count":0}
            self.state[t.symbol] = st; return
        # 同桶迟到判定
        if t.ts_us > st["bucket"] + 5_000_000 + self.max_late:
            st["late_count"] += 1
            return
        # 合并
        st["high"] = max(st["high"], t.px)
        st["low"]  = min(st["low"], t.px)
        st["close"]= t.px
        st["vol"] += t.qty
        st["vwap_num"] += t.px*t.qty
        st["vwap_den"] += t.qty
        st["wm_ts"] = max(st["wm_ts"], t.ts_us)

    async def flush_overdue(self, now_us):
        for sym, st in list(self.state.items()):
            if now_us >= st["bucket"] + 5_000_000 + self.emit_buf:
                await self._emit(sym, st); self.state.pop(sym, None)

    async def _emit(self, sym, st):
        bar = {
          "schema_v":2,
          "metadata":{"event_id":str(uuid.uuid4()),"ts_us":now_us(),"producer":"agg"},
          "data":{
            "symbol": sym,
            "ts_start_us": st["bucket"],
            "ts_end_us": st["bucket"]+5_000_000,
            "open": st["open"], "high": st["high"], "low": st["low"], "close": st["close"],
            "vol": st["vol"],
            "vwap": (st["vwap_num"]/st["vwap_den"]) if st["vwap_den"] else None,
            "rth": True, "source": "AGG", "calc_mode": "realtime",
            "late_count": st["late_count"]
          }
        }
        await self.bus.publish("md.bar.5s.v2", key=sym, value=bar)
```

## 3.6 策略引擎最小触发（只发下单意图）

class MiniEngine:
    def __init__(self, bus):
        self.bus = bus
    async def place_limit(self, strategy_id, symbol, qty, limit_px):
        idem = f"ord:req:{strategy_id}:{symbol}:{uuid.uuid4()}"
        payload = {
          "schema_v":2,
          "metadata":{"event_id":str(uuid.uuid4()),"ts_us":now_us(),"producer":"engine","idempotency_key":idem},
          "data":{
            "strategy_id":strategy_id, "symbol":symbol, "side":"BUY" if qty>0 else "SELL",
            "order_type":"LMT","qty":abs(qty),"limit_px":float(limit_px),"stop_px":None,"tif":"DAY",
            "notional_hint_usd":abs(qty)*float(limit_px),"slippage_buffer_bps":8,"time_stop_s":900,
            "tags":["demo","5s"],"params_hash":"demo"
          }
        }
        await self.bus.publish("engine.order.request.v2", key=f"{strategy_id}:{symbol}", value=payload)
        return idem

async def test_reserve_exec_release():
    bus = Bus(); ledger = FakeLedger(cap_usd=100_000)
    risk = RiskService(bus, ledger); execv = ExecService(bus, ledger); eng = MiniEngine(bus)

### 用例 B：并发冲关（同 strategy×symbol）

```python
async def test_concurrency_gate():
    bus = Bus(); ledger = FakeLedger(cap_usd=10_000)
    risk = RiskService(bus, ledger); execv = ExecService(bus, ledger); eng = MiniEngine(bus)
    asyncio.create_task(risk.run()); asyncio.create_task(execv.run())
    async def fire():
        await eng.place_limit("S1","AAPL",50,100.0)
    await asyncio.gather(*[fire() for _ in range(10)])
    await asyncio.sleep(0.5)
    # 由于 FakeLedger 没有 symbol 粒度锁，示例里用“资金上限”导致部分 DENIED
    # 正式服务会用 PG advisory lock 串行化；这里断言“非全部通过”即可
    assert ledger.reserved == 0.0
```

### 用例 C：tick→5s bar（含迟到丢弃）

```python
async def test_tick_to_bar():
    bus = Bus(); agg = InMemAgg(bus, emit_buffer_ms=300, max_late_ms=2000)
    # 合成 12 根 5s 桶
    t0 = now_us()
    # 每桶塞 10 个 tick，包含 ±1500ms 乱序；再塞一个超迟到 tick（应计作 late_count）
    for i in range(12):
        bucket_start = t0 + i*5_000_000
        for j in range(10):
            ts = bucket_start + 200_000 + (j*20_000) + ([-1,1][j%2]*1_500_000)  # ±1.5s 抖动
            await agg.on_tick(Tick("AAPL", ts, px=100+i*0.1+j*0.01, qty=10))
        # 超迟到
        await agg.on_tick(Tick("AAPL", bucket_start + 5_000_000 + 3_500_000, px=99.0, qty=1))
        await agg.flush_overdue(bucket_start + 5_000_000 + 400_000)

    # 收集输出
    q = bus.subscribe("md.bar.5s.v2")
    bars = []
    while not q.empty():
        bars.append((await q.get())["value"]["data"])
    assert len(bars) == 12, f"应有12根bar，实际 {len(bars)}"
    assert all(b["late_count"] >= 1 for b in bars), "每桶应至少记录到一个迟到被丢弃"
```

## 你怎么用这份 Harness

* 把 3.1–3.7 片段放进同一个 Python 脚本（或测试框架里），直接 `asyncio.run()` 顺序跑三个用例；
* 通过后，按我们已定的接口把总线替换成 Kafka、账本换 PG 存储过程、聚合器状态换 Redis；
* 同名指标（成功率/延迟/跳过原因）也能同步接到正式的 Prom 面板。
