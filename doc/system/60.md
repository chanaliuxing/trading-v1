# 1) 目标与范围

* 将策略从**影子（不下单）**到**金丝雀（极小资金）**再到**全量**的过程标准化与自动化。
* 所有发布**受安全闸（Safety Gates）**控制；违反门槛自动**暂停/回退**；人工可一键 KillSwitch。
* 全流程**可观测**（SLO、错误、风控事件、PnL）与**可审计**（param_hash、变更记录、操作日志）。

---

# 2) 角色与名词

* **策略实例（Strategy Instance）**：`strategy_id + param_hash` 的具体运行体。
* **发布单（Release Plan）**：一次从影子到生产的过程配置（见 §6 的 YAML）。
* **控制器（Rollout Controller）**：自动评估门槛、推进/回退的后台服务。
* **安全闸（Safety Gates）**：技术 SLO、风控健康、市场风险、运维健康四大类门槛。
* **金丝雀配额（Canary Quota）**：资金、并发、订单速率、每标的上限等硬限制。

---

# 3) 环境与通道

* **数据通道**：Kafka（`md.features.*`、`md.bars.*`）、ClickHouse（历史/回补）。
* **执行通道**：

  * 影子：**ShadowBroker**（本地撮合/IBKR Paper 对照）
  * 金丝雀/生产：IBKR Live（我们已有的 **Error Matrix + Reg-Lite + OCO** 守护）
* **状态总线**：StateBus（管理暂停/恢复/KillSwitch 的跨进程控制命令）。
* **账本/风控**：Reservation Ledger（每策略资金池）+ Arbitration（同标的仲裁）。

# 4) 发布状态机（策略发布生命周期）

```
DRAFT → SHADOW → PAPER(可选) → CANARY → RAMP_x% → FULL
   \           ↘        ↘             ↘
    \            ↘        ↘             ↘
     └──────────── PAUSED ←─────────── ROLLBACK
                                  ↘
                                   RETIRED
```

* **进入/退出钩子**：

  * 进入：校验配置 → 预热（回读历史、指标对齐）→ 健康检查（连接、滞后、队列积压）
  * 退出：**Cancel & Flatten**（撤挂 & 平仓）→ 释放预留 → 记录审计

# 5) 安全闸（Safety Gates）——四大类门槛

## 5.1 技术 SLO（来自第 6 步）

* `p95(bar→env) ≤ 800ms`、`p95(env→submit) ≤ 1200ms`；连续 2 个观察窗超线 → **暂停并放宽节奏**。
* `intent_expired_total / submitted ≤ 2%`。
* Kafka/CH 滞后：`bars/features publish lag ≤ 2s`。

## 5.2 执行/风控健康

* 订单拒绝率（券商/Reg-Lite/风控）`≤ 1%`；
* Error Matrix 重试达到**上限**占比 `≤ 0.2%`；
* OCO 不一致（应有双子单，实则缺失或方向错）= 0；
* Reservation 看门狗强撤次数占比 `≤ 0.1%`。

## 5.3 市场风险/业绩门槛（金丝雀期间更严格）

* 单策略**当日回撤** ≤ `X%`（默认 1%）；
* 单标的**滑点劣化**（成交均价 vs 中位估计） ≤ `Y bps`；
* **连亏暂停**规则（来自第 5 步风控）触发 → 自动降阶/暂停。

## 5.4 运维/依赖健康

* IBKR 连接重连频率 ≤ `N 次/小时`；
* Kafka 消费滞后 `consumer_lag` ≤ 阈值；
* CH `INSERT`/`MV` 错误率 ~ 0；
* 关键任务心跳（features publisher、controller、executor）无缺口。

# 7) 控制器骨架（Rollout Controller）

> 负责：**评估门槛 → 推进/回退**；调用 **StateBus** 控制策略运行级别；与 **ReserveLedger** 同步资金上限；异常时**Cancel & Flatten**。

```python
# -*- coding: utf-8 -*-
import asyncio, time
from dataclasses import dataclass
from typing import Dict, Any, Optional

def now_s(): return int(time.time())

@dataclass
class Step:
    name: str
    min_minutes: int
    capital_usd: float = 0.0
    per_symbol_max_usd: float = 0.0
    max_concurrent_plans: int = 1
    gates: Dict[str, Any] = None

class RolloutController:
    def __init__(self, plan: Dict[str,Any], statebus, risk_api, ledger, arbiter, logger, metrics):
        self.plan = plan; self.bus = statebus; self.risk = risk_api
        self.ledger = ledger; self.arb = arbiter
        self.log = logger; self.m = metrics
        self.cur_step_idx = 0
        self.step_started_at = now_s()
        self.paused = False

    async def apply_step_limits(self, step: Step):
        # 1) 每策略资金池限额（第3步 ReserveLedger 已执行硬约束）
        await self.risk.set_strategy_caps(
            strategy_id=self.plan["strategy_id"], cap_usd=step.capital_usd, per_symbol_cap=step.per_symbol_max_usd
        )
        # 2) 并发/仲裁限制
        await self.arb.set_symbol_global_caps(max_notional_usd=step.per_symbol_max_usd or 1e12)
        await self.bus.set_max_concurrency(self.plan["strategy_id"], step.max_concurrent_plans)
        self.log.info(f"[rollout] applied limits for step={step.name}")

    async def check_gates(self, step: Step) -> (bool, Dict[str,Any]):
        # 汇总 Prometheus/DB 指标：SLO、reject、dd、qscore、lag 等
        stats = await collect_stats(self.plan["strategy_id"], self.plan["symbols"], window_min=step.min_minutes)
        ok = True; reasons = []
        def fail(why, val=None): 
            nonlocal ok; ok=False; reasons.append((why,val))
        g = step.gates or {}

        if g.get("tech_slo_p95", False):
            if stats["p95_bar_env_ms"] > 800 or stats["p95_env_submit_ms"] > 1200:
                fail("slo_latency", (stats["p95_bar_env_ms"], stats["p95_env_submit_ms"]))

        if "data_qscore_avg" in g and stats["qscore_avg"] < g["data_qscore_avg"]:
            fail("data_qscore_low", stats["qscore_avg"])

        if "reject_rate_max" in g and stats["reject_rate"] > g["reject_rate_max"]:
            fail("reject_rate", stats["reject_rate"])

        if "dd_intraday_max" in g and stats["drawdown_intraday"] > g["dd_intraday_max"]:
            fail("drawdown_intraday", stats["drawdown_intraday"])

        return ok, {"stats": stats, "reasons": reasons}

    async def promote_or_hold(self):
        step_cfg = self.plan["steps"][self.cur_step_idx]
        step = Step(**step_cfg)
        # 若刚进入/重启，先施加本步限额
        if now_s() - self.step_started_at < 2:
            await self.apply_step_limits(step)

        # 最低驻留时间
        if now_s() - self.step_started_at < step.min_minutes*60:
            return  # hold 直到时长满足

        ok, meta = await self.check_gates(step)
        if ok and self.cur_step_idx < len(self.plan["steps"])-1:
            # 前进到下一步
            self.cur_step_idx += 1
            self.step_started_at = now_s()
            next_step = Step(**self.plan["steps"][self.cur_step_idx])
            await self.apply_step_limits(next_step)
            self.log.warning(f"[rollout] promote → {next_step.name}")
            self.m.rollout_promotions_total.inc()
        elif not ok:
            await self.rollback(meta["reasons"])

    async def rollback(self, reasons):
        # 立即暂停新意图 + 撤单 + 平仓 + 释放预留
        self.log.error(f"[rollout] rollback due to: {reasons}")
        await self.bus.pause_strategy(self.plan["strategy_id"], reason="rollback")
        await cancel_all_open_orders(self.plan["strategy_id"])
        await flatten_all_positions(self.plan["strategy_id"])
        await release_all_reservations(self.plan["strategy_id"], cause="rollback")
        self.cur_step_idx = 0
        self.step_started_at = now_s()
        await self.apply_step_limits(Step(**self.plan["steps"][0]))
        self.m.rollout_rollbacks_total.inc()

    async def loop(self):
        # 主循环：每 30s 评估一次
        while True:
            try:
                await self.promote_or_hold()
            except Exception as e:
                self.log.exception(f"[rollout] controller error: {e}")
            await asyncio.sleep(30)
```

# 8) 自动回退触发（KillSwitch & Circuit Breakers）

* **全局 KillSwitch**（StateBus）：`/control/kill_all` → 全体暂停 → **撤单+平仓** → 释放预留 → 标记 `SYSTEM_HALTED`。
* **策略 KillSwitch**：`/control/kill/{strategy_id}` → 同上，仅作用于该策略。
* **断路器（Circuit Breakers）**：

  * 按 **回撤**、**拒单率**、**订单错误**、**数据缺口率** 阈值触发；
  * 触发后进入 **PAUSED** 状态，等待人工复位或到期自动重试（冷却 30min）。

# 12) 灾备与演练（DR）

* **IBKR 断连演练**：模拟断连 ≥ `broker_disconnect_s` → 控制器触发 `PAUSED` + **撤单+平仓**；
* **Kafka 停顿**：bars/features 发布滞后 > 5s → **停止提交意图**（TTL 自然过期）；
* **ClickHouse 写入失败**：仅影响历史/特征重算，策略热链不依赖 CH，可继续，但需要**降级告警**；
* **进程重启**：Reconciler 领养订单 + Reservation 重建（第 3 步）；OCO 恢复（第 4 步）。

# 13) 金丝雀配额模型（细化）

* **资金**：`strategy_cap_usd`、`per_symbol_cap_usd`；
* **并发**：`max_concurrent_plans`；
* **速率**：`max_orders_per_min`；
* **标的白名单**：仅允许在白名单内下单（可按 step 扩展）；
* **时段**：仅在指定交易时段/避开开盘前 5 分钟与收盘前 5 分钟。

# 14) 发布验收标准（示例）

* 影子期 ≥ 60min，技术 SLO 过线，影子 vs Paper 成交模拟偏差（滑点模拟）`< 5 bps`。
* 金丝雀期 ≥ 120min，拒单率 < 1%，当日 DD < 0.5%，WD 强撤 = 0。
* RAMP_10 / RAMP_25 各 ≥ 180/240min，指标稳定，无连续 2 天回撤超 1%。
* FULL：进入持续运行，开启**持续门槛**监控（任何门槛破裂 → 自动-暂停-回退）。

---

# 15) 与前 1–9 步的对齐

* **第 1–2 步**（Reg-Lite/错误矩阵）：发布期间所有下单仍受修复/退避，避免“改单风暴”。
* **第 3 步**（Reservation WD）：回退/暂停必定释放预留；TTL 过期自动清理。
* **第 4 步**（OCO 编舞）：回退时先**取消保护**再平仓；反手流程由控制器持锁编排。
* **第 5 步**（仲裁）：金丝雀期间建议 `preempt=never`；进入 FULL 后可升级为 `price_better`。
* **第 6 步**（TTL/SLO）：发布门槛直接复用 p95 指标。
* **第 7–8 步**（CH 与特征层）：发布前跑**回补重算**，保证开盘即有完整 warmup；运行期监控 `ver` 波动与质量分。
