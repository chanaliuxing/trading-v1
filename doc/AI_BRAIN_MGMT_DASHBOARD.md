# AI Brain - 管理视图 使用指南

**Dashboard URL**: http://localhost:3000/d/ai-brain-mgmt/
**设计理念**: 用人话告诉你 AI 在做什么,你应该怎么办
**目标用户**: 系统管理员、交易员、基金经理

---

## 🎯 这个 Dashboard 和之前有什么不同?

### 之前的 Dashboard (技术视图)
- ❌ 显示 `diagnosis: "no_trading_history_due_to_new_system_init"`
- ❌ 显示 JSON 字段和数组
- ❌ 让你自己猜 "这意味着什么"
- ❌ 没有告诉你 "我该怎么办"

### 现在的 Dashboard (管理视图)
- ✅ 显示 "系统刚启动，正在收集数据"
- ✅ 显示 "AI 说: 你好！我刚启动,还没有交易历史数据..."
- ✅ 明确告诉你 "你需要做什么: 无 - 让我继续跑"
- ✅ 给你具体的修复步骤和命令

## 📊 Dashboard 结构

### Row 1: 🚦 一眼健康检查 (最重要!)

打开 dashboard 第一眼就看到系统是否正常。

#### Panel: AI 大脑状态

**显示内容**:
```
🟢 正常运行
```

**颜色含义**:
- 🟢 **绿色 "正常运行"**: 最后活动 < 1 小时,系统健康
- 🟡 **黄色 "轻微延迟"**: 1-2 小时未活动,注意观察
- 🟠 **橙色 "数据过期"**: 2-6 小时未活动,需要关注
- 🔴 **红色 "已停止"**: > 6 小时未活动,**需要立即修复**

**你应该做什么**:
- 🟢 绿色: 什么都不用做,继续查看其他 panels
- 🟡 黄色: 继续观察,如果变橙色/红色再处理
- 🟠/🔴 橙色/红色: **立即** 查看 Row 4 (问题排查)

---

#### Panel: 最后活动

**显示内容**:
```
11月01日 14:06
```

**用途**:
- 配合 "AI 大脑状态" 使用
- 快速判断 AI 多久没活动了

---

#### Panel: 今日 AI 活动

**显示内容**:
```
调用次数: 23
分析次数: 12
决策次数: 11
```

**用途**:
- 了解 AI 今天有多活跃
- 正常情况下,每小时应该有几次调用
- 如果今天调用次数是 0,说明 AI 根本没运行

---

### Row 2: 🤖 AI 大脑在说什么

**这是最有价值的部分** - 把 AI 的技术输出翻译成人话

#### Panel: AI 大脑的最新分析

**显示内容示例** (系统刚启动时):

```markdown
# 🤖 AI 大脑说:

**当前状态**: 系统刚启动，正在收集数据

**AI 的分析**:
你好！我刚启动，还没有交易历史数据。我需要先观察 2-4 小时，
收集一些数据，然后才能给你更好的建议。

---

**AI 建议你**:
• ✅ 继续运行系统 (我会自动收集数据)
• ✅ 保持当前设置 (已启用保护措施)
• ❌ 不要手动调整参数 (等我收集够数据)

---

**下一步**:
⏱️ 预计 2-4 小时后，我会有第一次参数优化建议

---

*分析时间: 11月01日 14:00*
*置信度: 90%*
```

**你能理解什么**:
- ✅ AI 当前在什么状态 (刚启动 / 正常运行 / 有问题)
- ✅ AI 为什么这么想 (没有数据 / 性能下降 / 风险过高)
- ✅ AI 建议你做什么 (具体的行动清单)
- ✅ 接下来会发生什么 (预期时间线)

---

### Row 3: ⚙️ AI 刚才做的配置修改

**显示 AI 最近一次修改系统配置的详情**

#### Panel: 最近一次配置修改

**显示内容示例**:

```markdown
# ⚙️ AI 修改了系统配置

**修改时间**: 11月01日 14:06

**你能理解什么**:
- ✅ AI 修改了哪些参数 (用人话,不是 config key)
- ✅ AI 为什么要改 (原因说明)
- ✅ 这个修改对交易有什么实际影响 (会发生什么)
- ✅ 如果不同意怎么办 (可以手动覆盖)

## 🎯 使用场景

### 场景 1: 每日例行检查

**时间**: 每天早上开盘前

**步骤**:
1. 打开 Dashboard: http://localhost:3000/d/ai-brain-mgmt/
2. 查看 "AI 大脑状态"
   - 🟢 绿色: 系统正常,继续
   - 🔴 红色: 立即修复 (见场景 3)
3. 阅读 "AI 大脑的最新分析"
   - 了解 AI 当前的状态
   - 查看 AI 的建议
4. 查看 "最近一次配置修改"
   - 了解 AI 昨天做了什么调整
   - 确认修改是否合理

**预计耗时**: 2-3 分钟

---

### 场景 2: 理解 AI 的决策

**触发**: 你发现交易行为异常 (如突然停止交易)

**步骤**:
1. 打开 Dashboard
2. 查看 "AI 大脑的最新分析"
   - 看 "当前状态" 是什么
   - 阅读 "AI 的分析" 了解原因
3. 查看 "最近一次配置修改"
   - 确认 AI 是否修改了相关参数
   - 查看 "实际影响" 了解为什么会这样

**示例**:
```
你发现: 系统今天没有开新仓

Dashboard 显示:
  当前状态: 性能下降
  AI 说: "过去 2 小时策略准确率下降,我暂停了新开仓"
  修改了: • 禁止新开仓: true
  实际影响: 系统会继续管理现有仓位,但不会开新仓

你理解了: AI 检测到策略表现不好,主动降低风险
```

---

### 场景 3: AI 大脑停止故障排查

**触发**: "AI 大脑状态" 显示 🔴 红色

**步骤**:
1. 展开 Row 4 (问题排查)
2. 复制 "步骤 1" 的命令,在终端运行:
   ```bash
   ps aux | grep orchestrator
   ```
3. 如果没有输出 (进程不存在):
   - 复制 "步骤 2" 的命令重启:
     ```bash
     cd .
     python scripts/ai_trader/orchestrator.py &
     ```
4. 运行 "步骤 3" 查看日志,确认没有错误:
   ```bash
   tail -50 logs/ai_brain_orchestrator.log
   ```
5. 等待 1-2 分钟,刷新 Dashboard
6. 验证 "AI 大脑状态" 变为 🟢 绿色

**预计修复时间**: 3-5 分钟

---

### 场景 4: 评估 AI 的建议是否合理

**触发**: 你想确认 AI 的决策是否正确

**步骤**:
1. 查看 "AI 大脑的最新分析"
2. 重点关注:
   - **置信度**: 如果 > 80%,AI 通常是对的
   - **AI 的分析**: 原因是否合理
   - **建议你**: 行动是否可执行
3. 查看 "最近一次配置修改"
   - **实际影响**: 这个修改是否符合你的风险偏好

**判断标准**:
- ✅ **好的建议**:
  - 置信度高 (> 80%)
  - 原因清晰合理
  - 影响可预测

- ⚠️ **需要审查的建议**:
  - 置信度低 (< 60%)
  - 原因模糊
  - 影响太激进或太保守

**如果不同意**:
- 在 `config.yml` 中手动覆盖 AI 的修改
- AI 会学习你的反馈 (未来版本)

## 💡 设计原则

### 1. 用人话,不要用代码

❌ **技术视图**:
```
diagnosis: "no_trading_history_due_to_new_system_init"
```

✅ **管理视图**:
```
当前状态: 系统刚启动，正在收集数据

AI 说: "你好！我刚启动,还没有交易历史数据。我需要先观察 2-4 小时..."
```

---

### 2. 告诉我"为什么"和"怎么办"

❌ **技术视图**:
```
最后更新: 11 小时前
```

✅ **管理视图**:
```
🔴 AI 大脑已停止 11 小时

影响: 系统无法根据市场变化自动调整参数

修复步骤:
1. [一键命令: ps aux | grep orchestrator]
2. [一键命令: python scripts/ai_trader/orchestrator.py &]
```

---

### 3. 关注"效果",不要只显示"动作"

❌ **技术视图**:
```
risk_management.guardian.dd_intraday_pct = -5.0
```

✅ **管理视图**:
```
AI 设置了 -5% 回撤限制

实际影响:
✅ 如果今天亏损达到 -5%,系统会自动停止交易
✅ 这是一个保护措施,避免单日亏损过大
⚠️ 可能会限制盈利能力 (过于保守时)
```

---

### 4. 给我"下一步",不要让我猜

❌ **技术视图**:
```
diagnosis: "performance_degradation"
```

✅ **管理视图**:
```
⚠️ AI 检测到性能下降

原因: 过去 2 小时,策略准确率从 65% 降到 45%

AI 已经做了:
- 停止新开仓
- 减少仓位大小

你需要做什么:
🔍 [查看详细性能报告]
⚙️ [手动调整策略参数]
📞 [等待 AI 自动恢复] (推荐)

预计恢复时间: 1-2 小时
```
