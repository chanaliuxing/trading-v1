# 你现在的地基（复盘）

* **数据**：ClickHouse 的 `features_*` 表（分钟级等），我们已加了 `feature_cutoff_ts`、泄漏防线与 embargo。

# 集成思路（不动主干，按层插入）

## 1) 抽象一层“模型适配器”（ModelAdapter）

统一 XGBoost/LSTM 的训练与推理接口，供 **Walk-Forward** 和 **实时**共用：

```text
models/
  base.py        # 抽象接口：fit/predict/save/load/metadata
  xgb_model.py   # XGBoost 实现（tabular）
  lstm_model.py  # LSTM 实现（序列）
```

### 统一接口（关键点）

* `fit(df_train, y_train, df_valid=None, sample_weight=None, groups=None, **kwargs)`
* `predict(df)` → 预测值（回归：期望收益；分类：p_up）
* `decision_signal(pred, scheme)` → 转成交易信号/仓位（阈值/quantile/score→[-1,1]）
* `save(path) / load(path)` + `metadata()`（含版本、超参、特征列、lookback、训练窗口、seed）

> **XGBoost**：适合大量结构化特征（秒/分级技术指标、交叉特征、新闻情绪数值化）；
> **LSTM**：建模时序依赖（滑动窗口 lookback），对“序列形态/滞后”更敏感。

---

## 2) 标签与任务定义（安全、可配置）

* **预测目标**：`y = log(close_{t+H}/close_t)` 或 `ret_{t→t+H}`；H 可配置（1m/5m/30m）。
* **任务类型**：回归（直接预测期望收益）或二分类（上涨概率），配置中指定：`"task": "reg" | "clf"`
* **泄漏控制**：训练/验证/测试严格按时间切分 + `feature_cutoff_ts` 过滤；WF 折间有 `embargo`。

---

## 3) WalkForwardHPO 内的模型路径（零侵入接入）

在 `WalkForwardHPO` 的“每个参数组合 × 每个折”评估里，若网格参数包含 `model_type`，启用**模型训练→预测→信号→回测**链路：

1. **取数据**：按折得到 `df_IS` / `df_OOS`（均已是 point-in-time）。
2. **特征选择**：支持网格（或 LLM 提议）给出 `feature_subset`（白名单）。
3. **训练**：实例化 `ModelAdapter`（XGB or LSTM），调用 `fit()`；

   * XGB：早停、class_weight、分位数回归（可选）；
   * LSTM：构造 lookback 窗口（`[t-L, …, t-1] → y_{t→t+H}`），规范化/填补缺失；可选 Dropout。
4. **推理**：对 IS/OOS 产出 `pred`；映射为 `signal`（阈值/分位/温度缩放）；
5. **回测**：把 `signal` 注入到策略或回测执行层（见下一节），走你已有的 `SimAdapter + Overlay`；
6. **指标**：行级 rows 存入模型信息（`model_type / hparams / features / lookback / train_end_ts`），OOS 汇总写 ClickHouse（含 `model_*` 元数据）。

> 这让 **模型候选**成为 COOP/Optuna 里的“一等公民”：你可以在 Stage1 同时比较“公式化 alpha vs XGB vs LSTM”，然后 Stage2 对胜出模型的超参**邻域**做贝叶斯细化。

---

## 4) 策略侧的“模型驱动”胶水（两种无缝方式）

### A. “信号即特征”法（最简单，零改策略）

* 在 WF 与实时推理阶段，把模型输出写入 `features["ml_signal"]`（和 `features["ml_conf"]` 可选）。
* 你现有的策略（如 `TSLASimplifiedV7_2`）在 `on_features()` 里读这个特征，按阈值/分位/仓位函数下单。

### B. “模型策略模板”法（适配器策略）

* 新增 `ModelSignalStrategy(StrategyAlgorithm)`，内部仅根据 `ml_signal`（或直接调用载入模型预测）生成 `DecisionEnvelope`。
* 适合你想把“模型交易”作为独立策略栈运行/对账。

> 两条路可并行；我建议先走 **A**（改动极小），等产线稳了再封装 **B** 做多策略组合。

---

## 5) 实时推理（Paper/Prod 共用）

在 `paper_engine.py`（和真实路由共用）加一个 **InferenceManager**：

* 维护**特征滑窗**（LSTM 的 lookback 缓冲）；
* 每个 `on_market_data()` 先更新滑窗 → 调用 `model.predict()` → 写回 `features["ml_signal"]` → 再调策略；
* 模型热加载（订阅某个 `models/active.json` symlink 或 ClickHouse 模型表）；
* 故障降级：模型不可用→`ml_signal=None`→策略退化为 baseline 或不开仓（Kill-switch 不触发全局，仅本策略熔断）。

---

## 6) COOP + Optuna 的协同升级

* **Stage1（COOP）**：允许 LLM/ML 同时

  1. 提出**公式化参数网格**；
  2. 提出 **XGB/LSTM** 的**候选超参**与**特征子集**；
     合并后：grid 里会出现 `model_type ∈ {none, xgb, lstm}`，以及各自的 `params_*`。
* **Stage2（Optuna）**：根据 Stage1 冠军（可能是 XGB 或 LSTM），构建**邻域空间**：

  * XGB：`max_depth, learning_rate, n_estimators, colsample_bytree, subsample, min_child_weight…`
  * LSTM：`lookback, hidden_dim, num_layers, dropout, lr, weight_decay, batch_size…`

> 目标函数继续用你已接的**复合指标**（含 `psr/dsr/pbo`），避免“看似高 Sharpe 的过拟合”。

---

## 7) 监控与治理（Production 需要的“看见”）

* **落库**：在 `alpha_rows/alpha_runs` 增 `model_type / model_version / lookback / feature_count / train_end_ts`；
* **Grafana 卡片**：

  * XGB：重要度/SHAP Top-K（变更检测：重要度漂移）；
  * LSTM：预测分布/置信度热力/校准曲线；
* **SLO**：新增 `infer_latency_ms`（单次推理时延）与 `infer_error_rate`；
* **漂移**：特征分布 K–S 检测（列举 Top 漂移列）；阈值触发**自动再训练任务**或**降级**。

---

## 8) 性能与风控衔接

* 推理耗时：XGB 单点 <1ms；LSTM lookback×batch 控制在 <10ms；
* 执行风控：`PortfolioOverlay` 不改；只要策略发单，Overlay 仍然**硬限**仓位、净/总暴露与熔断；
* 并行：WF 可把“按折 × 候选模型”分发给 Ray/多进程；线上推理保持**单线程/无GIL热点**（XGB 原生，LSTM 用 Torch 的 `inference_mode()`）。

# models/base.py
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, asdict
from typing import Any, Dict, List, Optional, Tuple
import numpy as np
import pandas as pd

@dataclass
class DecisionScheme:
    mode: str = "quantile"   # "quantile" | "threshold" | "zscore"
    q_long: float = 0.7      # quantile 上分位做多
    q_short: float = 0.3     # quantile 下分位做空
    thr_long: float = 0.0    # 回归/概率阈值
    thr_short: float = 0.0
    z_k: float = 1.0         # zscore 的倍数

class ModelAdapter(ABC):
    """统一训练/推理/保存接口，供 WF 与 实时共用。"""
    def __init__(self, task: str = "reg", hparams: Optional[Dict[str, Any]] = None):
        assert task in ("reg", "clf"), "task must be 'reg' or 'clf'"
        self.task = task
        self.hparams = hparams or {}
        self._fcols: List[str] = []
        self._trained = False

    # ---- 生命周期 ----
    @abstractmethod
    def fit(self, df_train: pd.DataFrame, y_train: np.ndarray,
            df_valid: Optional[pd.DataFrame] = None,
            y_valid: Optional[np.ndarray] = None,
            **kwargs) -> Dict[str, Any]:
        """返回训练摘要（如 early_stop_round, valid_metric 等）"""
        raise NotImplementedError

    @abstractmethod
    def predict(self, df: pd.DataFrame) -> np.ndarray:
        """回归: 直接返回预测收益; 分类: 返回 P(up) 概率."""
        raise NotImplementedError

    @abstractmethod
    def save(self, path: str) -> None:
        raise NotImplementedError

    @abstractmethod
    def load(self, path: str) -> None:
        raise NotImplementedError

    # ---- 元数据 ----
    def set_feature_cols(self, cols: List[str]): self._fcols = list(cols)
    def feature_cols(self) -> List[str]: return list(self._fcols)
    def is_trained(self) -> bool: return bool(self._trained)

    def metadata(self) -> Dict[str, Any]:
        return {
            "type": self.__class__.__name__,
            "task": self.task,
            "hparams": self.hparams,
            "feature_cols": self._fcols,
        }

    # ---- 信号映射 ----
    @staticmethod
    def to_signal(pred: np.ndarray, scheme: DecisionScheme) -> np.ndarray:
        p = np.asarray(pred).astype(float)
        if scheme.mode == "quantile":
            lo = np.nanquantile(p, scheme.q_short)
            hi = np.nanquantile(p, scheme.q_long)
            sig = np.where(p >= hi, 1.0, np.where(p <= lo, -1.0, 0.0))
            return sig
        if scheme.mode == "threshold":
            sig = np.where(p >= scheme.thr_long, 1.0, np.where(p <= scheme.thr_short, -1.0, 0.0))
            return sig
        if scheme.mode == "zscore":
            mu, sd = np.nanmean(p), np.nanstd(p) + 1e-9
            z = (p - mu) / sd
            sig = np.where(z >= scheme.z_k, 1.0, np.where(z <= -scheme.z_k, -1.0, 0.0))
            return sig
        return np.zeros_like(p)
```

# models/xgb_model.py
from __future__ import annotations
from typing import Any, Dict, Optional, List
import numpy as np
import pandas as pd
from .base import ModelAdapter

class XGBModel(ModelAdapter):
    def __init__(self, task: str = "reg", hparams: Optional[Dict[str, Any]] = None):
        super().__init__(task, hparams)
        try:
            import xgboost as xgb  # noqa
        except Exception as e:
            raise RuntimeError("xgboost not installed. `pip install xgboost`") from e
        self._model = None

    def fit(self, df_train: pd.DataFrame, y_train: np.ndarray,
            df_valid: Optional[pd.DataFrame] = None,
            y_valid: Optional[np.ndarray] = None,
            **kwargs) -> Dict[str, Any]:
        import xgboost as xgb
        cols = self.feature_cols() or [c for c in df_train.columns if c not in ("ts","symbol","y")]
        self.set_feature_cols(cols)
        Xtr = df_train[cols].to_numpy()
        eval_set = None
        if df_valid is not None and y_valid is not None:
            Xva = df_valid[cols].to_numpy()
            eval_set = [(Xtr, y_train), (Xva, y_valid)]

        if self.task == "reg":
            self._model = xgb.XGBRegressor(
                n_estimators= self.hparams.get("n_estimators", 500),
                max_depth=   self.hparams.get("max_depth", 6),
                learning_rate=self.hparams.get("learning_rate", 0.05),
                subsample=   self.hparams.get("subsample", 0.9),
                colsample_bytree=self.hparams.get("colsample_bytree", 0.8),
                min_child_weight=self.hparams.get("min_child_weight", 1.0),
                reg_lambda=  self.hparams.get("reg_lambda", 1.0),
                tree_method= self.hparams.get("tree_method", "auto"),
                random_state=self.hparams.get("seed", 42),
                n_jobs=self.hparams.get("n_jobs", -1),
            )
            self._model.fit(
                Xtr, y_train,
                eval_set=eval_set,
                verbose=False,
                early_stopping_rounds=self.hparams.get("early_stopping_rounds", 50) if eval_set else None
            )
        else:  # clf
            self._model = xgb.XGBClassifier(
                n_estimators= self.hparams.get("n_estimators", 500),
                max_depth=   self.hparams.get("max_depth", 6),
                learning_rate=self.hparams.get("learning_rate", 0.05),
                subsample=   self.hparams.get("subsample", 0.9),
                colsample_bytree=self.hparams.get("colsample_bytree", 0.8),
                min_child_weight=self.hparams.get("min_child_weight", 1.0),
                reg_lambda=  self.hparams.get("reg_lambda", 1.0),
                tree_method= self.hparams.get("tree_method", "auto"),
                random_state=self.hparams.get("seed", 42),
                n_jobs=self.hparams.get("n_jobs", -1),
                eval_metric=self.hparams.get("eval_metric", "logloss"),
            )
            self._model.fit(
                Xtr, y_train,
                eval_set=eval_set,
                verbose=False,
                early_stopping_rounds=self.hparams.get("early_stopping_rounds", 50) if eval_set else None
            )
        self._trained = True
        return {"best_iteration": getattr(self._model, "best_iteration", None)}

    def predict(self, df: pd.DataFrame) -> np.ndarray:
        assert self._trained and self._model is not None
        X = df[self.feature_cols()].to_numpy()
        if self.task == "reg":
            return self._model.predict(X)
        proba = self._model.predict_proba(X)
        return proba[:,1]  # P(up)

    def save(self, path: str) -> None:
        import json, os
        os.makedirs(path, exist_ok=True)
        meta = self.metadata()
        json.dump(meta, open(f"{path}/meta.json","w",encoding="utf-8"))
        self._model.save_model(f"{path}/model.json")

    def load(self, path: str) -> None:
        import json, xgboost as xgb
        meta = json.load(open(f"{path}/meta.json","r",encoding="utf-8"))
        self.task = meta["task"]; self.hparams = meta["hparams"]; self._fcols = meta["feature_cols"]
        if self.task == "reg":
            self._model = xgb.XGBRegressor()
        else:
            self._model = xgb.XGBClassifier()
        self._model.load_model(f"{path}/model.json")
        self._trained = True
```

```python
# models/lstm_model.py
from __future__ import annotations
from typing import Any, Dict, Optional, List, Tuple
import numpy as np
import pandas as pd
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader
from .base import ModelAdapter

class _SeqDataset(Dataset):
    def __init__(self, df: pd.DataFrame, cols: List[str], y: np.ndarray, lookback: int):
        X = df[cols].to_numpy(dtype=np.float32)
        self.look = int(lookback)
        self.Xseq, self.y = [], []
        for t in range(self.look, len(X)):
            self.Xseq.append(X[t-self.look:t])
            self.y.append(y[t])
        self.Xseq = np.asarray(self.Xseq, dtype=np.float32)
        self.y = np.asarray(self.y, dtype=np.float32)
    def __len__(self): return len(self.y)
    def __getitem__(self, i): return self.Xseq[i], self.y[i]

class _LSTMHead(nn.Module):
    def __init__(self, in_dim: int, hidden: int = 64, num_layers: int = 1, dropout: float = 0.0, task: str = "reg"):
        super().__init__()
        self.task = task
        self.lstm = nn.LSTM(input_size=in_dim, hidden_size=hidden, num_layers=num_layers,
                            batch_first=True, dropout=dropout if num_layers>1 else 0.0)
        self.head = nn.Linear(hidden, 1)
        if task == "clf":
            self.out_act = nn.Sigmoid()
        else:
            self.out_act = nn.Identity()
    def forward(self, x):
        # x: [B, T, F]
        y, _ = self.lstm(x)
        z = y[:,-1,:]
        o = self.head(z)
        return self.out_act(o).squeeze(-1)

class LSTMModel(ModelAdapter):
    def __init__(self, task: str = "reg", hparams: Optional[Dict[str, Any]] = None):
        super().__init__(task, hparams)
        try:
            import torch  # noqa
        except Exception as e:
            raise RuntimeError("PyTorch not installed. `pip install torch`") from e
        self.device = "cuda" if torch.cuda.is_available() and self.hparams.get("use_cuda", True) else "cpu"
        self.model: Optional[_LSTMHead] = None
        self.lookback = int(self.hparams.get("lookback", 32))

    def _build(self, in_dim: int) -> _LSTMHead:
        return _LSTMHead(
            in_dim=in_dim,
            hidden=int(self.hparams.get("hidden", 64)),
            num_layers=int(self.hparams.get("num_layers", 1)),
            dropout=float(self.hparams.get("dropout", 0.0)),
            task=self.task
        ).to(self.device)

    def fit(self, df_train: pd.DataFrame, y_train: np.ndarray,
            df_valid: Optional[pd.DataFrame] = None,
            y_valid: Optional[np.ndarray] = None,
            **kwargs) -> Dict[str, Any]:
        cols = self.feature_cols() or [c for c in df_train.columns if c not in ("ts","symbol","y")]
        self.set_feature_cols(cols)
        tr = _SeqDataset(df_train, cols, y_train, self.lookback)
        va = _SeqDataset(df_valid, cols, y_valid, self.lookback) if df_valid is not None and y_valid is not None else None
        if len(tr) < 10: raise RuntimeError("Too few sequence samples.")

        self.model = self._build(in_dim=len(cols))
        opt = torch.optim.Adam(self.model.parameters(), lr=float(self.hparams.get("lr", 1e-3)),
                               weight_decay=float(self.hparams.get("weight_decay", 0.0)))
        if self.task == "reg":
            loss_fn = nn.MSELoss()
        else:
            loss_fn = nn.BCELoss()

        bs = int(self.hparams.get("batch_size", 256))
        dl_tr = DataLoader(tr, batch_size=bs, shuffle=True, drop_last=True)
        dl_va = DataLoader(va, batch_size=bs, shuffle=False, drop_last=False) if va is not None else None

        best_loss, best_state, no_improve = 1e9, None, 0
        patience = int(self.hparams.get("patience", 10))
        max_epochs = int(self.hparams.get("epochs", 100))

        for ep in range(max_epochs):
            self.model.train()
            for xb, yb in dl_tr:
                xb, yb = xb.to(self.device), yb.to(self.device)
                opt.zero_grad(set_to_none=True)
                with torch.cuda.amp.autocast(enabled=False):
                    pred = self.model(xb)
                    loss = loss_fn(pred, yb)
                loss.backward()
                torch.nn.utils.clip_grad_norm_(self.model.parameters(), float(self.hparams.get("grad_clip", 1.0)))
                opt.step()

            # valid
            if dl_va is not None:
                self.model.eval()
                tot, cnt = 0.0, 0
                with torch.no_grad():
                    for xb, yb in dl_va:
                        xb, yb = xb.to(self.device), yb.to(self.device)
                        pr = self.model(xb)
                        l = loss_fn(pr, yb).item()
                        tot += l * len(yb); cnt += len(yb)
                vloss = tot / max(1, cnt)
                if vloss + 1e-6 < best_loss:
                    best_loss, best_state, no_improve = vloss, self.model.state_dict(), 0
                else:
                    no_improve += 1
                if no_improve >= patience:
                    break

        if best_state is not None:
            self.model.load_state_dict(best_state)
        self._trained = True
        return {"best_valid_loss": float(best_loss)}

    def predict(self, df: pd.DataFrame) -> np.ndarray:
        assert self._trained and self.model is not None
        cols = self.feature_cols()
        X = df[cols].to_numpy(dtype=np.float32)
        if len(X) < self.lookback:
            return np.zeros(len(X), dtype=np.float32)
        # 滑窗推理
        self.model.eval()
        out = np.zeros(len(X), dtype=np.float32)
        with torch.no_grad():
            for t in range(self.lookback, len(X)):
                seq = torch.from_numpy(X[t-self.lookback:t]).unsqueeze(0).to(self.device)  # [1,T,F]
                pr = self.model(seq).item()
                out[t] = pr
        return out

    def save(self, path: str) -> None:
        import os, json, torch
        os.makedirs(path, exist_ok=True)
        torch.save(self.model.state_dict(), f"{path}/model.pt")
        meta = self.metadata(); meta["lookback"] = self.lookback
        json.dump(meta, open(f"{path}/meta.json","w",encoding="utf-8"))

    def load(self, path: str) -> None:
        import json, torch, os
        meta = json.load(open(f"{path}/meta.json","r",encoding="utf-8"))
        self.task = meta["task"]; self.hparams = meta["hparams"]; self._fcols = meta["feature_cols"]
        self.lookback = int(meta.get("lookback", self.hparams.get("lookback", 32)))
        self.model = self._build(in_dim=len(self._fcols))
        self.model.load_state_dict(torch.load(f"{path}/model.pt", map_location=self.device))
        self._trained = True
```

# 4) 实时推理管理器（必贴）

**`inference/manager.py`**

```python
# inference/manager.py
from __future__ import annotations
from typing import Any, Dict, Optional
import os, json, time
import pandas as pd
import numpy as np
from models.base import DecisionScheme
from models.xgb_model import XGBModel
from models.lstm_model import LSTMModel

class InferenceManager:
    """
    负责：加载/热切模型 → 每条 features 生成 ml_signal（写回 features），供策略 on_features 使用。
    """
    def __init__(self, cfg: Dict[str, Any]):
        """
        cfg:
          { "active_path": "./models/active", 
            "decision": {"mode":"quantile","q_long":0.7,"q_short":0.3},
            "fallback_zero": true }
        """
        self.cfg = cfg or {}
        self.path = self.cfg.get("active_path", "./models/active")
        self.scheme = DecisionScheme(**(self.cfg.get("decision") or {}))
        self.model = None
        self.meta = {}
        self._last_load_ts = 0
        self._load_if_changed()

    def _load_if_changed(self):
        meta_p = os.path.join(self.path, "meta.json")
        if not os.path.exists(meta_p): return
        mtime = os.path.getmtime(meta_p)
        if mtime <= self._last_load_ts: return
        meta = json.load(open(meta_p,"r",encoding="utf-8"))
        mtype = meta.get("type")
        if mtype == "XGBModel":
            mdl = XGBModel(task=meta.get("task","reg"), hparams=meta.get("hparams"))
        elif mtype == "LSTMModel":
            mdl = LSTMModel(task=meta.get("task","reg"), hparams=meta.get("hparams"))
        else:
            return
        mdl.load(self.path)
        self.model, self.meta = mdl, meta
        self._last_load_ts = mtime

    def infer_row(self, features_row: Dict[str, Any]) -> Dict[str, Any]:
        """单条行推理：返回写入了 ml_signal/ml_pred/ml_conf 的 features_row 副本。"""
        self._load_if_changed()
        out = dict(features_row)
        if self.model is None:
            if self.cfg.get("fallback_zero", True):
                out["ml_signal"], out["ml_pred"], out["ml_conf"] = 0.0, 0.0, 0.0
            return out

        cols = self.model.feature_cols()
        if not cols:
            return out

        # 单行 -> DataFrame
        df = pd.DataFrame([out])
        try:
            pred = self.model.predict(df)[-1]
            out["ml_pred"] = float(pred)
            # 简易置信度：回归用 |pred| 的缩放；分类用 |p-0.5|
            if self.model.task == "reg":
                out["ml_conf"] = float(min(1.0, abs(pred)))
            else:
                out["ml_conf"] = float(min(1.0, abs(pred - 0.5)*2))
            sig = self.model.to_signal(np.array([pred]), self.scheme)[0]
            out["ml_signal"] = float(sig)
        except Exception:
            if self.cfg.get("fallback_zero", True):
                out["ml_signal"], out["ml_pred"], out["ml_conf"] = 0.0, 0.0, 0.0
        return out
```

# 5) Walk-Forward 集成（在 `wf_hpo.py` 里补两个“钩子”）

> 只需在你的 `WalkForwardHPO` 中调用以下函数：当 `grid` 含 `model_type` 时走模型分支；否则走你原本的公式化 alpha 分支。

**新增：`wf_model_hooks.py`（便于独立维护）**

```python
# wf_model_hooks.py
from __future__ import annotations
from typing import Any, Dict, Tuple
import numpy as np
import pandas as pd

from models.base import DecisionScheme
from models.xgb_model import XGBModel
from models.lstm_model import LSTMModel

def build_model(model_type: str, task: str, hparams: Dict[str, Any]):
    if model_type == "xgb":
        return XGBModel(task=task, hparams=hparams)
    if model_type == "lstm":
        return LSTMModel(task=task, hparams=hparams)
    raise ValueError(f"Unknown model_type: {model_type}")

def train_predict_to_signal(
    df_is: pd.DataFrame, df_oos: pd.DataFrame,
    y_is: np.ndarray, y_oos: np.ndarray,
    features: list[str],
    model_type: str, task: str, hparams: Dict[str, Any],
    decision: Dict[str, Any]
) -> Tuple[np.ndarray, np.ndarray, Dict[str, Any]]:
    """
    训练模型并对 IS/OOS 产生信号（-1,0,1），返回 (sig_is, sig_oos, train_meta)
    """
    mdl = build_model(model_type, task, hparams)
    mdl.set_feature_cols(features)
    # 切出校验集（IS 的后 10%）
    cut = int(len(df_is)*0.9)
    df_tr, y_tr = df_is.iloc[:cut], y_is[:cut]
    df_va, y_va = df_is.iloc[cut:], y_is[cut:]
    meta = mdl.fit(df_tr, y_tr, df_valid=df_va, y_valid=y_va)

    p_is = mdl.predict(df_is)
    p_oos = mdl.predict(df_oos)
    scheme = DecisionScheme(**(decision or {}))
    s_is = mdl.to_signal(p_is, scheme)
    s_oos = mdl.to_signal(p_oos, scheme)
    m = {"model_meta": mdl.metadata(), "train_meta": meta}
    return s_is.astype(float), s_oos.astype(float), m
```

> 在 **`wf_hpo.py`** 的参数组合评估位置（你形成每折 `df_IS/df_OOS` 时）插入：

```python
# 伪代码：在每个 grid 组合评估前

    # 后续复用你现有的“按特征驱动策略”的回测路径
    #   e.g. engine.run(df_IS/df_OOS) 或内部打分→下单→SimAdapter

    row["model_type"] = model_type

```
