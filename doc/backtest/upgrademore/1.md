# 0. 总览（你将得到什么）

* **Stage-0（离线）**：用 LSTM 在**时间走样**+**禁运**下生成 **OOF（out-of-fold）** 预测（严格样本外），作为“势能/节奏”特征。
* **Stage-1（训练）**：XGBoost 读取“基础特征 + LSTM_OOF 特征”训练/评估。
* **存储层**：OOF 特征**独立入库**（避免对主特征表做 UPDATE），并通过 **视图**与原表联结；可多版本共存、可回滚。
* **WF/HPO 集成**：允许开关 `use_relay`、搜索 `seq_len/hidden/embargo` 等超参；统一指标（AUC/IC、PSR/DSR、PBO）。
* **上线**：实时仅用 XGB（读取离线产出的 OOF 列），**无 LSTM 在线时延**；支持影子对照与一键回滚。
* **监控/SLO**：覆盖率、A/B、订单质量、OOF 新鲜度等在 Grafana/ClickHouse 中可见。

# 1. 数据/标签与时间对齐（关键防泄漏）

**标签定义**（示例，预测未来 5 分钟收益）：

```sql
-- label_h5 = 未来5m收盘相对当前收盘的收益（或方向）
ALTER TABLE trading.features_1m
  ADD COLUMN IF NOT EXISTS label_h5 Float32 DEFAULT 0;

-- 若已存有 close 字段，则可在ETL/特征产出时生成 label_h5（推荐在上游一次性生成）
-- 伪SQL（具体实现放在你的ETL中）：
-- label_h5(t) = (close(t+5m) / close(t) - 1)
```

**对齐规范**

* 训练/预测时使用的特征均为 **t** 时刻值，预测目标为 **t+H**（H=5m）时刻的 `label_h5`。
* **任何 LSTM 预测回填到特征库时，必须是样本外**（见下节 OOF 生成）。
* 在**折边界**处加**禁运（Embargo）**（例如 10 分钟），避免相邻窗口泄漏。

# 2. ClickHouse 表设计：**独立 OOF 表 + 视图联结**（推荐）

避免对主特征表做 UPDATE，使用**独立表**承载 OOF（可多版本并存），再用视图透出到训练读取层。

```sql
-- 2.1 OOF 特征表（可多 run_id/版本）
CREATE TABLE IF NOT EXISTS trading.oof_lstm_h5
(
  ts         DateTime,
  symbol     String,
  pred       Float32,     -- OOF 预测
  conf       Float32,     -- 置信度（可选）
  run_id     String,      -- 本次离线生成的唯一ID（日期+git sha）
  model_ver  String,      -- 模型版本/超参指纹
  updated_at DateTime DEFAULT now()
)
ENGINE = ReplacingMergeTree(updated_at)
ORDER BY (symbol, ts)
SETTINGS index_granularity = 8192;

-- 2.2 训练读取视图：主特征 + OOF 透出（选择最新的版本）
CREATE OR REPLACE VIEW trading.features_1m_with_oof AS
SELECT
  f.*,
  o.pred AS lstm_oof_h5,
  o.conf AS lstm_oof_conf_h5
FROM trading.features_1m AS f
LEFT JOIN
(
  SELECT *
  FROM
  (
    SELECT
      ts, symbol, pred, conf,
      row_number() OVER (PARTITION BY symbol, ts ORDER BY updated_at DESC) AS rn
    FROM trading.oof_lstm_h5
  ) WHERE rn = 1
) AS o
ON o.symbol = f.symbol AND o.ts = f.ts;
```

> 好处：
>
> * 不破坏主表；OOF 多版本可共存；视图自动取最近一版；回滚更简单（删最新一版或切 run_id）。
> * 训练、回测、在线读取路径**一致**（读取视图即可）。

def upsert_oof(client, df, run_id, model_ver):

        part["model_ver"] = model_ver

# 6. 上线（实时）策略

* **实时仅用 XGB**；输入：基础特征 + `lstm_oof_*` 列（来自视图）。
* **OOF 刷新策略**：

  * T 日盘后（或每小时）重跑 Stage-0，产出新的 run_id 写入 OOF 表；
  * 视图始终取最新 `updated_at`；若当下时点还没新数据，继续用旧版本（**平滑切换**）。
* **兜底**：若某时刻某 symbol 无 OOF（NULL），fallback 为 0 或上一有效值；在日志记录 `oof_coverage`。
* **灰度/影子**：`strategy_config` 启用 `use_relay` 的 shadow 策略，与 baseline 同时跑但不下单，对比成交与PnL。

# 7. 监控/SLO（关键看板与告警）

**ClickHouse 侧（示例 SQL）**

* OOF 覆盖率（最近 1d）：

```sql
SELECT
  symbol,
  avg(lstm_oof_h5 IS NOT NULL) AS oof_coverage
FROM trading.features_1m_with_oof
WHERE ts >= now() - INTERVAL 1 DAY
GROUP BY symbol
ORDER BY oof_coverage ASC;
```

* Relay A/B 表现（若落地到 runs 表）：

```sql
-- 假设 runs 表有 use_relay 标记与 psr/dsr/auc 等
SELECT toDate(ts) d,
       avgIf(psr, use_relay=1) psr_relay,
       avgIf(psr, use_relay=0) psr_base
FROM runs
WHERE ts >= today()-7
GROUP BY d
ORDER BY d;
```

**Grafana**

* Time series：OOF 覆盖率；OOF 更新延迟（now()-max(updated_at)）；
* Table：Top 空洞 symbol（缺 OOF）；
* Stat：A/B PSR 差值、胜率差值；
* Loki：当 `use_relay=true AND lstm_oof=NULL` 时输出 `warn` 日志；Tempo Span attr：`relay.used=true`。

**告警**

* OOF 覆盖率 < 95%（5m 评估窗）报警；
* OOF 更新延迟 > 30m 报警；
* Relay 开启后，订单拒绝/裁剪显著上升（>Xσ）报警（避免漂移害人）。

# 10. 安全与性能建议

* LSTM 只离线：CPU 也能跑；批量/折数/epoch 按时限压缩；必要时 GPU 加速。
* ClickHouse 批量写入每批 1e5 行；避免每行小事务。
* 表达式计算（如 label）尽量在上游 ETL 固化，减少训练期计算。
* 版本优先：不要 UPDATE 主表；独立 OOF 表更安全、可回滚。

## 2) `alpha_loop.py` 两阶段接力 Objective（可直接粘贴）

> 依赖：`pip install clickhouse-driver optuna xgboost scikit-learn`
> 以及**你已有的** LSTM OOF 生成器（我之前给的 `pipelines/lstm_oof_to_clickhouse.py`）。若你还未放入仓库，先把我之前那份文件放到 `pipelines/` 下即可。

```python
# alpha_loop.py  — two-stage relay objective (LSTM OOF -> XGB)
from __future__ import annotations
import os, json, time, subprocess, hashlib
from dataclasses import dataclass
from typing import List, Tuple

import numpy as np
import pandas as pd
import optuna
from optuna.pruners import MedianPruner
from sklearn.metrics import roc_auc_score, log_loss
from sklearn.model_selection import TimeSeriesSplit

import xgboost as xgb
from clickhouse_driver import Client

# —— 可选：导入你之前的 OOF 生成器（已提供过） ——
from pipelines.lstm_oof_to_clickhouse import OOFConfig, run_oof_pipeline  # 若路径不同，调整导入

# ===================== 基础配置 =====================

@dataclass
class RelayConfig:
    ch_host: str = "localhost"
    ch_port: int = 9000
    ch_user: str = "default"
    ch_password: str = ""
    ch_db: str = "trading"

    table_view: str = "features_1m_with_oof"  # 统一从视图读取
    symbol: str = "TSLA"
    start: str = "2024-06-01 00:00:00"
    end: str   = "2025-10-01 00:00:00"

    label_col: str = "label_h5"   # 方向：>0 记 1（分类）
    base_feats: Tuple[str, ...] = ("vwap","rsi_14","ema_9","atr_14","close")
    relay_feats: Tuple[str, ...] = ("lstm_oof_h5","lstm_oof_conf_h5")

    n_splits: int = 5
    study_name: str = "relay_xgb_hpo"
    objective_metric: str = "auc"  # 目标：AUC；你也可换 PSR/DSR（需相应计算）
    pruner_median: bool = True

    # OOF 生成的默认参数（trial 会覆盖一部分）
    oof_seq_cols: Tuple[str,...] = ("close","vwap","ema_9","rsi_14","atr_14")
    oof_epochs: int = 2
    oof_folds: int  = 4
    oof_embargo_min: int = 10
    oof_seq_len: int = 60
    oof_horizon_min: int = 5
    oof_model_ver: str = "lstm_h64_l1"

# ===================== ClickHouse Utils =====================

def ch_client(cfg: RelayConfig) -> Client:
    return Client(host=cfg.ch_host, port=cfg.ch_port, user=cfg.ch_user,
                  password=cfg.ch_password, database=cfg.ch_db,
                  settings={"use_numpy": True})

def fetch_frame(cfg: RelayConfig, use_relay: bool) -> pd.DataFrame:
    cols = ["ts","symbol", cfg.label_col, *cfg.base_feats]
    if use_relay:
        cols += list(cfg.relay_feats)
    q = f"""
    SELECT {", ".join(cols)}
    FROM {cfg.table_view}
    WHERE symbol=%(sym)s AND ts >= %(st)s AND ts < %(ed)s
    ORDER BY ts
    """
    cli = ch_client(cfg)
    data = cli.execute(q, {"sym": cfg.symbol, "st": cfg.start, "ed": cfg.end})
    df = pd.DataFrame(data, columns=cols)
    df = df.dropna()
    return df

def insert_run(cfg: RelayConfig, trial: optuna.trial.Trial,
               run_id: str, mean_val: float, auc: float,
               fold_scores: List[float], params: dict):
    try:
        git = subprocess.getoutput("git rev-parse --short HEAD") or "nogit"
    except Exception:
        git = "nogit"
    config_sha = hashlib.sha256(json.dumps(params, sort_keys=True).encode()).hexdigest()[:12]

    q = """
    INSERT INTO trading.runs
    (study, trial_id, run_id, symbol, start, end, use_relay, auc, mean_val, fold_scores, params_json, git_commit, config_sha)
    VALUES
    """
    row = (cfg.study_name, trial.number, run_id, cfg.symbol, cfg.start, cfg.end,
           int(params.get("use_relay", 0)), float(auc), float(mean_val),
           [float(x) for x in fold_scores], json.dumps(params), git, config_sha)
    ch_client(cfg).execute(q, [row])

# ===================== 指标 & 训练 =====================

def timeseries_cv_scores(df: pd.DataFrame, label_col: str, features: List[str],
                         trial: optuna.trial.Trial | None = None,
                         xgb_params: dict | None = None,
                         n_splits: int = 5) -> Tuple[List[float], float, float]:
    """
    返回：各折 AUC 列表、平均 AUC、平均 LogLoss（可用于监控）
    """
    X = df[features].values
    y = (df[label_col].values > 0).astype(np.int32)
    tscv = TimeSeriesSplit(n_splits=n_splits)

    if xgb_params is None:
        xgb_params = dict(
            eta=0.05, max_depth=5, subsample=0.8, colsample_bytree=0.8,
            min_child_weight=1.0,
            objective="binary:logistic", eval_metric="auc"
        )

    aucs, losses = [], []
    for fold, (tr, va) in enumerate(tscv.split(X)):
        dtr = xgb.DMatrix(X[tr], label=y[tr])
        dva = xgb.DMatrix(X[va], label=y[va])
        bst = xgb.train(xgb_params, dtr, num_boost_round=300, evals=[(dva, "valid")], verbose_eval=False)
        p = bst.predict(dva)
        auc = roc_auc_score(y[va], p)
        ll  = log_loss(y[va], p, labels=[0,1])
        aucs.append(auc); losses.append(ll)
        if trial is not None:
            trial.report(auc, step=fold)   # 支持 pruner
            if trial.should_prune():
                raise optuna.TrialPruned(f"pruned at fold {fold}, auc={auc:.4f}")
    return aucs, float(np.mean(aucs)), float(np.mean(losses))

# ===================== OOF 生成（Stage-0） =====================

def maybe_run_oof(cfg: RelayConfig, params: dict) -> str | None:
    """
    当 use_relay=1 时，按 trial 采样的超参生成 OOF 并入库，返回 run_id
    """
    if not params.get("use_relay", 0):
        return None

    # trial 里采样 / 或采用默认
    seq_len  = int(params.get("oof_seq_len", cfg.oof_seq_len))
    embargo  = int(params.get("oof_embargo_min", cfg.oof_embargo_min))
    epochs   = int(params.get("oof_epochs", cfg.oof_epochs))
    folds    = int(params.get("oof_folds", cfg.oof_folds))

    # 生成唯一 run_id
    git = subprocess.getoutput("git rev-parse --short HEAD") or "nogit"
    run_id = f"oof_{time.strftime('%Y%m%d_%H%M%S')}_{git}"

    oof_cfg = OOFConfig(
        ch_host=cfg.ch_host, ch_port=cfg.ch_port, ch_user=cfg.ch_user,
        ch_password=cfg.ch_password, ch_db=cfg.ch_db,
        table=cfg.table_view.replace("_with_oof",""),  # OOF 从原表拉序列列
        symbol=cfg.symbol, start=cfg.start, end=cfg.end,
        horizon_min=cfg.oof_horizon_min, label_col=cfg.label_col,
        seq_cols=cfg.oof_seq_cols, seq_len=seq_len,
        batch=512, lr=1e-3, epochs=epochs, folds=folds,
        embargo_min=embargo,
        write_pred_col="pred", write_conf_col="conf"  # 在 oof 表中固定字段名
    )
    # run_oof_pipeline 内部请按我之前给的 upsert 逻辑写到 trading.oof_lstm_h5（带 run_id/model_ver）
    # 如果你使用的是上次“写回主表”的版本，请替换为写入 oof_lstm_h5 的 upsert（推荐）。
    run_oof_pipeline(oof_cfg)  # 生成并写入 oof_lstm_h5

    return run_id

# ===================== Optuna Objective =====================

def make_objective(cfg: RelayConfig):
    def objective(trial: optuna.trial.Trial) -> float:
        # ------- 采样空间（可按需扩充） -------
        use_relay = trial.suggest_categorical("use_relay", [0, 1])

        # OOF 相关（仅 use_relay=1 时有效）
        if use_relay:
            trial.suggest_int("oof_seq_len", 40, 120, step=10)
            trial.suggest_int("oof_embargo_min", 5, 20, step=5)
            trial.suggest_int("oof_epochs", 1, 3)
            trial.suggest_int("oof_folds", 3, 6)

        # XGB 相关
        xgb_params = dict(
            eta=trial.suggest_float("eta", 0.02, 0.2, log=True),
            max_depth=trial.suggest_int("max_depth", 3, 7),
            subsample=trial.suggest_float("subsample", 0.6, 1.0),
            colsample_bytree=trial.suggest_float("colsample_bytree", 0.5, 1.0),
            min_child_weight=trial.suggest_float("min_child_weight", 0.5, 5.0),
            objective="binary:logistic",
            eval_metric="auc"
        )

        params = {"use_relay": use_relay, **{k: v for k, v in trial.params.items() if k not in ["use_relay"]}}

        # ------- Stage-0：按需生成 OOF -------
        run_id = None
        if use_relay:
            run_id = maybe_run_oof(cfg, params)

        # ------- Stage-1：训练评估 -------
        df = fetch_frame(cfg, use_relay=bool(use_relay))
        feats = list(cfg.base_feats) + (list(cfg.relay_feats) if use_relay else [])
        aucs, mean_auc, mean_ll = timeseries_cv_scores(df, cfg.label_col, feats, trial, xgb_params, cfg.n_splits)

        # ------- 记录到 ClickHouse -------
        insert_run(cfg, trial, run_id or "", mean_auc, mean_auc, aucs,  # mean_val 就用 AUC
                   params={**params, "features": feats, "n_splits": cfg.n_splits})

        return float(mean_auc)
    return objective

# ===================== main: 启动 Study =====================

def main():
    cfg = RelayConfig()
    pruner = MedianPruner(n_warmup_steps=1) if cfg.pruner_median else None
    study = optuna.create_study(
        study_name=cfg.study_name,
        direction="maximize",
        pruner=pruner
    )
    objective = make_objective(cfg)
    trials = int(os.getenv("TRIALS", "20"))
    study.optimize(objective, n_trials=trials, show_progress_bar=True)

    print("Best:", study.best_trial.value, study.best_trial.params)

if __name__ == "__main__":
    main()
```

**说明**

* `maybe_run_oof()` 在 `use_relay=1` 时调用你之前的 `run_oof_pipeline()` 生成严格 OOF，并写入 `trading.oof_lstm_h5`；训练与推理统一从 `features_1m_with_oof` 视图读取。
* `objective()` 在每个折结束后 `trial.report(...)`，允许 **Optuna Pruner** 提前终止差的 trial。
* `insert_run()` 把试验记录写入 `trading.runs`，带参数与分数，方便你在 Grafana/ClickHouse 中回看。
