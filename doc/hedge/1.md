## 一、你这版还有哪些问题（简短列一下）

你贴的“改正版”里面主要还有这些坑（我只说关键的）：

1. **还在用拍脑袋常数**

   * `total_equity = 100000.0` 写死。
   * `est_theta = notional * 0.0008`，`delta_per_contract_usd = 20000` 还是拍的。
   * `w_vix`, `w_trend`, `w_carry` 虽然放进 config 了，但没有任何数据标定逻辑。

2. **对冲比例没跟 `max_net_delta` 真正绑定**

   * `_calc_target_ratio` 用 `ratio_base + w_vix*vix_pct - w_trend*trend + w_carry*carry`，
     但没用 `abs(net_delta) / max_net_delta` 作为锚点，
     也没在下单处用 `max_net_delta` 限制总对冲规模。

3. **ATR 算法还不是“业界标准版”**

   * 虽然用了 True Range，但 ATR 是用简单平均，而你之前要求所有 ATR 统一（一般是 Wilder EMA）。

4. **Theta / Delta 依然是假值**

   * `_get_current_hedge_delta` 里仍旧假设 SPY=500, Delta=-0.4。
   * `_execute_adjustment` 减仓时还是用 `delta_gap/20000` 算张数。
   * 这会导致：账面 Delta 已经接近平衡，你系统还以为“缺口很大”。

5. **pnl_pos_5s 可能仍然混入对冲仓位**

   * `_get_portfolio_exposure` 还没排除 `sys_hedger` 的仓位，存在 feedback loop 风险。

## 二、如果让我做：这是我给你的“最终版 HedgingService”

特点：

1. **对冲比例 = 仓位风险 × 市场状态倍率**

   * 仓位风险：`exposure_ratio = min(1, abs(net_delta) / max_net_delta)`
   * 市场状态倍率：由 VIX 百分位、ATR 标准化趋势、Carry 信号一起决定。

2. **ATR 使用 Wilder 标准算法**，满足你之前“统一标准”的要求。

3. **Theta 预算 + Delta 缺口尽量用真实 Greeks**

   * 优先从 `OptionsSelector` 或 `market_data_service` 读 `delta` / `theta`。
   * 如果拿不到，再 fallback 到估算。

4. **冷却 + 滞后带 + EMA 平滑**

   * 真正避免频繁调仓（你原来定义了 cooldown，但没用上）。

> 说明：下面的代码尽量不猜你其它模块的具体接口，用 `getattr`+fallback 的方式写，保证集成时改动最小。

### 最终版代码（建议直接作为 `services/risk/hedging_service.py`）

```python
import asyncio
import time
from typing import Dict, Optional, Any, Tuple, List

from libs.logger import get_logger
from libs.config import config
from libs.db.clickhouse import ClickHouseDB
from libs.strategy.base import DecisionEnvelope, OrderStyle, Freshness
from services.strategy.strategy_base import make_decision_id
from scripts.ai_trader.risk.options_selector import OptionsSelector, HedgeIntent

logger = get_logger(__name__)


class HedgingService:
    """
    量化动态对冲服务 (Quant Dynamic Hedging)

    核心设计：
    1. 对冲比例 = 仓位风险 * 市场状态倍率
       - 仓位风险：由 net_delta / max_net_delta 决定
       - 市场状态倍率：VIX 分位 + ATR 标准化趋势 + 波动率 Carry
    2. 指标统一：
       - 趋势： (Price - EMA20) / ATR20 (Wilder)
       - VIX： 过去 252 天的分位数
       - ATR：标准 TR + Wilder EMA
    3. 成本约束：
       - 每日 Theta 预算 = 账户净值 * theta_budget_pct
       - 新增对冲的 Theta 不得使总 Theta 超过预算
    4. 防抖动：
       - EMA 平滑对冲比例
       - 滞后带 + 冷却时间，避免震荡中频繁交易
    """

    def __init__(self, strategy_engine, market_data_service=None):
        self.strategy_engine = strategy_engine
        self.md = market_data_service
        self.running = False

        self.selector = OptionsSelector()
        self.ch = ClickHouseDB()

        cfg_root = config.get("risk_management", {}).get("hedging", {})
        self.enabled = cfg_root.get("enabled", False)
        self.check_interval = cfg_root.get("check_interval_sec", 60)

        thresholds = cfg_root.get("thresholds", {})
        # 最大可接受的净 Delta 敞口（以 USD 计），决定 exposure_ratio 的归一化
        self.max_net_delta = float(thresholds.get("max_net_delta_usd", 50000.0))

        # 动态参数（可通过 config 调整 / 数据校准写回）
        self.params = {
            "smooth_alpha": 0.3,        # 对冲比例 EMA 平滑
            "hysteresis": 0.05,         # 滞后带（比例变化 < 5% 不交易）
            "theta_budget_pct": 0.0005, # 每日 Theta 预算占净值比例（5 bps）
            "mult_min": 0.5,            # 市场状态倍率下限
            "mult_max": 1.5,            # 市场状态倍率上限
            "trend_weight": 0.4,        # 趋势在倍率中的权重
            "vix_weight": 0.4,          # VIX 在倍率中的权重
            "carry_weight": 0.2,        # Carry 在倍率中的权重
            "min_gap_usd": 10000.0      # 少于这个缺口不调仓
        }
        if "dynamic_params" in cfg_root:
            self.params.update(cfg_root["dynamic_params"])

        self.strategy_id = "sys_hedger"
        self.last_action_ts = 0.0
        self.cooldown_sec = float(cfg_root.get("cooldown_sec", 300))

        # 对冲比例状态
        self.exposure_ratio = 0.0           # 仓位风险比
        self.target_hedge_ratio_raw = 0.0   # 未平滑的目标对冲比例
        self.target_hedge_ratio_ema = 0.0   # EMA 平滑后的目标对冲比例
        self.last_committed_ratio = 0.0     # 上一次真正执行时的对冲比例

        logger.info("QuantHedging initialized", params=self.params)

    # ----------------------------------------------------------------------
    # 公共接口
    # ----------------------------------------------------------------------
    async def start(self):
        if not self.enabled:
            logger.info("HedgingService disabled in config")
            return
        self.running = True
        logger.info("🛡️ Quant Hedging Service STARTED")
        while self.running:
            try:
                await self._run_cycle()
            except Exception as e:
                logger.error("Hedging cycle error", error=str(e), exc_info=True)
            await asyncio.sleep(self.check_interval)

    async def stop(self):
        self.running = False

    # ----------------------------------------------------------------------
    # 主循环
    # ----------------------------------------------------------------------
    async def _run_cycle(self):
        # 0. 冷却检查
        if time.time() - self.last_action_ts < self.cooldown_sec:
            return

        # 1. 获取组合敞口
        exposure = await self._get_portfolio_exposure()
        net_delta = exposure.get("net", 0.0)
        gross_delta = exposure.get("gross", 0.0)

        if gross_delta <= 0:
            logger.debug("No exposure, skipping hedge cycle")
            return

        # 仓位风险比：0~1
        self.exposure_ratio = min(1.0, abs(net_delta) / self.max_net_delta)

        # 2. 市场状态：趋势 + VIX + Carry
        trend_score = await self._get_spy_trend_score_atr()   # 大致在 [-3, 3]
        vix_pct, carry = await self._get_vix_and_carry_factors()

        # 3. 计算目标对冲比例（未平滑）
        self.target_hedge_ratio_raw = self._calc_target_ratio(
            exposure_ratio=self.exposure_ratio,
            trend_score=trend_score,
            vix_pct=vix_pct,
            carry=carry
        )

        # 4. EMA 平滑
        alpha = self.params["smooth_alpha"]
        self.target_hedge_ratio_ema = (
            alpha * self.target_hedge_ratio_raw
            + (1 - alpha) * self.target_hedge_ratio_ema
        )

        # 5. 是否需要执行调整（滞后带）
        if not self._should_act(self.target_hedge_ratio_ema, self.last_committed_ratio):
            return

        # 6. 计算目标对冲 Delta & 当前对冲 Delta
        # 例如 net_delta = +100k（多头），目标对冲比例 0.4 → 目标对冲 -40k
        target_hedge_delta = -1.0 * net_delta * self.target_hedge_ratio_ema
        current_hedge_delta = await self._get_current_hedge_delta()
        delta_gap = target_hedge_delta - current_hedge_delta

        if abs(delta_gap) < self.params["min_gap_usd"]:
            logger.debug("Delta gap below min_gap_usd, skip adjust", gap=delta_gap)
            return

        # 7. 账户净值 & Theta 预算
        total_equity = await self._get_total_equity()
        theta_budget = total_equity * self.params["theta_budget_pct"]

        logger.info(
            "Hedge decision",
            net_delta=net_delta,
            exposure_ratio=f"{self.exposure_ratio:.2f}",
            trend_score=f"{trend_score:.2f}",
            vix_pct=f"{vix_pct:.2f}",
            carry=f"{carry:.2f}",
            target_ratio_raw=f"{self.target_hedge_ratio_raw:.2f}",
            target_ratio_ema=f"{self.target_hedge_ratio_ema:.2f}",
            target_hedge_delta=target_hedge_delta,
            current_hedge_delta=current_hedge_delta,
            delta_gap=delta_gap,
            theta_budget=theta_budget,
        )

        # 8. 执行调整
        await self._execute_adjustment(
            delta_gap_usd=delta_gap,
            carry=carry,
            theta_budget=theta_budget
        )

        # 9. 更新状态
        self.last_committed_ratio = self.target_hedge_ratio_ema
        self.last_action_ts = time.time()

    # ----------------------------------------------------------------------
    # 比例 / 决策逻辑
    # ----------------------------------------------------------------------
    def _calc_target_ratio(
        self,
        exposure_ratio: float,
        trend_score: float,
        vix_pct: float,
        carry: float,
    ) -> float:
        """
        对冲比例 = exposure_ratio * market_mult

        market_mult = 1 + w_trend * trend_norm + w_vix * vix_norm + w_carry * carry_pos

        - trend_norm: 将趋势分 [-3,3] 压缩到 [-1,1]
        - vix_norm:   将 VIX 分位 [0,1] 映射到 [-1,1]，中位数为 0
        - carry_pos:  Carry >0 时才起作用（期权相对便宜 → 更愿意用期权对冲）
        """
        p = self.params

        # 趋势：越强势（>0），越少对冲；越弱（<0），越多对冲
        trend_norm = max(-1.0, min(1.0, trend_score / 2.0))  # 大致 [-1,1]
        # VIX：高波动/恐慌时（分位高）对冲增大
        vix_norm = (vix_pct - 0.5) * 2.0  # [0,1] → [-1,1]
        # Carry：仅在 Carry > 0 时加快对冲（期权相对便宜）
        carry_pos = max(0.0, carry)       # 仅正向有效，范围约 [0,1]

        market_mult = (
            1.0
            + p["trend_weight"] * (-trend_norm)  # 趋势越强，mult 越小
            + p["vix_weight"] * vix_norm        # VIX 越高，mult 越大
            + p["carry_weight"] * carry_pos     # Carry 越高，对冲意愿越强
        )
        market_mult = max(p["mult_min"], min(p["mult_max"], market_mult))

        ratio = exposure_ratio * market_mult
        return max(0.0, min(1.0, ratio))

    def _should_act(self, new_ratio: float, last_ratio: float) -> bool:
        """
        决定是否真的发起调仓操作：
        1. 冷却期在 _run_cycle 最前面已经检查
        2. 滞后带：比例变化不足 hysteresis 不执行
        """
        hysteresis = self.params["hysteresis"]
        if abs(new_ratio - last_ratio) < hysteresis:
            return False
        return True

    # ----------------------------------------------------------------------
    # 执行层：如何根据 Delta 缺口下单
    # ----------------------------------------------------------------------
    async def _execute_adjustment(self, delta_gap_usd: float, carry: float, theta_budget: float):
        """
        根据 Delta 缺口调整仓位：
        - delta_gap_usd < 0：需要更多负 Delta（买 Put）
        - delta_gap_usd > 0：对冲过多，需要减少 Put（卖出/平仓）
        """

        # 简化版：先只实现期权对冲（SPY Put），线性对冲后面再加
        if delta_gap_usd < 0:
            # 需要增加负 Delta：买入 SPY Put
            await self._add_option_hedge(delta_gap_usd, theta_budget)
        else:
            # 需要减少负 Delta：平掉部分 SPY Put
            await self._reduce_option_hedge(delta_gap_usd)

    async def _add_option_hedge(self, delta_gap_usd: float, theta_budget: float):
        """
        新增对冲仓位（Long Put）
        - 利用 OptionsSelector 选合约
        - 利用 Delta 缺口和 Theta 预算约束张数
        """
        # gap < 0，取绝对值
        gap_abs = abs(delta_gap_usd)

        # 1. 先让 Selector 给出一个“合适”的 SPY Put
        intent = HedgeIntent(
            intent_type="dynamic_quant",
            instrument="SPY",
            size="medium",
            urgency="normal",
        )
        res = await self.selector.select_hedge_contract(
            exposure={"gross": 0, "net": 0},  # 占位
            intent=intent,
            target_notional_usd=gap_abs,
        )
        if not (res and getattr(res, "success", False) and res.contract):
            logger.warning("OptionsSelector failed to select hedge contract", gap=gap_abs)
            return

        contract = res.contract
        sym = getattr(contract, "occ_symbol", None) or getattr(contract, "symbol", None)
        if not sym:
            logger.warning("Hedge contract has no symbol", contract=contract)
            return

        # 2. 获取合约 Delta / Theta 估算
        delta_per_contract_usd, theta_per_contract = await self._estimate_contract_risk(sym, contract)

        if delta_per_contract_usd >= 0:
            logger.warning("Contract delta estimate non-negative, skip hedge", sym=sym)
            return

        # 3. 按 Delta 缺口算理论最大张数
        max_by_delta = int(gap_abs / abs(delta_per_contract_usd))
        if max_by_delta <= 0:
            logger.debug("Delta gap too small for even 1 contract", gap=gap_abs)
            return

        # 4. 按 Theta 预算算最大张数
        if theta_per_contract <= 0:
            max_by_theta = max_by_delta   # 没法估算 Theta，就不按 Theta 限制
        else:
            max_by_theta = int(theta_budget / abs(theta_per_contract))
            if max_by_theta <= 0:
                logger.info(
                    "Theta budget too tight, skip new hedge",
                    theta_budget=theta_budget,
                    theta_per_contract=theta_per_contract,
                )
                return

        final_qty = max(1, min(max_by_delta, max_by_theta))
        logger.info(
            "Add hedge via options",
            symbol=sym,
            gap_usd=gap_abs,
            delta_per_contract_usd=delta_per_contract_usd,
            theta_per_contract=theta_per_contract,
            max_by_delta=max_by_delta,
            max_by_theta=max_by_theta,
            final_qty=final_qty,
        )
        await self._submit_order(sym, final_qty, "BUY", "Quant Hedge Add")

    async def _reduce_option_hedge(self, delta_gap_usd: float):
        """
        减少现有对冲仓位：
        - 简化处理：遍历 sys_hedger 仓位，按 Delta 估算卖出张数
        - 更严格的做法是按到期日排序（先平快到期的），这里留给后续升级
        """
        gap = delta_gap_usd  # 正数，代表“想去掉这么多负 Delta”
        positions = await self._get_hedge_positions()
        if not positions:
            logger.debug("No hedge positions to reduce")
            return

        remaining = gap
        for sym, qty in positions.items():
            if qty <= 0:
                continue
            # 估算每张 Delta USD
            delta_per_contract_usd, _ = await self._estimate_contract_risk(sym)
            if delta_per_contract_usd >= 0:
                continue
            per_contract = abs(delta_per_contract_usd)
            # 当前合约最多能减少多少 Delta
            max_delta_here = qty * per_contract
            if max_delta_here <= 0:
                continue

            # 需要多少张
            need_contracts = int(remaining / per_contract)
            if need_contracts <= 0:
                continue

            to_sell = min(qty, need_contracts)
            await self._submit_order(sym, to_sell, "SELL", "Quant Hedge Reduce")
            remaining -= to_sell * per_contract

            if remaining <= 0:
                break

        logger.info("Reduce hedge done", original_gap=gap, remaining_gap=remaining)

    # ----------------------------------------------------------------------
    # 市场因子：趋势 / VIX / Carry
    # ----------------------------------------------------------------------
    async def _get_spy_trend_score_atr(self) -> float:
        """
        使用 Wilder ATR 的趋势分数：
        score = (Close - EMA20) / ATR20

        - EMA20 使用标准 EMA
        - ATR20 使用 TR 的 Wilder 平滑（行业常见定义）
        """
        try:
            sql = """
            SELECT close, high, low
            FROM trading.bars_1d_ibkr
            WHERE symbol = 'SPY'
            ORDER BY ts ASC
            LIMIT 80
            """
            rows = self.ch.query(sql)
            if not rows or len(rows) < 25:
                return 0.0

            closes = [float(r["close"]) for r in rows]
            highs = [float(r["high"]) for r in rows]
            lows = [float(r["low"]) for r in rows]

            # 计算 EMA20
            ema = closes[0]
            k_ema = 2.0 / (20 + 1)
            for c in closes:
                ema = c * k_ema + ema * (1 - k_ema)

            # 计算 ATR20 (Wilder)
            trs: List[float] = []
            prev_close = closes[0]
            for i in range(1, len(closes)):
                high = highs[i]
                low = lows[i]
                tr = max(
                    high - low,
                    abs(high - prev_close),
                    abs(low - prev_close),
                )
                trs.append(tr)
                prev_close = closes[i]

            if len(trs) < 20:
                return 0.0

            # 初始 ATR = 前 20 根 TR 的平均
            atr = sum(trs[:20]) / 20.0
            # Wilder 平滑后面的 TR
            for tr in trs[20:]:
                atr = (atr * 19 + tr) / 20.0

            if atr <= 0:
                return 0.0

            current_price = closes[-1]
            score = (current_price - ema) / atr
            # 限制在 [-3, 3] 区间内
            if score > 3.0:
                score = 3.0
            elif score < -3.0:
                score = -3.0
            return score

        except Exception as e:
            logger.warning("Failed to compute SPY trend score", error=str(e))
            return 0.0

    async def _get_vix_and_carry_factors(self) -> Tuple[float, float]:
        """
        返回 (VIX 分位数, Carry 信号)

        - VIX 分位数：过去 252 天收盘价的 rank ∈ [0,1]
        - Carry：这里暂时用一个简化版：
            * 当前 VIX 很高 → carry > 0 （期权偏贵，不一定适合大量买入）
            * 当前 VIX 很低 → carry < 0 （期权偏便宜，可以多用）
        实际上应该用 IV vs Realized Vol 的差值，这里给一个结构，后面可以接真实 IV/RV。
        """
        vix_pct = 0.5
        carry = 0.0
        try:
            sql = """
            SELECT close
            FROM trading.refs_vix_ticks
            ORDER BY ts DESC
            LIMIT 252
            """
            rows = self.ch.query(sql)
            if not rows:
                return vix_pct, carry

            vixs = [float(r["close"]) for r in rows]
            current = vixs[0]
            # 分位数：有多少历史值 <= 当前值
            rank = sum(1 for v in vixs if v <= current) / float(len(vixs))
            vix_pct = max(0.0, min(1.0, rank))

            # 简化 Carry：以一个中心值（比如 18）为基准，偏离越大 Carry 绝对值越大
            center = 18.0
            diff = current - center
            # 正值：IV 偏高，期权偏贵；负值：IV 偏低，期权偏便宜
            carry = max(-1.0, min(1.0, diff / 10.0))

        except Exception as e:
            logger.warning("Failed to compute VIX and Carry factors", error=str(e))

        return vix_pct, carry

    # ----------------------------------------------------------------------
    # Greeks 估算 & 风险测度
    # ----------------------------------------------------------------------
    async def _estimate_contract_risk(
        self,
        symbol: str,
        contract: Optional[Any] = None,
    ) -> Tuple[float, float]:
        """
        估算单张合约的 Delta USD 和日 Theta USD。

        优先级：
        1. contract 内部有 greeks: contract.delta, contract.theta, contract.underlying_px
        2. market_data_service.get_option_greeks(symbol)
        3. Fallback：粗略估算（最后兜底）
        """
        delta = None
        theta = None
        underlying_px = None
        multiplier = 100.0

        # 1. 从 contract 里读
        if contract is not None:
            delta = getattr(contract, "delta", None)
            theta = getattr(contract, "theta", None)
            underlying_px = getattr(contract, "underlying_px", None)
            if hasattr(contract, "multiplier"):
                try:
                    multiplier = float(contract.multiplier)
                except Exception:
                    pass

        # 2. 从 MarketDataService 读
        if self.md and (delta is None or theta is None or underlying_px is None):
            try:
                greeks = await self.md.get_option_greeks(symbol)
                if greeks:
                    delta = delta if delta is not None else getattr(greeks, "delta", None)
                    theta = theta if theta is not None else getattr(greeks, "theta", None)
                    underlying_px = underlying_px if underlying_px is not None else getattr(
                        greeks, "underlying_px", None
                    )
            except Exception as e:
                logger.warning("Failed to fetch greeks from market_data_service", symbol=symbol, error=str(e))

        # 3. Fallback：粗略估算
        if underlying_px is None:
            underlying_px = 500.0  # SPY 大致量级，兜底

        if delta is None:
            # 对于 ATM Put，用 -0.4 兜底
            delta = -0.4

        if theta is None:
            # 对于短期 ATM Put，日 Theta 大概是名义价值的 0.5%~1% 以内
            # 粗略估算：名义价值 * 0.0008
            notional = underlying_px * multiplier
            theta = -notional * 0.0008  # 负值：每天亏的时间价值

        delta_usd = delta * underlying_px * multiplier  # 每张合约对组合的 Delta USD
        theta_usd = theta                                # 已经是 USD/天

        return float(delta_usd), float(theta_usd)

    # ----------------------------------------------------------------------
    # 组合敞口 & 现有对冲
    # ----------------------------------------------------------------------
    async def _get_portfolio_exposure(self) -> Dict[str, float]:
        """
        获取当前组合的总敞口（不含本对冲策略的仓位）。

        注意：如果 pnl_pos_5s 包含了对冲仓位，需要在表结构或 SQL 中区分：
        - 例如用 account / strategy_id 过滤主策略与 sys_hedger
        这里给出一个通用写法，如需按具体 schema 修改 WHERE 条件。
        """
        sql = """
        SELECT
            sum(abs(pos_qty * mark_px)) AS gross,
            sum(pos_qty * mark_px)      AS net
        FROM trading.pnl_pos_5s
        WHERE ts_end > now() - INTERVAL 10 MINUTE
          AND strategy_id != 'sys_hedger'
        """
        try:
            res = self.ch.query(sql)
            if res:
                row = res[0]
                return {
                    "gross": float(row.get("gross") or 0.0),
                    "net": float(row.get("net") or 0.0),
                }
        except Exception as e:
            logger.warning("Failed to query portfolio exposure", error=str(e))

        return {"gross": 0.0, "net": 0.0}

    async def _get_current_hedge_delta(self) -> float:
        """
        计算当前对冲仓位的总 Delta USD（仅 sys_hedger 的仓位）。
        """
        positions = await self._get_hedge_positions()
        total = 0.0
        for sym, qty in positions.items():
            if qty == 0:
                continue
            delta_usd, _ = await self._estimate_contract_risk(sym)
            total += qty * delta_usd
        return total

    async def _get_hedge_positions(self) -> Dict[str, float]:
        """
        获取 sys_hedger 策略下的期权持仓。
        """
        if not hasattr(self.strategy_engine, "portfolio_view"):
            return {}
        pf = await self.strategy_engine.portfolio_view(self.strategy_id)
        pos_map: Dict[str, float] = {}
        for p in pf.get("positions", []):
            qty = float(p.get("qty") or 0.0)
            if qty == 0:
                continue
            symbol = p.get("symbol")
            if not symbol:
                continue
            pos_map[symbol] = qty
        return pos_map

    async def _get_total_equity(self) -> float:
        """
        获取账户总净值，用于计算 Theta 预算。

        这里提供一个保守的通用实现：
        - 如果 strategy_engine 提供 account_summary / get_equity 等接口，则优先调用；
        - 否则 fallback 到 max(gross_exposure, config 中的一个最低值)。
        """
        # 1. 尝试从 strategy_engine 读
        if hasattr(self.strategy_engine, "get_account_equity"):
            try:
                eq = await self.strategy_engine.get_account_equity()
                if eq and eq > 0:
                    return float(eq)
            except Exception as e:
                logger.warning("Failed to get account equity from strategy_engine", error=str(e))

        # 2. fallback：用 exposure.gross 当一个近似
        exposure = await self._get_portfolio_exposure()
        gross = exposure.get("gross", 0.0)
        return max(gross * 1.0, 100000.0)  # 保底 10 万

    # ----------------------------------------------------------------------
    # 下单封装
    # ----------------------------------------------------------------------
    async def _submit_order(self, symbol: str, qty: int, side: str, reason: str):
        final_qty = float(qty) if side.upper() == "BUY" else float(-qty)
        envelope = DecisionEnvelope(
            decision_id=make_decision_id(),
            strategy_id=self.strategy_id,
            symbol=symbol,
            ts_bar_end_us=int(time.time() * 1e6),
            target_qty=final_qty,
            order_style=OrderStyle(kind="MKT"),
            freshness=Freshness(ttl_ms=60000, dlb_ms=1000),
            extras={"hedge_reason": reason, "is_hedge": True},
        )
        if self.strategy_engine:
            await self.strategy_engine.submit_intent(self.strategy_id, envelope)
        else:
            logger.warning("No strategy_engine attached, order not submitted", symbol=symbol, qty=final_qty)
```

```python
import asyncio
import json
import time
from datetime import datetime
from typing import Dict, Optional, Any
from zoneinfo import ZoneInfo

from libs.logger import get_logger
from libs.config import config
from libs.db.clickhouse import ClickHouseDB
from libs.strategy.base import DecisionEnvelope, OrderStyle, Freshness
from services.strategy.strategy_base import make_decision_id

# 复用现有的合约选择器逻辑
from scripts.ai_trader.risk.options_selector import OptionsSelector, HedgeIntent

logger = get_logger(__name__)

class HedgingService:
    """
    自动对冲服务 (System-Level Hedging Service)
    
    职责:
    1. 监控全账户 Delta 敞口 (ClickHouse pnl_pos_5s)
    2. 监控市场恐慌指数 (VIX)
    3. 当敞口过大且市场危险时，自动买入反向期权进行对冲
    """

    def __init__(self, strategy_engine, market_data_service=None):
        self.strategy_engine = strategy_engine
        self.md = market_data_service
        self.running = False
        self.selector = OptionsSelector() # 自动加载 config 中的 options policy
        self.ch = ClickHouseDB()
        
        # 加载配置
        self.cfg = config.get("risk_management", {}).get("hedging", {})
        self.enabled = self.cfg.get("enabled", False)
        self.check_interval = self.cfg.get("check_interval_sec", 60)
        
        # 阈值
        thresholds = self.cfg.get("thresholds", {})
        self.max_net_delta = float(thresholds.get("max_net_delta_usd", 50000.0))
        self.activation_vix = float(thresholds.get("activation_vix", 18.0))
        
        # 预算与冷却
        self.last_hedge_ts = 0
        self.cooldown_sec = 300 # 5分钟冷却，避免重复下单

        logger.info("HedgingService initialized", 
                    enabled=self.enabled, 
                    max_delta=self.max_net_delta,
                    activation_vix=self.activation_vix)

    async def start(self):
        """启动对冲守护循环"""
        if not self.enabled:
            logger.info("HedgingService disabled by config")
            return

        self.running = True
        logger.info("🛡️ HedgingService STARTED - Guarding Portfolio")
        
        while self.running:
            try:
                await self._check_and_hedge()
            except Exception as e:
                logger.error("HedgingService loop error", error=str(e), exc_info=True)
            
            await asyncio.sleep(self.check_interval)

    async def stop(self):
        self.running = False
        logger.info("HedgingService stopped")

    async def _check_and_hedge(self):
        # 1. 获取市场状态 (VIX)
        vix = await self._get_current_vix()
        if vix < self.activation_vix:
            # 低波动环境下，允许裸奔，节省期权费
            return

        # 2. 获取组合敞口
        exposure = await self._get_portfolio_exposure()
        net_delta = exposure.get("net", 0.0)
        gross = exposure.get("gross", 0.0)

        # 3. 判断是否触发对冲
        # 逻辑: 如果净敞口 > 阈值 (做多太多) OR 净敞口 < -阈值 (做空太多)
        need_hedge = abs(net_delta) > self.max_net_delta
        
        if not need_hedge:
            return

        # 检查冷却
        now = time.time()
        if now - self.last_hedge_ts < self.cooldown_sec:
            logger.info("Hedging triggered but in cooldown", net_delta=net_delta)
            return

        logger.warning("🚨 HEDGING TRIGGERED", 
                       vix=vix, 
                       net_delta=net_delta, 
                       threshold=self.max_net_delta)

        # 4. 生成对冲意图
        # 如果 net_delta > 0 (做多), 需要 short delta (买 Put) -> intent="drawdown_protect"
        # 如果 net_delta < 0 (做空), 需要 long delta (买 Call)
        intent_type = "beta_balance" 
        
        # 计算需要对冲掉的金额 (目标是把 Delta 压回阈值以内，而不是完全归零，省钱)
        hedge_amount = abs(net_delta) - (self.max_net_delta * 0.8)
        
        intent = HedgeIntent(
            intent_type=intent_type,
            instrument="SPY", # 默认用 SPY 对冲
            size="large" if hedge_amount > 100000 else "medium",
            urgency="high"
        )

        # 5. 选择合约
        # 传入 target_notional_usd 覆盖默认逻辑，精确对冲
        result = await self.selector.select_hedge_contract(
            exposure=exposure,
            intent=intent,
            target_notional_usd=hedge_amount
        )

        if result.success and result.contract:
            # 6. 下单 (通过 StrategyEngine 提交 Intent)
            await self._submit_hedge_order(result.contract, reason=f"Auto-Hedge: VIX={vix}, Delta={net_delta}")
            self.last_hedge_ts = now
        else:
            logger.error("Failed to select hedge contract", error=result.error)

    async def _submit_hedge_order(self, contract, reason: str):
        """将选中的期权合约转化为交易指令"""
        symbol = contract.occ_symbol
        qty = contract.quantity
        
        logger.info("🚀 Submitting Hedge Order", symbol=symbol, qty=qty, reason=reason)
        
        # 构造 DecisionEnvelope
        envelope = DecisionEnvelope(
            decision_id=make_decision_id(),
            strategy_id="sys_hedger", # 特殊策略ID
            symbol=symbol,
            ts_bar_end_us=int(time.time() * 1e6),
            target_qty=float(qty), # 买入
            order_style=OrderStyle(kind="MKT"), # 紧急对冲用市价单
            freshness=Freshness(ttl_ms=60000, dlb_ms=1000),
            extras={
                "hedge_reason": reason,
                "is_hedge": True
            }
        )
        
        # 通过 StrategyEngine 提交，这样会经过 RiskService (RegLite/Quota)
        if self.strategy_engine:
            await self.strategy_engine.submit_intent("sys_hedger", envelope)
        else:
            logger.error("StrategyEngine not linked, cannot place hedge order")

    async def _get_current_vix(self) -> float:
        """获取最新 VIX，优先从 MarketDataService 内存拿，否则查库"""
        # 方式 1: 从 MarketDataService (如果传进来了)
        if self.md:
            try:
                # 假设 md 有 get_last_price 方法
                tick = self.md.get_last_price("VIX") or self.md.get_last_price("VIXY")
                if tick:
                    return float(tick)
            except:
                pass
        
        # 方式 2: 默认返回一个“安全值”避免报错阻断，或者查库
        # 这里简单处理，如果没有实时数据，为了安全起见，假设 VIX 不低
        return 20.0 

    async def _get_portfolio_exposure(self) -> Dict[str, float]:
        """查询 ClickHouse 获取全账户敞口 (复用 options_hedge.py 逻辑)"""
        sql = """
        SELECT
          sum(abs(pos_qty * mark_px)) AS gross,
          sum(pos_qty * mark_px) AS net
        FROM trading.pnl_pos_5s
        WHERE ts_end > now() - INTERVAL 10 MINUTE
        """
        try:
            # 这里需要一个异步执行器，或者因为频率低(60s)，暂时用同步调用
            # 注意：生产环境建议用 aiohttp 或 run_in_executor
            res = self.ch.query(sql)
            if res:
                gross = float(res[0].get('gross') or 0.0)
                net = float(res[0].get('net') or 0.0)
                return {"gross": gross, "net": net}
        except Exception as e:
            logger.error("Failed to query portfolio exposure", error=str(e))
        
        return {"gross": 0.0, "net": 0.0}
```

### 🛠️ 升级一：完整的 `hedging_service.py` (含平仓逻辑)

请使用这份代码覆盖刚才的文件。它新增了 `_check_and_unwind` 方法，当风险解除时自动平仓。

```python
import asyncio
import time
from typing import Dict, Optional, Any

from libs.logger import get_logger
from libs.config import config
from libs.db.clickhouse import ClickHouseDB
from libs.strategy.base import DecisionEnvelope, OrderStyle, Freshness
from services.strategy.strategy_base import make_decision_id
from scripts.ai_trader.risk.options_selector import OptionsSelector, HedgeIntent

logger = get_logger(__name__)

class HedgingService:
    """
    自动对冲服务 (System-Level Hedging Service) - 完整闭环版
    
    职责:
    1. 开仓对冲 (Hedging): 敞口过大 + VIX 高 -> 买入反向期权
    2. 平仓回归 (Unwinding): 敞口回归 + VIX 回落 -> 卖出对冲持仓
    """

    def __init__(self, strategy_engine, market_data_service=None):
        self.strategy_engine = strategy_engine
        self.md = market_data_service
        self.running = False
        self.selector = OptionsSelector()
        self.ch = ClickHouseDB()
        
        # 加载配置
        self.cfg = config.get("risk_management", {}).get("hedging", {})
        self.enabled = self.cfg.get("enabled", False)
        self.check_interval = self.cfg.get("check_interval_sec", 60)
        
        # 阈值配置
        thresholds = self.cfg.get("thresholds", {})
        self.max_net_delta = float(thresholds.get("max_net_delta_usd", 50000.0))
        self.activation_vix = float(thresholds.get("activation_vix", 18.0))
        
        # 平仓阈值 (Hysteresis/滞后区间，防止反复震荡)
        # 当敞口降到 50% 以下，或者 VIX 降到 激活线-2 以下时，开始平仓
        self.unwind_delta_threshold = self.max_net_delta * 0.5 
        self.unwind_vix_threshold = self.activation_vix - 2.0
        
        self.last_action_ts = 0
        self.cooldown_sec = 300 
        self.strategy_id = "sys_hedger" # 专用的对冲策略ID

        logger.info("HedgingService initialized", 
                    enabled=self.enabled, 
                    max_delta=self.max_net_delta,
                    unwind_delta=self.unwind_delta_threshold)

    async def start(self):
        if not self.enabled:
            logger.info("HedgingService disabled")
            return
        self.running = True
        logger.info("🛡️ HedgingService STARTED (Full Loop)")
        while self.running:
            try:
                await self._run_cycle()
            except Exception as e:
                logger.error("HedgingService cycle error", error=str(e), exc_info=True)
            await asyncio.sleep(self.check_interval)

    async def stop(self):
        self.running = False
        logger.info("HedgingService stopped")

    async def _run_cycle(self):
        # 1. 获取状态
        vix = await self._get_current_vix()
        exposure = await self._get_portfolio_exposure()
        net_delta = exposure.get("net", 0.0)
        
        # 2. 获取当前对冲持仓 (查询 sys_hedger 账户)
        # 注意：需要 StrategyEngine 支持 portfolio_view
        current_hedge_pos = await self._get_hedge_positions()
        has_hedge = len(current_hedge_pos) > 0

        # 检查冷却
        if time.time() - self.last_action_ts < self.cooldown_sec:
            return

        # === 逻辑分支 A: 需要开仓对冲吗？ ===
        # 条件: (敞口超限 AND VIX高) AND (当前没对冲 OR 敞口继续恶化)
        is_dangerous = abs(net_delta) > self.max_net_delta and vix > self.activation_vix
        
        if is_dangerous:
            await self._execute_hedge(exposure, net_delta, vix)
            return

        # === 逻辑分支 B: 需要平仓退保吗？ (Unwind) ===
        # 条件: 有持仓 AND (敞口已安全 OR VIX已回落)
        is_safe_now = abs(net_delta) < self.unwind_delta_threshold or vix < self.unwind_vix_threshold
        
        if has_hedge and is_safe_now:
            await self._execute_unwind(current_hedge_pos, reason=f"Risk Subsiding: VIX={vix}, Delta={net_delta}")
            return

    async def _execute_hedge(self, exposure, net_delta, vix):
        logger.warning("🚨 OPENING HEDGE", net_delta=net_delta, vix=vix)
        
        # 计算目标对冲金额 (只对冲超额部分 + 缓冲)
        target_hedge = abs(net_delta) - self.unwind_delta_threshold
        if target_hedge < 10000: return # 太小不折腾

        intent_type = "beta_balance"
        intent = HedgeIntent(
            intent_type=intent_type,
            instrument="SPY",
            size="large" if target_hedge > 100000 else "medium",
            urgency="high"
        )
        
        result = await self.selector.select_hedge_contract(
            exposure=exposure, intent=intent, target_notional_usd=target_hedge
        )

        if result.success and result.contract:
            await self._submit_order(
                symbol=result.contract.occ_symbol, 
                qty=result.contract.quantity, 
                side="BUY",
                reason=f"Hedge Open: VIX={vix}"
            )
            self.last_action_ts = time.time()

    async def _execute_unwind(self, positions, reason):
        """平掉所有对冲持仓"""
        logger.info("🕊️ UNWINDING HEDGE (Risk Off)", reason=reason)
        
        for symbol, qty in positions.items():
            if qty == 0: continue
            
            # 平仓方向相反
            side = "SELL" if qty > 0 else "BUY"
            close_qty = abs(qty)
            
            await self._submit_order(
                symbol=symbol,
                qty=close_qty, # submit_order 内部根据 side 处理正负
                side=side,
                reason=f"Unwind: {reason}"
            )
        self.last_action_ts = time.time()

    async def _submit_order(self, symbol: str, qty: float, side: str, reason: str):
        """统一发单入口"""
        final_qty = qty if side == "BUY" else -qty
        
        envelope = DecisionEnvelope(
            decision_id=make_decision_id(),
            strategy_id=self.strategy_id,
            symbol=symbol,
            ts_bar_end_us=int(time.time() * 1e6),
            target_qty=float(final_qty),
            order_style=OrderStyle(kind="MKT"),
            freshness=Freshness(ttl_ms=60000, dlb_ms=1000),
            extras={"hedge_reason": reason, "is_hedge": True}
        )
        
        if self.strategy_engine:
            await self.strategy_engine.submit_intent(self.strategy_id, envelope)
            logger.info("Sent Order", symbol=symbol, qty=final_qty, reason=reason)

    async def _get_hedge_positions(self) -> Dict[str, float]:
        """查询 sys_hedger 策略名下的持仓"""
        # 如果 StrategyEngine 还没有 portfolio_view，我们需要直接查数据库或 PortfolioService
        # 这里假设 StrategyEngine 已经有了我们之前讨论的接口
        try:
            if hasattr(self.strategy_engine, "portfolio_view"):
                pf = await self.strategy_engine.portfolio_view(self.strategy_id)
                # pf 结构: {'positions': [{'symbol': '...', 'qty': 10}, ...]}
                pos_map = {}
                for p in pf.get("positions", []):
                    if p['qty'] != 0:
                        pos_map[p['symbol']] = p['qty']
                return pos_map
        except Exception as e:
            logger.error("Failed to get hedge positions", error=str(e))
        return {}

    async def _get_current_vix(self) -> float:
        # (保持之前的逻辑)
        if self.md:
            try:
                tick = self.md.get_last_price("VIX") or self.md.get_last_price("VIXY")
                if tick: return float(tick)
            except: pass
        return 20.0

    async def _get_portfolio_exposure(self) -> Dict[str, float]:
        # (保持之前的 ClickHouse 逻辑)
        sql = """
        SELECT sum(abs(pos_qty * mark_px)) AS gross, sum(pos_qty * mark_px) AS net
        FROM trading.pnl_pos_5s WHERE ts_end > now() - INTERVAL 10 MINUTE
        """
        try:
            res = self.ch.query(sql)
            if res:
                return {"gross": float(res[0].get('gross') or 0.0), "net": float(res[0].get('net') or 0.0)}
        except: pass
        return {"gross": 0.0, "net": 0.0}
```

import time
import math
import json
from typing import Dict, Optional, Any, Tuple
from datetime import datetime, timedelta

from libs.logger import get_logger

from libs.strategy.base import DecisionEnvelope, OrderStyle, Freshness
from services.strategy.strategy_base import make_decision_id
from scripts.ai_trader.risk.options_selector import OptionsSelector, HedgeIntent

logger = get_logger(__name__)

class HedgingService:
    """
    量化动态对冲服务 (Quantitative Dynamic Hedging Service)
    
    特性:
    1. 归一化因子: 使用 ATR 标准化趋势，使用 Rank 标准化 VIX。
    2. 成本感知: 引入 Carry (IV/RV) 决定工具，引入 Theta Budget 决定规模。
    3. 防抖动: 采用 EMA 平滑对冲比例 + 滞后带控制。
    """

    def __init__(self, strategy_engine, market_data_service=None):
        self.strategy_engine = strategy_engine
        self.md = market_data_service
        self.running = False
        self.selector = OptionsSelector()
        self.ch = ClickHouseDB()
        
        # --- 配置加载 ---
        self.cfg = config.get("risk_management", {}).get("hedging", {})
        self.enabled = self.cfg.get("enabled", False)
        self.check_interval = self.cfg.get("check_interval_sec", 60)

        thresholds = self.cfg.get("thresholds", {})
        self.max_net_delta = float(thresholds.get("max_net_delta_usd", 50000.0))

        self.params = {
            "ratio_base": 0.10,      # 基础底仓比例
            "w_vix": 0.40,           # VIX 权重
            "w_trend": 0.30,         # 趋势权重
            "w_carry": 0.20,         # 波动率溢价权重
            "smooth_alpha": 0.3,     # EMA 平滑系数
            "hysteresis": 0.05,      # 滞后带宽度
            "theta_budget_pct": 0.0005 # 每日 Theta 预算占净值比例 (5bps)
        }
        # 覆盖默认参数
        if "dynamic_params" in self.cfg:
            self.params.update(self.cfg["dynamic_params"])

        # 状态记录
        self.last_action_ts = 0
        self.cooldown_sec = self.cfg.get("cooldown_sec", 300)
        self.strategy_id = "sys_hedger"
        self.last_target_ratio = 0.0 # 上一次计算的目标比例 (未平滑)
        self.current_smooth_ratio = 0.0 # 当前平滑后的比例
        self.last_committed_ratio = 0.0 # 上一次实际执行的比例

        logger.info("QuantHedging initialized", config=self.params)

    async def start(self):
        if not self.enabled: return
        self.running = True
        logger.info("🛡️ Quant Hedging Service STARTED")
        while self.running:
            try:
                await self._run_cycle()
            except Exception as e:
                logger.error("Hedging cycle error", error=str(e), exc_info=True)
            await asyncio.sleep(self.check_interval)

    async def stop(self):
        self.running = False

    async def _run_cycle(self):
        # 1. 获取市场因子 (标准化)
        trend_score = await self._get_spy_trend_score_atr() # 范围约 [-2, 2]
        vol_factors = await self._get_vol_factors()         # {vix_pct: 0-1, carry: -1~1}
        
        # 2. 计算目标对冲比例 (Raw -> Smoothed)
        target_ratio = self._calc_target_ratio(
            vix_pct=vol_factors['vix_pct'], 
            trend_score=trend_score, 
            carry=vol_factors['carry']
        )
        
        # EMA 平滑
        alpha = self.params["smooth_alpha"]
        self.current_smooth_ratio = alpha * target_ratio + (1 - alpha) * self.current_smooth_ratio
        
        # 3. 判断是否执行 (冷却 + 滞后带)
        if not self._should_act(self.current_smooth_ratio, self.last_committed_ratio):
            return

        # 4. 获取敞口与资产
        exposure = await self._get_portfolio_exposure()
        net_delta = exposure.get("net", 0.0)
        # 假设总资产 (Equity) 用于计算 Theta 预算，暂时用 fixed value 或查库
        total_equity = 100000.0 # TODO: 从 StrategyEngine.get_account_summary 获取
        
        # 5. 计算目标对冲金额 (Target Hedge Delta)
        # 逻辑: 只对冲净敞口的反向部分
        # 比如 net_delta = +100k (Long), ratio = 0.4 -> Target Hedge = -40k
        target_hedge_delta = -1.0 * net_delta * self.current_smooth_ratio
        
        # 6. 获取当前对冲仓位 Delta
        current_hedge_delta = await self._get_current_hedge_delta()
        
        # 7. 计算缺口
        delta_gap = target_hedge_delta - current_hedge_delta
        
        # 8. 执行调整
        min_gap = self.cfg.get("min_gap_usd", 10000)
        if abs(delta_gap) > min_gap:
            logger.info("Adjusting Hedge", 
                        trend=f"{trend_score:.2f}", 
                        vix_pct=f"{vol_factors['vix_pct']:.2f}",
                        ratio=f"{self.current_smooth_ratio:.2f}",
                        gap=f"${delta_gap:,.0f}")
            
            await self._execute_adjustment(
                delta_gap_usd=delta_gap, 
                carry=vol_factors['carry'],
                equity=total_equity
            )
            # 更新状态
            self.last_committed_ratio = self.current_smooth_ratio
            self.last_action_ts = time.time()

    def _calc_target_ratio(self, vix_pct: float, trend_score: float, carry: float) -> float:
        """
        计算公式: Ratio = Base + w1*VixPct - w2*Trend + w3*Carry
        """
        p = self.params
        raw = (p["ratio_base"] 
               + p["w_vix"] * vix_pct 
               - p["w_trend"] * trend_score 
               + p["w_carry"] * max(0.0, carry)) # 只有 Carry>0 (期权便宜) 才增加对冲
        return max(0.0, min(1.0, raw))

    def _should_act(self, new_ratio: float, last_committed: float) -> bool:
        # 1. 冷却检查
        if time.time() - self.last_action_ts < self.cooldown_sec:
            return False
        # 2. 滞后带检查 (Hysteresis)
        if abs(new_ratio - last_committed) < self.params["hysteresis"]:
            return False
        return True

    async def _execute_adjustment(self, delta_gap_usd: float, carry: float, equity: float):
        """执行层：选择工具并下单"""
        # 1. 工具选择 (Vehicle Selection)
        # 如果 Carry 高 (IV >> RV)，期权太贵，优先用线性工具 (反向ETF/期货)
        # 如果 Carry 低，期权便宜，优先用 Put (获取凸性)
        vehicle = "options"
        if carry > 0.2: # 阈值可配
            vehicle = "linear"
            
        # 2. 方向判断
        action = "ADD" if delta_gap_usd < 0 else "REDUCE" # gap<0 需要更多负Delta(买Put/卖指)
        
        if vehicle == "linear":
            # 线性对冲逻辑 (卖 SPY 或买 SH) - 暂未实现，打印日志
            logger.warning("Linear hedge suggested but not implemented", gap=delta_gap_usd)
            return 

        # 3. 期权对冲 (Theta 预算约束)
        if action == "ADD":
            # 计算预算: 每日允许亏损 Theta
            theta_budget = equity * self.params["theta_budget_pct"]
            
            # 调用 Selector (传入 intent 强制使用 options)
            intent = HedgeIntent(
                intent_type="dynamic_quant", 
                instrument="SPY", 
                size="large", 
                urgency="normal"
            )
            res = await self.selector.select_hedge_contract(
                exposure={"gross": 0, "net": 0}, # 占位
                intent=intent,
                target_notional_usd=abs(delta_gap_usd)
            )
            
            if res.success and res.contract:
                # 检查 Theta 是否超标 (假设 OptionsSelector 返回了 Greeks，或估算)
                # 估算 Theta: 通常 ATM Put 日 Theta ≈ 名义价值 * 0.0005 ~ 0.001
                est_theta = res.contract.notional_usd * 0.0008 
                
                final_qty = res.contract.quantity
                if est_theta > theta_budget:
                    scale = theta_budget / est_theta
                    final_qty = max(1, int(final_qty * scale))
                    logger.info("Theta constraint applied", original=res.contract.quantity, scaled=final_qty)

                await self._submit_order(res.contract.occ_symbol, final_qty, "BUY", "Quant Hedge Add")
                
        elif action == "REDUCE":
            # 减少对冲：平仓
            # 优先平掉 Theta 损耗最高的（快到期的）
            positions = await self._get_hedge_positions()
            # 简单处理：按比例平仓
            delta_to_reduce = delta_gap_usd # 正数
            # 假设每张 Put Delta USD ≈ 20000
            contracts = int(delta_to_reduce / 20000.0)
            
            for sym, qty in positions.items():
                if contracts <= 0: break
                to_sell = min(qty, contracts)
                await self._submit_order(sym, to_sell, "SELL", "Quant Hedge Reduce")
                contracts -= to_sell

    # --- 指标计算组件 ---

    async def _get_spy_trend_score_atr(self) -> float:
        """计算 (Price - EMA20) / ATR20"""
        try:
            # 取60天数据以确保 EMA/ATR 稳定
            sql = """
            SELECT close, high, low FROM trading.bars_1d_ibkr 
            WHERE symbol='SPY' ORDER BY ts ASC LIMIT 60
            """
            rows = self.ch.query(sql)
            if not rows or len(rows) < 30: return 0.0
            
            closes = [float(r['close']) for r in rows]
            highs = [float(r['high']) for r in rows]
            lows = [float(r['low']) for r in rows]
            
            # 简易计算 EMA20
            ema = closes[0]
            k = 2 / (20 + 1)
            for c in closes:
                ema = c * k + ema * (1 - k)
                
            # 简易计算 ATR20
            trs = []
            for i in range(1, len(closes)):
                tr = max(highs[i]-lows[i], abs(highs[i]-closes[i-1]), abs(lows[i]-closes[i-1]))
                trs.append(tr)
            atr = sum(trs[-20:]) / 20.0 if trs else 1.0
            
            # 归一化分数
            score = (closes[-1] - ema) / atr
            return max(-2.0, min(2.0, score)) # Clip
        except Exception:
            return 0.0

    async def _get_vol_factors(self) -> Dict[str, float]:
        """计算 VIX 分位与 Carry"""
        vix_pct = 0.5
        carry = 0.0
        try:
            # 1. VIX Rank (过去 252 天)
            sql = "SELECT close FROM trading.refs_vix_ticks ORDER BY ts DESC LIMIT 252"
            rows = self.ch.query(sql)
            if rows:
                vixs = [float(r['close']) for r in rows]
                current = vixs[0]
                rank = sum(1 for v in vixs if v <= current) / len(vixs)
                vix_pct = rank
                
            # 2. Carry (IV/RV)
            # 这里假设你有 implied_vol 表，如果没有，暂时用 VIX 代替 IV，用历史波动率代替 RV
            # 简化版：如果 VIX 处于低位但历史波动率更低，Carry 正 (期权贵)
            # 这是一个高阶特性，暂且用 VIX 绝对值模拟
            if current > 25: carry = 0.5 # 恐慌时 IV 通常极高，Carry 高 -> 也许该卖空期货而不是买期权
            
        except Exception:
            pass
        return {"vix_pct": vix_pct, "carry": carry}

    # --- 基础组件 (复用之前的) ---
    async def _get_current_hedge_delta(self) -> float:
        pos = await self._get_hedge_positions()
        total = 0.0
        for sym, qty in pos.items():
            # 粗略估算 Delta USD，实盘应查 Option Greeks
            total += (qty * 100 * 500 * -0.4) 
        return total

    async def _get_hedge_positions(self) -> Dict[str, float]:
        if hasattr(self.strategy_engine, "portfolio_view"):
            pf = await self.strategy_engine.portfolio_view(self.strategy_id)
            pos_map = {}
            for p in pf.get("positions", []):
                 if p['qty'] != 0: pos_map[p['symbol']] = p['qty']
            return pos_map
        return {}

    async def _get_portfolio_exposure(self) -> Dict[str, float]:
        sql = "SELECT sum(abs(pos_qty * mark_px)) AS gross, sum(pos_qty * mark_px) AS net FROM trading.pnl_pos_5s WHERE ts_end > now() - INTERVAL 10 MINUTE"
        try:
            res = self.ch.query(sql)
            if res: return {"gross": float(res[0].get('gross') or 0.0), "net": float(res[0].get('net') or 0.0)}
        except: pass
        return {"gross": 0.0, "net": 0.0}

    async def _submit_order(self, symbol, qty, side, reason):
        final_qty = float(qty) if side == "BUY" else float(-qty)
        envelope = DecisionEnvelope(
            decision_id=make_decision_id(),
            strategy_id=self.strategy_id,
            symbol=symbol,
            ts_bar_end_us=int(time.time() * 1e6),
            target_qty=final_qty,
            order_style=OrderStyle(kind="MKT"),
            freshness=Freshness(ttl_ms=60000, dlb_ms=1000),
            extras={"hedge_reason": reason, "is_hedge": True}
        )
        if self.strategy_engine:
            await self.strategy_engine.submit_intent(self.strategy_id, envelope)

### 💡 配置补充

请同步更新 `config.yml` 中的 `dynamic_params`，方便后续调优（不用改代码）：

```yaml
risk_management:
  hedging:
    enabled: true
    check_interval_sec: 60
    thresholds:
      max_net_delta_usd: 50000
    # 新增：量化参数
    dynamic_params:
      ratio_base: 0.10       # 哪怕风平浪静，也保持 10% 对冲 (黑天鹅底仓)
      w_vix: 0.40            # VIX 对决策的影响权重 (最大)
      w_trend: 0.30          # 趋势权重
      w_carry: 0.20          # 成本权重
      smooth_alpha: 0.3      # 平滑因子 (越小越平滑，反应越慢)
      hysteresis: 0.05       # 5% 变化才触发交易
      theta_budget_pct: 0.0005 # 每天最多亏万分之五的时间价值
```

### 这个版本的质变

1.  **告别拍脑袋**：对冲比例不再是“我觉得”，而是由 VIX Rank 和 Trend Score 算出来的。
2.  **成本可控**：通过 `theta_budget_pct`，你明确知道每天为“安全”支付多少钱。如果市场不动，系统会自动减少对冲量以节省权利金。
3.  **拒绝左右挨打**：EMA 平滑 + Hysteresis 滞后带，确保只有趋势确立或风险显著变化时才动手，避免在震荡市中反复磨损。
