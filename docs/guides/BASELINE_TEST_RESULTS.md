## 关键发现

### 1. 市场不可预测性证据

| 指标 | 随机baseline | 5分钟窗口 | 10分钟窗口 | 生产模型(30分钟) |
|------|-------------|----------|-----------|----------------|
| Accuracy | 50% | **51.2%** | **50.9%** | **50.85%** |
| AUC | 0.50 | **0.515** | **0.509** | **0.514** |
| IC | 0.00 | **0.030** | **0.015** | **0.016** |

**结论**:
- 即使最简单的特征，所有预测窗口都无法超过随机猜测
- 缩短预测窗口略有改善，但远不足以实用
- 生产模型的16个特征并没有带来实质性提升

### 2. 为什么会失败？

#### 可能原因1: 市场效率

TSLA在1分钟级别可能接近有效市场：
- 高频交易者已经捕获了大部分可预测的模式
- 简单的技术指标(ret_1m, volume_ratio)信息已被price in
- 需要更复杂的特征（订单流、微观结构）才可能有效

#### 可能原因2: 数据不足

```
时间范围: 2025-10-01 至 2025-11-08 (约1个月)
样本数: 33,960行
```

问题:
- 1个月数据可能不足以学习稳定模式
- 缺乏不同市场regime的数据（牛市、熊市、震荡）
- 建议: 至少需要6-12个月数据

#### 可能原因3: 特征设计

当前特征过于简单:
```python
ret_1m         # 1分钟收益率
volume_ratio   # 成交量相对20周期均值
spread_bps     # 买卖价差 (当前为0，未实现)
```

缺失关键特征:
- 订单流不平衡 (buy/sell pressure)
- 大单追踪 (whale activity)
- 订单簿深度
- 跨资产相关性 (SPY, QQQ)
- 波动率regime

#### 可能原因4: 标签定义

当前标签: 简单的方向预测
```sql
if(lead(close, N) OVER w > close, 1, 0) AS label
```

问题:
- 忽略了价格变化幅度
- 未考虑交易成本
- 应该预测risk-adjusted return而非简单方向

## 决策建议

### 方案A: 继续ML路线（高风险）

**条件**: 只有在以下情况下才值得继续
1. 能获取更多历史数据（6-12个月）
2. 能实现高级特征（订单流、L2数据）
3. 有足够时间进行研究（2-3周）

**步骤**:
1. 加载更多历史数据
   ```bash
   python tool/load_hist_multi.py --symbols TSLA --bar-size "1 min" --days 180
   ```

2. 实现高级特征工程
   - 订单流: buy/sell imbalance, tick rule
   - 微观结构: spread, depth, quote pressure
   - Market regime: volatility clustering, correlation with SPY

3. 优化标签定义
   ```sql
   -- 风险调整收益而非简单方向
   (lead(close, N) - close) / atr_14 AS risk_adjusted_return
   ```

4. 重新训练baseline
   - 目标: Acc>55%, IC>0.05
   - 如仍失败 → 放弃ML

**预期成功率**: 30%

---

### 方案B: 切换到规则策略（推荐）⭐

**原因**:
- 当前数据无法支持ML
- 规则策略更容易理解和调试
- 不需要大量历史数据
- 可以立即开始实盘测试

**推荐策略**:

#### 1. Mean Reversion策略
```python
# RSI超买超卖反转
if rsi_14 < 30 and volume > avg_volume * 1.5:
    signal = BUY  # 超卖+放量 → 反转
elif rsi_14 > 70 and volume > avg_volume * 1.5:
    signal = SELL  # 超买+放量 → 反转
```

特点:
- 适合震荡市
- 止损明确（ATR的2倍）
- 持仓时间短（30-60分钟）

#### 2. Momentum突破策略
```python
# 突破+成交量确认
if close > ema_20 and volume > avg_volume * 2.0 and atr_14 > atr_14_sma * 1.2:
    signal = BUY  # 突破+放量+波动率上升
```

特点:
- 适合趋势市
- 风险收益比高
- 需要严格止损

#### 3. 订单流策略（如果有L2数据）
```python
# 大单跟随
if large_buy_trades > large_sell_trades * 1.5:
    signal = BUY  # 大单买入压力
```

**实施步骤**:
1. 选择1-2个策略进行Paper Trading
2. 运行2-4周收集数据
3. 分析结果，调整参数
4. 如表现好 → 小资金实盘
5. 逐步增加资金

## 最终决策

基于baseline测试结果，我建议:

### 🚫 **不继续当前ML路线**

原因:
1. 即使最简单的baseline也无法超过随机
2. 生产模型（16特征，30分钟窗口）表现同样差
3. `minute_of_day`特征导致过拟合，移除后模型无预测能力
4. 需要更多数据和更复杂特征，但成功率低

### ✅ **立即切换到规则策略**

原因:
1. 可解释性强
2. 不需要大量历史数据
3. 易于调试和优化
4. 可以快速迭代

**下一步行动**:
1. 实现2-3个规则策略（Mean Reversion + Momentum）
2. 在Bug #10修复后的backtest engine上测试
3. Paper Trading 2-4周
4. 根据结果决定是否实盘

> "我们做机器学习是为了赚钱，置信度要严格，因为我不想garbage in garbage out"
