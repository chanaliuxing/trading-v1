## 🎯 核心原则

### 1. 用人话,不要用代码

❌ `diagnosis: "no_trading_history_due_to_new_system_init"`
✅ "系统刚启动,正在收集数据"

❌ `confidence: 0.9`
✅ "AI 非常确定 (90% 置信度)"

❌ `key: "risk_management.guardian.dd_intraday_pct", value: -5.0`
✅ "回撤限制设为 -5% (如果今天亏 5%,停止交易)"

---

### 2. 告诉我"为什么"和"怎么办"

❌ 只显示数据:
```
最后更新: 11 小时前
```

✅ 解释 + 行动:
```
🔴 AI 大脑已停止 11 小时

为什么这很重要:
系统无法根据市场变化自动调整参数

我应该做什么:
1. [一键重启]
2. [查看日志]
3. [联系技术支持]
```

---

### 3. 关注"效果",不要只显示"动作"

❌ AI 修改了配置:
```
risk_management.guardian.dd_intraday_pct = -5.0
```

✅ AI 修改的效果:
```
AI 设置了 -5% 回撤限制

今天的效果:
✅ 未触发限制 (最大回撤 -2.3%)
💰 保护了账户 (如果没有限制,可能亏 -8%)

历史效果:
过去 30 天,这个限制触发了 3 次,
避免了平均 $1,200 的损失
```

---

### 4. 给我"下一步",不要让我猜

❌ 显示诊断:
```
diagnosis: "performance_degradation"
```

✅ 告诉我该做什么:
```
⚠️ AI 检测到性能下降

原因:
过去 2 小时,策略准确率从 65% 降到 45%

AI 已经做了:
- 停止新开仓
- 减少仓位大小

我需要做什么:
🔍 [查看详细性能报告]
⚙️ [手动调整策略参数]
📞 [等待 AI 自动恢复] (推荐)

预计恢复时间: 1-2 小时
```

---

## 💭 结论

我之前做的 dashboard 是给**开发者**看的,不是给**管理员**看的。

管理员需要的是:
1. ✅ **一眼看出**系统是否正常
2. ✅ **人话解释** AI 在做什么
3. ✅ **明确指示**我应该做什么
4. ✅ **效果反馈** AI 的决策是否有效

而不是:
- ❌ JSON 字段
- ❌ 技术术语
- ❌ 统计图表 (没有解释)
- ❌ 让我自己去猜 "这意味着什么"

---

**需要完全重新设计。**
