### 🚨 **关键问题1: 模型准确率极低**

| 指标 | 交叉验证 | Out-of-Fold | 评估 |
|------|---------|-------------|------|
| **Accuracy** | **50.85%** | **50.85%** | ❌ **基本等于随机猜测** |
| **AUC** | **0.514** | **0.509** | ❌ **几乎无预测能力** |
| **IC** | 0.025 | 0.016 | ⚠️ 极低相关性 |
| Sharpe | 4.14 | 4.80 | ⚠️ 异常高（可能过拟合）|

**分析**:
- **Accuracy = 50.85%** 意味着模型只比抛硬币好一点点
- **AUC = 0.514** (0.5=随机，1.0=完美) → 几乎没有区分能力
- **IC = 0.016-0.025** (信息系数) → 预测值和实际值相关性极低
- **Sharpe = 4.8** 但Accuracy这么低 → **矛盾！可能是计算错误或数据泄漏**

### 💡 **为什么置信度低？**

当模型Accuracy≈50%时：
```python
# 假设模型输出概率
pred_proba = [0.51, 0.49, 0.52, 0.48, ...]  # 在0.5附近摆动
```

这意味着：
1. 模型**非常不确定** → 概率总是接近50%
2. 即使预测"涨"，置信度也只有51%
3. **conf_floor=0.40** → 大部分预测会通过
4. **但实际预测能力极弱！**
