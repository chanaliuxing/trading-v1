**关键代码**:
```python
class ProviderPool:
    async def call_with_fallback(
        self,
        prompt: str,
        operation: str = "unknown"
    ) -> Tuple[Dict[str, Any], str, str]:
        """
        调用 Provider 池，自动 Fallback

        Returns: (parsed_json, raw_response, provider_used)
        Raises: RuntimeError if all providers fail
        """
        for i, config in enumerate(self.configs):
            for attempt in range(1, config.max_retries + 1):
                success, data, raw, error = await self._call_provider(config, prompt, attempt)
                if success:
                    return data, raw, config.name

        raise RuntimeError(f"All {len(self.configs)} providers failed")
```

```python
async def _ask(self, prompt: str, timeout: float = 300.0, operation: str = "unknown") -> tuple[Dict[str, Any], str, str]:
    """
    Call LLM with automatic provider fallback and return (parsed_json, raw_response, provider_used)
    """
    try:
        # Use ProviderPool with automatic fallback
        data, raw, provider_used = await self.pool.call_with_fallback(prompt, operation)
        self.log.info(
            "llm_call_success",
            operation=operation,
            provider=provider_used,
            response_len=len(raw)
        )
        return data, raw, provider_used

    except RuntimeError as e:
        # All providers failed
        self.log.error("all_providers_failed", operation=operation, error=str(e))
        return {"error": "all_providers_failed"}, "", "none"
```

## 🔍 **技术细节**

### Fallback 流程

```
Request: propose_plan()
  ↓
Call ProviderPool.call_with_fallback(prompt, "propose_plan")
  ↓
Try Provider #1: deepseek_nvidia
  ├─ Timeout: 60s
  ├─ Max Retries: 1
  ↓
  Success?
  ├─ Yes → Return (data, raw, "deepseek_nvidia")
  └─ No (Timeout/Error)
      ↓
      Log fallback event: deepseek_nvidia → gemini
      ↓
      Try Provider #2: gemini
      ├─ Timeout: 30s
      ├─ Max Retries: 1
      ↓
      Success?
      ├─ Yes → Return (data, raw, "gemini")
      └─ No (Timeout/Error)
          ↓
          Log fallback event: gemini → openai
          ↓
          Try Provider #3: openai
          ├─ Timeout: 45s
          ├─ Max Retries: 1
          ↓
          Success?
          ├─ Yes → Return (data, raw, "openai")
          └─ No (Timeout/Error)
              ↓
              Log: ALL PROVIDERS FAILED
              ↓
              Raise RuntimeError("All 3 providers failed")
```

**最坏情况延迟**: 60s + 30s + 45s = 135 秒（所有 provider 都超时）

**最好情况**: < 5 秒（primary provider 成功）

**查询**:
```sql
SELECT
    formatDateTime(ts_ny, '%Y-%m-%d %H:%M:%S') as time,
    details
FROM llm.session_cleanup_log
WHERE action = 'FALLBACK_EVENT'
ORDER BY ts_ny DESC
LIMIT 20
```

## ⚠️ **注意事项**

### 1. API Key 要求

**所有 fallback provider 都需要有效的 API key**，否则 fallback 会失败。

**当前要求**:
- `NVIDIA_API_KEY` - deepseek_nvidia
- `GEMINI_API_KEY` - gemini
- `OPENAI_API_KEY` - openai

**检查**:
```bash
echo "NVIDIA_API_KEY: ${NVIDIA_API_KEY:0:10}..."
echo "GEMINI_API_KEY: ${GEMINI_API_KEY:0:10}..."
echo "OPENAI_API_KEY: ${OPENAI_API_KEY:0:10}..."
```

**如果缺少某个 key**:
- **Option 1**: 添加 API key
- **Option 2**: 从 ProviderPool 配置中移除该 provider

### 2. 成本影响

**Fallback = 额外 API 成本**

如果 deepseek_nvidia 频繁失败并 fallback 到 openai，将产生 OpenAI API 费用。

**当前定价** (参考):
- deepseek_nvidia: $0.002/1K tokens (便宜)
- gemini: $0.001/1K tokens (最便宜)
- openai (gpt-4o-mini): $0.15/1M tokens (中等)

**监控成本**:
```bash
# 统计实际使用的 provider 分布
cat runs/$(date +%Y-%m-%d)/brain_calls.jsonl | jq -r '.provider' | sort | uniq -c
```

**建议优先级** (按成本):
1. gemini (最便宜)
2. deepseek_nvidia (便宜)
3. openai (较贵)

### 3. 性能影响

**Fallback 会增加延迟** (timeout + retry time)

**最坏情况**: 60s + 30s + 45s = 135 秒

**缓解方法**:
- 减小 timeout（但可能导致误判）
- 减少 max_retries（但降低成功率）
- 监控 `duration_ms` 并调整配置

### 4. 向后兼容

**ControlBrain 保持向后兼容**:
- `self.provider` 仍存在（用于日志）
- `self._prov` 仍存在（直接访问 provider，如果需要）
- `_ensure_provider()` 仍可用

**但**: 新的 `_ask()` 方法默认使用 ProviderPool。

**破坏性变更**: `_ask()` 返回值从 `(data, raw)` 改为 `(data, raw, provider_used)`

**如果有外部调用者**: 需要更新以接收 3-tuple

### 5. 模型差异

不同 provider 使用不同模型:
- **deepseek_nvidia**: DeepSeek R1 (reasoning model, REASONING/CONTENT format)
- **gemini**: Gemini 1.5 Flash 002 (fast, JSON-friendly)
- **openai**: GPT-4o-mini (balanced)

**JSON 提取**: ProviderPool 自动处理 DeepSeek R1 的 REASONING/CONTENT 格式（从 brain.py 复制逻辑）

**Model 质量**: 不同模型的输出质量可能不同，建议通过 A/B test 验证。
