### Recommendation 4: Optimize Prompt Size 📝

**Problem**: Large prompts increase latency

**Current propose_plan prompt includes**:
- Trading universe (10-20 symbols)
- Historical memory summary
- News context (multiple symbols)
- Features freshness data
- System health snapshot

**Potential Optimizations**:
1. **Reduce universe size**: Send only top 5 liquid symbols instead of 20
2. **Compress memory**: Summarize historical data more aggressively
3. **Remove redundant context**: Only include news for actively traded symbols
4. **Lazy load details**: Send minimal context first, details on-demand

**Expected Impact**:
- Prompt size: 5000 tokens → 2000 tokens (60% reduction)
- Latency: 25.6s → ~15s (estimated 40% reduction)

**Risk**:
- ❌ May reduce plan quality if context is insufficient
- Need A/B testing to validate

---

### Recommendation 5: Cache Expensive Operations 💾

**Problem**: Re-computing same data on every call

**Opportunities**:
1. **Trading universe**: Load once per session, not per call
2. **Memory summary**: Cache for 1 hour (doesn't change often)
3. **News**: Cache for 30 minutes
4. **Features freshness**: Cache for 5 minutes

**Implementation**:
```python
from functools import lru_cache
from datetime import datetime, timedelta

@lru_cache(maxsize=128)
def get_trading_universe_cached(date):
    # Cache universe per day
    return load_universe()
```

**Expected Impact**:
- Reduces data loading time
- May not directly reduce LLM latency (that's model-bound)

## 💰 **Cost Analysis** (Preliminary)

### Current Cost (DeepSeek R1 only)

**Assumptions**:
- DeepSeek R1 via NVIDIA: $0.002/1K input tokens, $0.002/1K output tokens
- Avg prompt: ~3000 tokens input, ~500 tokens output

**Cost per call**:
- Input: 3000 * $0.002 / 1000 = $0.006
- Output: 500 * $0.002 / 1000 = $0.001
- **Total**: **$0.007 per call**

**Cost per day** (based on 148 calls / 7 days = 21 calls/day):
- 21 calls * $0.007 = **$0.15/day**
- **$4.50/month**

**Conclusion**: Cost is **NOT a concern** (very low)

---

### Cost Impact of Fallback

**If 10% fallback to Gemini**:
- Gemini: $0.001/1K tokens (5x cheaper)
- 10% * 21 calls = 2.1 calls/day to Gemini
- Cost: 2.1 * $0.001 = $0.002/day

**If 10% fallback to OpenAI GPT-4o-mini**:
- OpenAI: $0.15/1M input, $0.60/1M output
- Very cheap (similar to Gemini)

**Conclusion**: Fallback cost impact is **negligible**
