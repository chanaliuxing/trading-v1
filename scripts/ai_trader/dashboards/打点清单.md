下面这份清单把“已经打点、可上大屏”的指标与工件分门别类列清楚，并给出一套可落地的大屏结构建议。

  已打点的核心指标（MLflow metrics）

  - 性能与上线（HPO/OOS）
      - oos_sharpe、oos_mdd、oos_trades
      - rl_gate_ok（RL 部署门槛是否通过）
  - 处方与落参（Pending/Apply）
      - pending_count、pending_disable_rl、pending_increase_conf_floor、pending_reduce_sizing_multiplier
      - 早盘实际执行（另一个运行 pending_exec_{date}）：
          - pending_total、applied_keys、applied_disable_rl、applied_increase_conf_floor、
            applied_reduce_sizing_multiplier、pending_denied、pending_unsupported
  - 对冲与风险（Hedging/Guardian）
      - hedging_events、hedging_notional_usd
      - guardian_events、guardian_max_dd_pct
  - 数据质量（Data Quality）
      - dq_ok、dq_failed_count、dq_passed_count
  - 工具健康（llm_trader Watchdog）
      - tools_kill、tools_restart、tools_backoff、tools_running
  - 组合与对冲 Overlay
      - overlay_beta、overlay_need_hedge
  - RL 对比评估（单独的 rl_eval 运行）
      - base_（如 base_sharpe/base_max_drawdown 等）与 rl_ 同维度指标
      - gate_ok（RL 候选是否通过门槛）

  已打点的参数与注释（便于大屏标注）

  - policy_*（HPO 门槛/策略阈值）
  - dq_failed_sym_1..5（黑名单前 5 个 symbol）
  - bp_small（最佳参数前 ~50 个键）

  已归档的工件（Artifacts，便于表格/明细面板）

  - 决策/处方/评估
      - hpo_decision.json、rl_eval.json、pending_actions.yml、daily_report.md
  - 风控与健康
      - guardian_events.jsonl（熔断/降风险/强平）
      - tools_ledger.jsonl（kill/restart/backoff 事件）
      - data_quality.json（DQ 结果：blacklist 与原因）
  - 对冲与组合
      - hedging_events.jsonl（对冲事件）
      - portfolio_weights.json、portfolio_apply.json
      - overlay_hedge.json、overlay_events.jsonl
  - 环境与反思
      - context.json（市场语境/Regime/VIX）、reflection_dxp.json（诊断/处方）

  可生成的大屏（Grafana 结构建议）

  - 总览（Today Overview）
      - KPI 指标卡：oos_sharpe、oos_mdd、rl_gate_ok、dq_ok、guardian_max_dd_pct、hedging_notional_usd、
        tools_running
      - 当日状态条：pending_count（含 -/+ 分类）、overlay_need_hedge（开/关）
  - 数据质量（Data Quality）
      - 黑名单计数：dq_failed_count / dq_passed_count
      - 黑名单表（Top N）：symbol + 第一条触发原因（来自 data_quality.json）
      - 趋势：dq_failed_count 按日
  - 风控与对冲（Risk & Hedging）
      - Guardian：guardian_events（日内总数）+ guardian_max_dd_pct（最大日内回撤）
      - 对冲：hedging_events（计数）+ hedging_notional_usd（名义）
      - 明细表：tools_ledger.jsonl（最近 50 条 kill/restart/backoff）
  - 策略与上线（Strategy & Deployment）
      - HPO/OOS：oos_sharpe、oos_mdd、oos_trades
      - Pending：pending_count 三分类堆叠条
      - 实际落参：pending_exec_{date} 指标（applied_*）与 decision_log.yaml 链接
  - 组合与 Overlay（Portfolio & Overlay）
      - overlay_beta 与 overlay_need_hedge 指示灯
      - 权重表：portfolio_weights.json → symbol: scale 与 multiplier（Top 10）
  - RL 评估（RL Evaluation）
      - base_sharpe vs rl_sharpe、base_max_drawdown vs rl_max_drawdown
      - gate_ok 指示灯
  - 工具健康（LLM Tools Health）
      - tools_running、tools_kill、tools_restart、tools_backoff（单日与趋势）
      - 最近事件表：tools_ledger.jsonl（时间、事件、原因）

  数据来源与查阅入口

  - MLflow 指标与工件
      - learn_{date} 运行：上面列的多数指标/工件
      - pending_exec_{date} 运行：早盘处方实际执行指标与工件
      - rl_eval_* 运行：RL 对比指标与评估 JSON
  - 每日目录（runs/ai_trader/YYYY-MM-DD）
      - data_quality.json/guardian_events.jsonl/tools_ledger.jsonl/hedging_events.jsonl/portfolio_* /
